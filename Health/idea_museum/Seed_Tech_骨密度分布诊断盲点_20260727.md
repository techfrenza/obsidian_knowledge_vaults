## 技术核心逻辑

**当前临床标准的结构性缺陷**：

骨质疏松诊断基于T-score（将BMD与年轻成人平均值比较）：
- T-score ≥ -1.0：正常
- -2.5 < T-score < -1.0：骨量减少
- T-score ≤ -2.5：骨质疏松

这个框架将股骨颈视为**均质结构**，但它不是。

**骨骼年龄图谱研究**（JBMR，2022，Yoshito Otake，NAIST，13,000人+7,000 UK Biobank参与者）：

| 发现 | 含义 |
|------|------|
| 股骨颈各区域密度衰减速率不同 | 弱化是局部的，不是均匀的 |
| 相同总BMD者，密度分布模式不同 | "相同风险"的假设是错误的 |
| 弱化位于关键受力区域时骨折风险大幅上升 | 位置比数量更重要 |
| 可预测"固定 vs 置换"手术类型 | 资源预配置价值（外科计划工具） |

## 优缺点对比

| 维度 | 当前T-score诊断 | 骨骼年龄图谱 |
|------|--------------|------------|
| 诊断颗粒度 | 单一均值 | 空间分布模式 |
| 同BMD人群区分能力 | 无（视为等同风险） | 有（定位高风险弱化区域） |
| 临床可用性 | 成熟、标准化 | 技术就绪，临床证据积累中 |
| 转化障碍 | 无 | 新旧体系切换需大量循证数据 |
| 骨折风险预测精度 | 中 | 预期更高（研究进行中） |

**核心启示**：骨质疏松"正常"报告可能错误——同一张DEXA扫描图像含有分布信息，但被平均后丢失了。这与心周脂肪被放射科忽视的信息丢失模式高度类似。
