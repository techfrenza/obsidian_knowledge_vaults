## 技术核心逻辑

### 矛盾证据并排

| 研究 | 设计 | 结论 |
|------|------|------|
| Science Translational Medicine 2025年12月 | 严格控制热量摄入，比较8小时TRE vs 对照 | **IF无额外代谢益处**（胰岛素敏感性、心血管指标均无差异） |
| 2025年多项研究 | 自由饮食 + IF | 内脏脂肪、血压、炎症标志物改善 |
| 格拉纳达大学RCT（2026） | 12周16:8 TRE，12个月随访 | eTRE额外改善脂肪质量（vs 晚时段TRE） |
| Cochrane综述2026 | 22项RCT，1,995人 | IF减重效果与标准饮食建议**相当**，无额外优势 |

### 机制分解

两份矛盾证据实际上揭示了 IF 作用的两个层次：

1. **行为机制（主要）**：进食窗口限制 → 自然减少热量摄入 → 代谢改善
   - 这个机制在控制热量后被去除，因此控制热量的研究显示 IF 无额外益处
   
2. **昼夜节律机制（增量）**：进食时间对齐代谢时钟 → 独立于总热量的少量代谢增益
   - eTRE vs 晚时段 TRE 在格拉纳达大学 RCT 中的差异支持这个增量存在
   - 但这个增量可能小于自由饮食研究中显现的总体效应

### 实践含义

对临床医生和患者：IF 的价值不在于"特殊代谢魔法"，而在于"简化了饮食决策从而自然减少摄入"——这是一个行为工具，不是一个代谢药物。但对已经控制热量的人，额外的时间对齐仍有少量增益。
