# 内分泌干扰物

内分泌干扰物（EDC）是合成或天然化学物质，通过**模拟激素、阻断激素受体或干扰激素信号**破坏内分泌系统。微量长期接触产生累积效应，与激素失衡、生育障碍、乳腺/甲状腺风险相关。

## 12类主要日常接触源

| 来源 | 化合物 | 主要危害机制 | 规避策略 |
|------|--------|------------|---------|
| 塑料、罐头、收据 | BPA（双酚A） | 拟雌激素，干扰雌激素代谢 | 使用玻璃/不锈钢容器，避免加热塑料 |
| 个护产品、香水 | 邻苯二甲酸酯（Phthalates） | 降低生育力，干扰激素 | 选无邻苯二甲酸酯/无香产品 |
| 洗发水、化妆品 | 对羟基苯甲酸酯（Parabens） | 拟雌激素，已在乳腺组织中检出 | 选无防腐剂产品 |
| 旧电器、受污染鱼 | 多氯联苯（PCBs） | 积聚脂肪组织，影响激素平衡 | 避免高脂鱼类（养殖三文鱼/蓝鱼）；妥善回收旧电子设备 |
| 不粘锅、防污面料 | 全氟化合物（PFCs/PFAS） | 干扰甲状腺和生殖激素；环境中长期残留 | 使用不锈钢或铸铁炊具，避免防污喷雾 |
| 除草剂、自来水 | 阿特拉津（Atrazine） | 干扰激素，影响生殖系统 | 使用高品质碳滤芯净水，选有机农产品 |
| 熏烤食物、工业排放 | 二噁英（Dioxins） | 破坏雌激素代谢，影响免疫 | 限制熏烤肉类，支持有机农业 |
| 抗菌皂、部分牙膏 | 三氯生（Triclosan） | 干扰甲状腺激素，助推抗生素耐药 | 用普通肥皂洗手，检查产品标签 |
| 除草剂、常规农产品 | 草甘膦（Glyphosate） | 破坏肠道菌群和激素功能 | 彻底清洗蔬果，尽量选有机 |
| 家具、床垫、电子设备 | 多溴联苯醚（PBDEs）阻燃剂 | 干扰甲状腺激素，积聚家庭粉尘 | 选无PBDE家具，使用HEPA吸尘 |
| 化学防晒霜 | 苯酮类（Oxybenzone） | 拟雌激素，可能增加皮肤氧化应激 | 改用矿物防晒（非纳米氧化锌/二氧化钛） |
| 海鲜、旧涂料、水管 | 重金属（汞/铅/镉） | 干扰酶功能，增加氧化应激 | 限制高汞鱼类（剑鱼等）；过滤饮用水 |

## 累积效应原理

EDC的危害常被单独评估时低估。**鸡尾酒效应**：多种EDC同时存在时，互相协同增强干扰力度，即使每种单独浓度低于毒性阈值。女性激素周期波动使接触时机也成为关键变量——胎儿期/青春期接触风险更高。

## 高风险人群

- 有乳腺癌/甲状腺疾病家族史者
- 备孕/孕期女性
- 青春期发育中的青少年
- 自身免疫性疾病患者

## 支持解毒与激素代谢的策略

| 策略 | 机制 |
|------|------|
| 摄入十字花科蔬菜（西兰花/卷心菜）+ DIM | 支持雌激素正常代谢路径 |
| 葡萄糖酸钙D（Calcium D-glucarate） | 抑制β-葡萄糖醛酸酶，促进雌激素排泄 |
| 肝脏支持（牛奶蓟/NAC等） | 加速EDC的肝脏解毒 |
| 规律运动 + 淋巴循环 | 促进排毒，维持激素平衡 |
| 压力管理 | 皮质醇过高本身干扰激素代谢并降低解毒效率 |

## 矛盾与争议

**BPA替代品争议**：BPA-free产品常含双酚S（BPS）或双酚F（BPF），研究（C级）显示这些替代品可能具有相似甚至更强的雌激素活性，"BPA-free"标签不代表更安全。  
**草甘膦**：国际癌症研究机构（IARC）将其列为2A类"可能致癌物"，但EPA/EFSA结论不同；研究机构之间存在分歧（B-C级证据）。
