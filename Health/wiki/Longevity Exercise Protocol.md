# Longevity Exercise Protocol

运动是证据最强的长寿干预之一，Eric Topol和Bryan Johnson均将其描述为"最强效的医学干预"。

## 周计划（Johnson标准）

| 类型 | 频率/时长 | 说明 |
|------|----------|------|
| 力量训练 | 3次/周 | 对抗肌肉减少症（sarcopenia） |
| Zone 2有氧 | 150 min/周 | 可维持对话的中等强度 |
| HIIT高强度 | 75 min/周 | 无法对话的剧烈运动 |
| 灵活性/平衡 | 每次穿插 | 防止伤害，维持功能性 |

理想总量：每周6小时。即使每天20分钟也有显著获益。

## 死亡率减少证据

| 干预 | 全因死亡率减少 |
|------|-------------|
| 最低推荐运动量 | 26-31% |
| 超出最低量2-4倍 | 21-23%额外减少 |
| 中高强度结合 | 35-42%减少 |
| 每周60分钟力量训练 | 25%减少（Topol数据） |
| 每周450分钟快走 | 多活4.5年 |

## Topol数据：运动作为时间乘数

- 1分钟运动 → 额外延长5分钟寿命
- 高强度运动 → 比率升至7-8分钟
- 早起有氧（低强度）→ 每分钟3分钟延寿

## 额外行为规范

- 每30分钟起身活动2-3分钟（久坐打断）
- 每餐后步行5-10分钟
- 避免运动伤害——伤害导致补偿性体态问题，长期有害

## 女性周期调整

| 阶段 | 建议 |
|------|------|
| 卵泡期 | 高强度 + 力量训练优先，雌激素增强恢复 |
| 黄体期 | Zone 2有氧 + 轻度力量，孕酮降低运动能力 |
| 围绝经期/绝经后 | 力量训练 + HIIT，维持骨密度和肌肉质量 |

## 运动剂量精确化：最新证据

详细数据见[[运动剂量精确化]]。核心更新：

### 性别差异：女性需要的运动量是男性的一半
- 女性：~4小时/周 → 降低30%心血管病风险
- 男性：~9小时/周 → 相同30%降低效果
- 已患冠心病者：女性达推荐量死亡率降低70%，男性仅20% `[A]`（UK Biobank 85,000人）
- 机制：雌激素增强脂肪氧化 + 女性更高比例耐力型肌纤维

### 周末战士等效于每日锻炼
- 每周≥150分钟运动，集中在1-2天 = 均匀分布 → 264种疾病风险降低无显著差异 `[B]`（90,000 UK Biobank参与者）
- 高血压风险：两组均降低>20%；糖尿病风险：两组均降低>40%

### 最小有效剂量
- 每天+5分钟中等强度活动 → 可避免全球10%过早死亡 `[A]`（Lancet 2026，135,000+人）
- 与饮食/睡眠协同：+11分钟睡眠 + +5分钟运动 + +0.25杯蔬菜 → 10%降低心脏病风险
