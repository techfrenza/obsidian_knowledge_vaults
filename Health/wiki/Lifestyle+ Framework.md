# Lifestyle+ Framework

Eric Topol在《Super Agers》中提出的扩展健康框架，突破传统"饮食+运动+睡眠"三角，将环境毒素和社会因素纳入系统性考量。

## 传统Lifestyle vs Lifestyle+

| 维度 | 传统健康 | Lifestyle+ |
|------|---------|-----------|
| 饮食 | 是 | 是（+AI个性化营养） |
| 运动 | 是 | 是（+抗阻训练强调） |
| 睡眠 | 是 | 是（+神经保护机制） |
| 环境毒素 | 否 | **是（新增核心维度）** |
| 社交/孤独 | 否 | **是（与吸烟同级风险）** |
| 社会经济地位 | 否 | **是（独立死亡风险因素）** |

## 各支柱详解

**饮食 + "AI饮食"**
- 不良饮食与全球22%死亡相关
- 强调地中海（aMED）、DASH、植物性饮食
- 避免超加工食品（UPF）
- 个体差异（肠道微生物组）使通用建议效果不一 → AI个性化营养是未来方向

**运动——"最强效医学干预"**
- 影响几乎所有组织，改善心血管、抑制炎症、清除大脑有毒蛋白
- Topol修正：之前过度强调有氧，现强调**抗阻/力量训练**对抗肌肉减少症（sarcopenia）

**睡眠——"大脑清洗"**
- **神经胶质系统（glymphatic system）**：深度非REM睡眠期间清除代谢废物（β-淀粉样蛋白）
- Ambien等安眠药可能损害这种清除功能，增加阿尔茨海默病风险

**环境毒素（"+"的关键贡献）**
- **微塑料/纳米塑料**：已在人体动脉和脑细胞中发现，引发多器官急性炎症
- **空气污染**：全球疾病负担首要贡献者，心血管健康无安全阈值
- **"永久性化学物质"（PFAS）**：持久性有机污染物

**社交孤立**
- 孤独/社交隔离 → 全因死亡率增加**32%**
- 风险等级：与吸烟或高血压相当

**社会经济地位**
- 独立过早死亡风险因素
- 与吸烟、高血压影响相当

## 可操作的含义

保护生命健康不只是个人行为选择，还涉及：
- 选择低污染居住环境
- 积极维护社交网络（家庭、友谊、社区）
- 减少塑料暴露
- 了解并解决个人社会经济风险
