# Berberine

Berberine是一种从小檗科植物（如黄连、黄柏皮）提取的异喹啉生物碱，在长寿社区中常被称为"天然二甲双胍"，核心机制是激活 [[AMPK]]。

## 来源与化学特征

Berberine是苯基异喹啉生物碱，呈黄色，历史上被用于染色。主要植物来源：欧洲小檗（Berberis vulgaris）、俄勒冈葡萄（Mahonia aquifolium）、黄连（Coptis chinensis）等。不存在于日常食物中，须通过补充剂摄入。

## 核心机制

| 机制 | 说明 |
|------|------|
| AMPK激活 | 直接靶向AMPK，调节细胞能量代谢和葡萄糖/脂质稳态 |
| 抗炎 | 降低促炎细胞因子，减缓炎症驱动的老化过程 |
| 肠道微生物组调节 | 与 [[Metformin]] 类似，均通过改变肠道菌群来影响代谢 |
| 棕色脂肪激活 | 激活棕色脂肪组织，促进产热和代谢消耗 |

**AMPK是四条衰老调控通路之一的核心**，其失调被认为是老化的驱动因素之一。

## 临床证据

### 糖尿病
- 2015年meta分析：Berberine + 生活方式干预降血糖效果优于单独生活方式干预
- 2019年系统综述：Berberine与降血糖药联用比单用药物更有效

### 高胆固醇
- 有证据支持Berberine可降低LDL胆固醇和甘油三酯（2017年综述）
- 多项研究结论：仍需更多大规模临床试验

### 肥胖
- 2017年综述：750mg×2/天，持续3个月，体重显著下降
- 机制推测：AMPK交互改变代谢 + 激活棕色脂肪

## 与Metformin的比较

| 指标 | Berberine | Metformin |
|------|-----------|-----------|
| 来源 | 天然植物碱 | 合成双胍 |
| 核心机制 | AMPK激活 | AMPK激活 + 线粒体复合体I抑制 |
| 肠道菌群 | 类似调节 | 类似调节 |
| 可及性 | 非处方补充剂 | 处方药 |
| 长期安全数据 | 不足 | 丰富 |

## 安全性与风险

- 常见轻微副作用：腹泻、便秘、恶心、皮疹、头痛
- **药物相互作用风险高**：抑制CYP2D6和CYP3A4酶，与他汀类药物联用可能增加心脏毒性
- 长期使用数据不足，**建议在医生指导下使用**

## 矛盾与争议

Berberine常被比作Metformin，但两者的具体机制存在差异，且Berberine的临床证据质量（研究规模、随访时长）与Metformin相比仍有较大差距。
