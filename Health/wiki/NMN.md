# NMN（烟酰胺单核苷酸）

NMN（Nicotinamide Mononucleotide）是核糖核苷酸，NAD+的直接前体，可补充随年龄下降的NAD+水平，从而改善细胞能量代谢、DNA修复和线粒体功能。

## 分子生物学

NMN = 烟酰胺基 + 核糖 + 磷酸基。通过NAMPT酶（限速酶）合成，也可由NR添加磷酸基生成。2019年发现Slc12a8基因编码的NMN特异转运体——NMN可**直接进入细胞**而无需先转化为NR（这一发现对NR市场是个打击）。

## NAD+前体比较

| 前体 | 路径 | 特点 |
|------|------|------|
| NMN | 直接转化 | 分子量大，曾质疑细胞摄取；2019年发现专用转运体 |
| NR（烟酰胺核苷） | 需去磷酸化再合成 | 市场较早，研究更多 |
| 烟酸（Niacin） | 从头合成路径 | 便宜但可引起皮肤潮红 |
| NMNH（还原型NMN） | 新型前体 | 更强效但尚无商业化补充剂 |

禁食和热量限制也可提升NAD+水平并激活Sirtuins（长寿基因）。

## 关键研究时间线

| 年份 | 发现 |
|------|------|
| 1963 | NMN激活PARP酶（DNA修复关键蛋白）的发现 |
| 2014 | Sinclair团队：NMN延长小鼠寿命 |
| 2017 | NMN通过提高NAD+水平逆转小鼠DNA损伤 |
| 2019 | NMN专用转运体Slc12a8发现 |
| 2020 | NMN改善老龄小鼠神经血管健康，逆转590基因中204个的老化表达 |
| 2020 | NMN恢复老龄小鼠神经血管耦合（NVC），NVC缺陷是认知运动功能老化衰退的主因 |

## 功效领域

### 心血管

- 心力衰竭（线粒体翻译缺陷）小鼠模型中：NMN补充改善溶酶体功能、增强自噬、延长寿命
- NMN通过改善溶酶体功能（而非直接改善线粒体功能）防止铁死亡（ferroptosis）
- ApoE缺陷动脉粥样硬化模型：NMN使斑块减少36%，坏死核减少48%，脂质面积降低43%，胶原含量增加51%

### 炎症与免疫

NMN降低氧化应激标志物（MDA），下调促炎细胞因子，并通过SIRT1/NF-κB通路调节巨噬细胞极化。

### 认知与代谢

- 老龄化SAMP8小鼠（NMN+NAOS联合）：学习记忆显著改善，线粒体融合蛋白OPA1/Mitofusin2升高
- 手术后认知功能障碍（POCD）预防：NMN保护NAD+-SIRT1信号通路，减少术后认知损伤
- 2021年人类试验：NMN改善糖尿病前期女性肌肉葡萄糖代谢

## 人类临床数据（截至2026）

- 单次给药（2020）：安全、耐受性好
- 氧气摄取量（2021）：NMN改善业余跑者有氧能力（效果适中）
- NAD+水平（多中心试验，2022）：NMN提升血浆NAD+，能量水平改善，效果较小
- 综合安全性（2023年更新综述）：多个剂量均安全，无重大副作用，个体响应差异显著

**局限性**：对照组NAD+水平也有所上升（安慰剂效应或饮食影响），研究规模较小（66人）。

## 生物利用度创新

- NMN-HAP纳米颗粒（羟基磷灰石载体）：循环时间更长，脑和肝中NAD+/NR浓度显著提升
- 微凝胶包载（LYC+NMN）：肠道抗炎、调节肠道菌群、保护肝脏免受LPS损伤

## 安全性

长期人类数据有限，但现有研究未报告重大副作用。早期使用者本质上在自我实验。高成本是普及的主要障碍。
