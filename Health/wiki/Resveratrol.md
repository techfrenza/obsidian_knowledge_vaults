# Resveratrol

白藜芦醇（Resveratrol）是一种天然多酚类化合物，作为SIRT1激活剂和热量限制模拟物被研究，在多种模式生物中延长寿命，但人类临床试验结果不一，生物利用度低是主要挑战。

## 来源与化学

天然多酚，植物应激信号分子（phytoalexin）。食物来源：葡萄（尤其红葡萄酒）、花生、蓝莓、黑莓、可可等。被代谢迅速清除，口服生物利用度低。

## 发现史与核心机制

热量限制研究（酵母）发现SIR2酶在营养稀缺应激中起关键作用。Resveratrol被鉴定为SIRT1（SIR2的人类版本）的潜在激活剂，同时是环氧化酶（Cox）抑制剂。

| 机制 | 效应 |
|------|------|
| SIRT1激活 | DNA修复↑、代谢效率↑、长寿信号激活 |
| AMPK激活 | 能量传感器激活，与SIRT1需求相互依赖 |
| Cox-2抑制 | 抗炎、潜在化学保护 |
| 直接抗氧化 | 清除ROS，抗脂质过氧化 |
| NF-κB抑制 | 减少炎症基因表达 |
| 雌激素受体调节 | 既阻断又模拟雌激素效应（双向作用） |

## 功效领域

### 心血管

- 抑制VCAM表达→减少白细胞穿透内皮→减缓动脉粥样硬化
- 抑制血管平滑肌细胞（VSMC）增殖→防止血管壁增厚→延缓慢性高血压
- 上调内皮NO合酶→NO生成↑→血管舒张、血压降低
- 抑制血小板活化和聚集→减少血栓形成风险

### 糖尿病与肥胖

提升胰岛素敏感性和葡萄糖耐量，改善血脂谱。可降低空腹血糖、胰岛素和HbA1c，升高HDL、降低LDL。通过SIRT1和AMPK改善代谢感应器活性。

### 神经保护

- 减少神经氧化应激和神经炎症
- 清除β-淀粉样斑块（阿尔茨海默病相关）和α-突触核蛋白聚集物（帕金森病相关）
- 大鼠实验：补充白藜芦醇促进新突触形成、改善血流、改善记忆学习和情绪
- 人类试验：200mg白藜芦醇+320mg槲皮素，26周，记忆显著改善

### 长寿证据层次

| 物种 | 效果 |
|------|------|
| 酵母 | 寿命延长70% |
| 线虫、果蝇、脊椎鱼 | 显著延长寿命 |
| 高热量饮食小鼠 | 平均寿命与正常饮食等同（纠正高热量危害） |
| 人类 | 无直接延长最大寿命的证据 |

### 抗癌

抑制乳腺、结肠、肝、胰腺、前列腺、皮肤、肺等多种癌细胞增殖。机制：抑制细胞色素P450（阻断致癌物激活）、降低DNA修复蛋白（在癌细胞中）、阻断新血管生成、抑制基质金属蛋白酶（MMP）、促进凋亡。

## 生物利用度问题与新型制剂

口服白藜芦醇被快速代谢，4-8g/天才在结肠癌研究中显现轻微效果。改进方向：
- 微粉化制剂（增大表面积）
- 脂质体包载
- 纳米载体（脂质体、聚合纳米颗粒、光解体、植物体）

## 安全性与药物相互作用

- 轻中度胃肠道副作用（>1g/天时）：恶心、腹胀、腹痛
- **抗凝药物联用禁忌**：白藜芦醇抑制血小板聚集，与抗凝药合用可能导致出血
- **细胞色素P450抑制**：可能提升多种药物毒性
- **雌激素相关**：有雌激素驱动癌症史的女性应避免；孕妇和哺乳期女性慎用

## 矛盾与争议

临床试验结果不一——部分研究显示显著益处，其他研究未能重现。SIRT1激活机制本身也存在争议（间接激活还是直接激活）。Price等2012年研究发现白藜芦醇的线粒体获益需要SIRT1，但SIRT1本身需要AMPK先被激活。
