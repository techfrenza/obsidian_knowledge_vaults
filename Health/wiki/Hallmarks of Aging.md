# Hallmarks of Aging

2013年López-Otín等人提出的衰老标志物框架（2023年更新至12个标志物），是当前衰老科学的主要分类模型，将细胞和分子层面的衰老机制分为三层级：原发性→拮抗性→整合性。[A]

## 三层级框架

| 层级 | 标志物 | 特征 |
|------|--------|------|
| **Primary（根本原因）** | 基因组不稳定性、端粒缩短、表观遗传改变、蛋白质稳态丧失 | 直接损伤细胞，是衰老的上游驱动因子 |
| **Antagonistic（拮抗性）** | 营养感应失调（mTOR/IGF-1）、线粒体功能障碍、细胞衰老（Senescence） | 初期有保护作用，慢性激活后变有害 |
| **Integrative（整合性）** | 干细胞耗竭、慢性炎症（炎症衰老）、细胞间通讯改变 | 上游积累后的系统性下游后果 |

## 主要干预策略对照表

| 标志物 | 靶向策略 | 代表疗法/化合物 |
|--------|----------|----------------|
| 基因组不稳定性 | 增强DNA修复，减少突变压力 | NAD⁺前体（NR/NMN）、PARP激活剂、抗氧化剂 |
| 端粒缩短 | 促进端粒酶活性，保护端粒 | TA-65、TERT基因疗法、生活方式（运动、减压） |
| 表观遗传改变 | 修改染色质状态，重置表观遗传标记 | 山中因子、HDAC抑制剂、NAD⁺前体 |
| 蛋白质稳态丧失 | 增强蛋白折叠和清除 | 雷帕霉素、亚精胺（自噬）、蛋白酶体激活剂 |
| 营养感应失调 | 恢复代谢平衡 | 二甲双胍、雷帕霉素、热量限制、间歇性断食 |
| 线粒体功能障碍 | 促进线粒体自噬、线粒体生物合成 | Urolithin A、MitoQ、运动、NAD⁺前体 |
| 细胞衰老（Senescence） | 清除或抑制衰老细胞及SASP | Senolytics（达沙替尼、疫苗靶向）、二甲双胍 |
| 干细胞耗竭 | 重新激活内源性干细胞 | 间充质干细胞疗法、GDF11、断食、运动 |
| 细胞间通讯改变 | 改善系统性信号传导 | NAD⁺前体、益生菌、运动、外泌体疗法 |
| 慢性炎症（炎症衰老） | 抑制炎症通路和免疫功能障碍 | IL-1/IL-6抑制剂、Omega-3、Senolytics、抗炎饮食 |

## 拮抗性标志物的双面性（关键概念）

拮抗性标志物（营养感应/线粒体/细胞衰老）具有"先保护后伤害"特性：
- **细胞衰老（Senescence）**：初期抑制肿瘤生长（保护），慢性分泌SASP（有害炎症）
- **mTOR激活**：短期促进合成代谢（保护），长期抑制自噬（有害）
- **VEGF**：缺乏时引发类衰老表型，过量时导致病理性血管生成和癌症 [A]

这意味着许多长寿干预的"剂量-时机-组织特异性"控制至关重要，激活某些通路可能同时减缓和加速衰老。

## 器官特异性老化的临床发现

斯坦福Wyss-Coray实验室2024年《Nature》研究（5676名参与者，SomaScan检测856个器官特异性蛋白质）：[A]
- 50岁以上个体中18.4%有至少一个快速衰老器官
- 10/11个器官的加速衰老与未来15年死亡风险增加15-50%相关
- **心脏加速老化** → 心衰风险增加250%
- **脑血管加速老化** → 阿尔茨海默病强预测因子
- 整合性标志物出现前，器官特异性检测可作为早期预警系统

## 矛盾与争议

激活某些通路的疗法可能"反直觉地"加速衰老：
- 雷帕霉素（mTOR抑制，自噬促进）→ 延长寿命，但不慎可能引发干细胞耗竭 [A/B]
- 端粒酶激活（TERT基因疗法）→ 可能悖论性地促进癌症 [A]
- VEGF疗法 → 三期临床试验主要失败，虽VEGF缺失也有害 [A]
- 低剂量阿司匹林 → 抗炎老化理论支持，但老年人群净收益仍有争议 [A/B]
