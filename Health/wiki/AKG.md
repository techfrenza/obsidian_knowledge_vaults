# AKG（α-酮戊二酸）

Alpha-ketoglutarate（AKG，α-酮戊二酸）是克雷布斯循环（Krebs Cycle）的关键中间体，通过抑制ATP合酶和TOR通路触发自噬，在C. elegans中延长寿命约50%，是Bryan Johnson长寿协议中的核心补充剂。

## 发现历史

1937年由Hans Adolf Krebs和William Arthur Johnson在谢菲尔德大学发现，是克雷布斯循环整体鉴定的组成部分。Krebs于1953年获诺贝尔生理学或医学奖。

## 多重功能角色

| 功能 | 说明 |
|------|------|
| 能量代谢中间体 | 克雷布斯循环关键节点，氧化乙酸产生ATP |
| 氨基酸代谢前体 | 谷氨酸和谷氨酰胺的重要来源，防止肌肉蛋白分解 |
| 氮清除剂 | 阻止氮过载，防止氨积累 |
| 细胞信号分子 | 调节TET酶（DNA去甲基化）和JmjC去甲基化酶（组蛋白去甲基化） |
| 表观遗传调节剂 | 通过TET/JmjC影响基因表达，是 [[表观遗传时钟]] 的代谢上游调控因子 |

## 核心长寿机制

### ATP合酶抑制 → 自噬增强

2014年Nature研究（C. elegans）：

```
AKG → 直接结合ATP合酶β亚基 → 抑制ATP合酶
     → ATP水平下降 + 耗氧量降低
     → 自噬增强 + 寿命延长约50%
```

关键洞察：**适度抑制线粒体功能（特别是电子传递链）延长寿命**——"慢活慢死"原理（"live slowly, die old"）。过度抑制则有害，需要恰当的平衡点。

### TOR通路依赖

AKG不直接作用于TOR，但通过ATP合酶抑制间接影响mTOR：

```
AMP/ATP比升高 → AMPK激活 → 磷酸化TSC2 → 抑制TOR信号
                            ↓
                        FoxO转录因子（PHA-4）激活 → 寿命延长
```

**跨物种TOR抑制均可延长寿命**：酵母、线虫、果蝇、小鼠均已验证。

### 禁食模拟效应

AKG水平在禁食状态下（饥饿蠕虫和人类运动后）自然升高，提示其是热量限制和运动的内源性代谢信号。**AKG不增加热量限制动物的寿命**——说明它们共用同一下游通路。

## 小鼠研究（Kennedy实验室）

Dr. Brian Kennedy（Buck老龄化研究所）发表小鼠研究：Ca-AKG（钙α-酮戊二酸）可延长健康寿命（healthspan）和寿命，同时减少慢性炎症。Bryan Johnson即使用Ca-AKG形式，1g/次，早晨+晚餐服用。

## 运动与AKG

运动后人体AKG水平升高，被认为是应对运动相关能量消耗（糖异生激活）的代谢响应。这为运动延长寿命的机制研究提供了一个新视角：运动可能部分通过升高AKG激活长寿通路。

## 安全性

人类中无重大副作用报告，但系统性长期安全数据有限。在运动营养补充剂中已有较长使用历史（运动员用于耐力和减轻疲劳）。
