# Healthspan vs Lifespan

Eric Topol在《Super Agers》和Ground Truths通讯中的核心框架：区分生命总时长（Lifespan）与健康状态中的时长（Healthspan）。

## 定义

| 概念 | 定义 |
|------|------|
| **Lifespan（寿命）** | 生命总时长 |
| **Healthspan（健康寿命）** | 无重大慢性病、保持认知和体能完整的时期 |
| **健康老龄化** | 到达70-75岁时无11种主要慢性病，且认知/体能完好 |

**现状**：当前仅约9.3%的人在70岁时达到健康老龄化标准。

## 生活方式对预期寿命的量化影响

| 干预组合 | 寿命延长 |
|---------|---------|
| 8个关键生活方式因素（40岁开始） | 男性+24年，女性+20.5年 |
| 有限健康习惯（不抽烟+BMI+适度饮酒） | 平均+7年 |
| 20岁开始最优饮食替代西式饮食 | +10年以上 |
| 40岁开始最优饮食 | +约9年 |
| 每周450分钟快走 | +4.5年 |
| 地中海/DASH饮食 | 70-75岁无重大慢病概率翻倍 |

## 运动作为时间乘数

- 普通强度：1分钟运动 → 额外5分钟寿命
- 高强度运动：1分钟 → 额外7-8分钟寿命
- 每周60分钟力量训练 → 全因死亡率降低25%

## Lifestyle+框架（Topol的核心贡献）

传统健康：饮食+运动+睡眠
**Lifestyle+** 额外包括：
- **环境毒素**：微塑料（已发现于人体动脉和脑细胞）、空气污染（无安全阈值）、永久性化学物质
- **社会孤立**：孤独/社交隔离→全因死亡率增加32%（等同于吸烟或高血压）
- **社会经济地位**：是独立早死风险因素

## Proteomic器官时钟

Topol描述的"安静革命"：通过测量数千种血浆蛋白确定各器官的生物年龄：
- "极端衰老"心脏者：心力衰竭风险高5倍
- 大脑/免疫系统"慢速衰老"者：15年生存率显著改善
