# HBOT（高压氧疗法）

高压氧疗法（Hyperbaric Oxygen Therapy）：在高压舱内吸入100%纯氧，Bryan Johnson称其为"我做过的最高价值健康疗法之一"。

## 协议参数

| 要素 | 参数 |
|------|------|
| 氧气浓度 | 100%（通过面罩，非环境100%氧气） |
| 气压 | 2个大气压 |
| 单次时长 | 90分钟（20分钟+5分钟空气休息，循环） |
| 总次数 | 60次（12周，5次/周） |
| 舱型 | HPO Tech硬壳舱，周围加压空气 |

**注意**：避免100%环境氧气舱（眼睛刺激、白内障风险、点火风险）

## 限制与注意

- FDA未批准任何抗衰老适应症
- 主要证据来自单一案例（n=1）或小样本研究
- 成本高昂；专业设施需求
- 维生素D上升235%可能是肠道微生物改善的继发效应
