# Metformin Longevity

二甲双胍（Metformin）是最古老的2型糖尿病药物之一，其长寿潜力来自对AMPK/mTOR轴的多靶点调节——与热量限制和[[Rapamycin Longevity]]共享部分分子通路。2026年现状：**代谢风险人群有意义，健康成人仍无证据**。

## 分子机制

| 机制 | 细胞效应 | 长寿相关性 |
|------|---------|-----------|
| AMPK激活 | 模拟热量限制：能量保护、自噬、胰岛素敏感性 | 动物模型强证据 |
| mTORC1抑制 | 减弱过度细胞生长信号 | 与[[Rapamycin Longevity]]同路径 |
| 炎症减少 | 降低CRP、NF-κB、线粒体ROS | 连接至炎症衰老（inflammaging） |
| 胰岛素敏感性提升 | 减少循环胰岛素 → 降低IGF-1信号 | 减少细胞衰老加速信号 |
| 线粒体复合物I抑制 | 减少氧化损伤 | DNA和线粒体保护 |

## 2026年证据状态

**关键试验**：

| 试验 | 人群 | 结果 |
|------|------|------|
| MILES（n=14） | 糖耐量受损老年人 | 分子生物标志物变化，未测长寿结局 |
| MASTERS（2019） | 老年人阻力训练 | **减少肌肉增益** — 负面发现 |
| MET-PREVENT（2025，Lancet） | 肌少症/虚弱老年人 | 步速无改善，耐受性更差 |
| DPP/DPPOS（2026，JAMA） | 糖尿病前期21年随访 | 生活方式干预>二甲双胍（多病共存风险） |
| 猕猴研究（2024，Cell） | 肥胖雄性猕猴 | 脑生物年龄减少~6年，认知改善 |
| TAME（进行中） | 65-79岁健康成人，3000+人 | 无已发表疗效结果 |

**观察性数据的陷阱**：Bannister 2014研究（糖尿病用药者vs非糖尿病对照）发现反直觉的长寿优势，但2022年丹麦研究未能复制，2025年批判性综述指出**选择性偏差**（用健康糖尿病患者对比可能有未诊断疾病的"健康"对照组）人工放大了效益。

## 适用人群矩阵

| 代谢表型 | 临床解读 | 优先行动 |
|---------|---------|---------|
| 糖尿病前期 + 内脏脂肪 | 可能有合理代谢适应症 | 医生评估代谢标志物 |
| 健康成人做力量训练 | 未证明长寿益处，可能**抑制运动适应** | 优先运动、蛋白质、睡眠 |
| 老年人虚弱/肌少症 | MET-PREVENT不支持 | 有监督力量训练 + 蛋白质 |
| 低eGFR / 肝病 | 安全风险超过假设益处 | 肾/肝功能评估 |

## 安全监测要点

- **维生素B12**：长期使用导致6-10%缺乏率，可模拟神经病变/认知症状
- **肾功能**：eGFR<30禁用；30-45慎用
- **肌肉干扰**：MASTERS/MET-PREVENT提示对力量训练适应有抑制 — 对长寿策略是重大权衡
- **造影剂**：碘化造影剂前需暂停
- **乳酸酸中毒**：罕见（<0.1%）但致命，肾衰竭时风险真实存在

## 与其他长寿干预的比较

- vs [[Rapamycin Longevity]]：两者共享AMPK-mTOR轴；雷帕霉素mTOR抑制更直接和强效，动物寿命延长证据更一致
- vs 生活方式干预：DPP/DPPOS的25年数据清楚：**强化生活方式 > 二甲双胍** 在多病共存风险终点

## 与间歇性禁食的关系

[[间歇性禁食]]与二甲双胍在AMPK激活路径上高度重叠，且IF无肌肉干扰风险：

| 维度 | 二甲双胍 | 间歇性禁食 |
|------|---------|----------|
| AMPK激活 | 直接（线粒体复合物I抑制） | 间接（能量剥夺） |
| mTOR抑制 | 中等 | 中等 |
| 肌肉干扰 | MASTERS证实负面影响 | TRE 16:8保持肌肉量 |
| 成本 | 极低（$4-15/月） | 零成本 |
| 适用人群 | 代谢风险人群（医生指导） | 胰岛素抵抗/内脏脂肪人群 |
