# 精准预防医学

核心范式转移：从症状出现后的诊断（reactive medicine），转向发病前10-20年的概率预测（predictive precision medicine）。UK Biobank 100,000人全身扫描与500,000人基因组数据是这一转移的基础设施核心。

## Delphi AI：20年疾病预测

基于LLM架构（类ChatGPT技术），从病历记录中学习疾病语言 `[A]`（Nature，2025年9月）：

| 特性 | 数据 |
|-----|------|
| 训练数据 | 400,000+ UK Biobank参与者病历 |
| 预测窗口 | 最长20年前 |
| 疾病覆盖 | 1000+种（含疾病间复杂交互） |
| 跨国验证 | 丹麦190万患者（不同医疗体系）效果近似 |
| 最优预测 | 痴呆、心脏病、血液中毒（进展模式明确） |
| 最弱预测 | 病毒感染、罕见遗传病 |

与现有风险评估工具相比，Delphi仅需性别/年龄/病历（无需血液检测），准确性不逊于要求更多信息的临床工具。关键在于提取已有数据中的正确知识，而非收集更多数据。

## 血液生物标志物早期预测

### 痴呆（15年前预测）
- 4种蛋白质在显现症状前15年即在表观健康人血液中异常升高
- 预测准确率：结合年龄/性别/家族史后达90% `[A]`（Jianfeng Feng等，Warwick大学）
- 目标：开发£10血液检测，替代腰椎穿刺/PET扫描（当前仅2/3痴呆患者获确诊）
- 已有药物能减缓早期阿尔茨海默病进展——早期诊断直接改变治疗结局（[[胶质淋巴系统]]淀粉样蛋白累积是20年过程；血液标志物15年前预测提供最长干预窗口）

### 运动神经元疾病ALS（10年前预测）
- 特定蛋白质组合可在症状前数年至十年检测到ALS生物指纹 `[A]`（Nature Medicine，2025）
- 当前现状：误诊率约40%，平均确诊延迟6-18个月（占患者总生存3-5年的近半）
- 蛋白质签名可区分ALS与其他神经系统疾病，减少不必要手术（目前>10%患者曾误诊手术）
- 研究者Ruth Chia（NIH）：ALS在症状前已进行了长达十年的病理累积——颠覆了"快速起病疾病"的传统认知

## UK Biobank影像基础设施

| 指标 | 数据 |
|-----|------|
| 总参与者 | 500,000人（2003年起，中年志愿者） |
| 全身扫描参与者 | 100,000人（2014-2025年） |
| 每人扫描时长 | 5小时（双MRI + DEXA + 超声） |
| 数据总量 | 30拍字节（30,000TB）已开放共享 |
| 衍生论文 | 17,000+篇同行评审文章 |
| 临床转化案例 | 12个NHS记忆诊所采用UK Biobank脑成像协议 |

关键发现之一：2022年MRI扫描证实即使轻度COVID-19感染也会损伤负责嗅觉的脑区——因为UK Biobank拥有感染前扫描作为基准对照。

## 矛盾与争议

- **Delphi伦理困境**：预测到无法预防/治疗的疾病（如某些癌症），告知患者有何价值？知情权 vs 心理伤害的权衡尚无共识 `[B]`（Alejandro Frangi，曼彻斯特大学明确指出）
- **人群代表性缺口**：UK Biobank参与者以白人欧洲裔为主，Delphi跨种族表现存疑；MND血液测试未在非欧洲背景人群中验证 `[C]`
- **关联性局限**：所有预测模型识别统计相关性，不建立因果机制——高风险预测不等于干预效果可预期
