# 居家心身练习协议

基于心身医学循证技术的自主居家练习脚本化指南。所有练习建议配合**SUDS评分**（主观痛苦程度0-10分）进行效果监测——练习前后打分，量化进步。

## 循证核心技术（金标准）

### CBT 思维记录三步法

**适用**：焦虑、负面自动思维、情绪触发

1. **识别**：画四格表——情境 → 自动思维 → 情绪/躯体反应 → 行为
2. **质疑**：扮演辩护律师，寻找支持/反对自动思维的客观证据
3. **重塑**：写下更理性的替代思维，重评SUDS分数

**ACT变体—树叶漂流法**：想象溪流，每个负面念头写在落叶上随水漂走，注意力回到符合价值观的当下行动。

### EMDR 蝴蝶抱双侧刺激法

**适用**：轻度创伤记忆、即时焦虑  
*注：正式EMDR需专业治疗师引导；此为居家温和版*

1. 双臂胸前交叉，右手放左肩，左手放右肩（蝴蝶姿势）
2. 轻度回想不舒服画面 + 身体紧绷感 + 负面信念
3. 左右手交替有节奏拍打（左-右-左-右，速度如心跳），保持深呼吸
4. 每组15-20次，停下深呼吸，觉察身体变化，重复3-5组

### PMR + 安全岛观想

**适用**：慢性压力、失眠、疼痛、焦虑  
**时长**：15-25分钟，睡前最佳

**PMR阶段（10-15分钟）**：
- 从脚趾开始，吸气蜷缩绷紧（5-10秒），呼气完全放松（10-20秒），注意释放感的温暖与下沉
- 顺序：脚趾→脚踝→小腿→大腿→臀部→腹部→双手→肩膀→咬牙皱眉

**Imagery阶段（5-10分钟）**：
- 在完全放松后构建安全岛（海滩/森林木屋）
- 五感沉浸：**看**云朵飘过，**听**海浪，**触**温暖沙子，**闻**海风
- 漫步5-10分钟，深呼吸后睁眼

### EFT 标准9点敲打法

**适用**：焦虑、情绪强烈时立即使用  
**时长**：每次10-15分钟

1. **确立陈述**：明确最强烈的负面情绪（越具体越好，如"胸口演讲焦虑"）
2. **手刀点设置**：轻敲手掌外侧小指边缘，同时说3遍："即使我有这种[焦虑]，我也深深完全接纳自己"
3. **序列敲打**（每点5-7次，重复提示词）：
   - 眉头 → 眼尾 → 眼下 → 人中 → 唇下 → 锁骨 → 腋下 → 头顶
4. 重评SUDS，若残余情绪将提示词改为"残余的[焦虑]"重复

## 能量与躯体导向技术

### Somatic Experiencing 钟摆练习

**适用**：创伤、慢性压力、神经系统过度激活

1. **定位压力**：扫描身体，找到储存压力的区域，觉察其大小/温度/质地（不评判）
2. **寻找资源**：在身体找到放松/中立区域（如"左手掌温暖"）
3. **钟摆摆动**：在两区域之间移动注意力——紧张区5秒 → 放松区15秒，反复摆动，直到紧张区自动松解

### Bengston RIC 高速愿望清单循环

**适用**：心理赋能、目标导向心理训练  
*证据：动物实验初步，缺乏人体RCT；作为辅助心理训练工具*

1. **列清单**：20-50个完全自私、已实现的愿望场景（第一人称，包含视觉/声音/触觉/情绪）
2. **建立图像**：每天练习，让每个图像像真实记忆般清晰唤起
3. **高速循环**：每个图像1-2秒，不断加速，目标10秒内掠过数十张图像
4. **情绪燃料**：任何强烈情绪（焦虑、兴奋、愤怒）都可作为加速驱动力
5. **心态**：玩乐、漫不经心；不要用力"意念治愈"

## 状态改变技术

### SATS 类睡眠状态（Neville Goddard）

**适用**：目标显化的深度神经可塑性植入  
*机制：利用睡前α/θ脑波状态（hypnagogia）增强暗示性，间接神经科学支持*

1. **截取短场景**（5-15秒）：愿望已实现后的瞬间，第一人称多感官
2. **进入昏沉状态**：睡前深呼吸，身体完全放松，进入半梦半醒漂浮感
3. **GIF式循环**：在昏沉中反复循环短场景，带着"已成真"的满足感，自然入睡

**与Bengston RIC互补**：
- SATS：缓慢、沉浸式，强烈情绪，单场景深度感受
- RIC：极高速、多图像，分散意识，任何情绪作为燃料

### 临床催眠 自我暗示下楼梯法

1. 设定肯定暗示语（现在时：如"我的身体每天都在自然疗愈"）
2. 想象站在10级楼梯顶端，数10→0，每级放松加深一倍
3. 放松状态中重复暗示语5-10遍，从1数到5唤醒

### 双耳节拍 频率对应选择

| 目标 | 频率 | 使用场景 |
|------|------|---------|
| 减压/放松 | α波（8-12Hz） | 白天冥想 |
| 深度冥想/创造力 | θ波（4-8Hz） | 睡前或冥想 |
| 深睡/愈合 | δ波（0.5-4Hz） | 入睡时 |
| 专注/学习 | β波（12-30Hz） | 工作时 |

**必须使用立体声耳机**；癫痫患者及有精神疾病史者禁用。

## 矛盾与争议

**Bengston RIC与SATS**：两者均缺乏严格RCT。RIC的"能量治愈"框架来自动物实验[C]，主要价值在于心理训练和目标priming效应。SATS的有效性通过"感觉是秘密"的显化框架描述，间接对应神经科学的可塑性与暗示性机制。建议作为辅助工具，不替代循证医学治疗。

**Reiki / Healing Touch**：证据质量低至中等，安慰剂效应与放松作用难以剥离 [C]。在医院辅助护理中有应用，但不用于主要医疗干预。
