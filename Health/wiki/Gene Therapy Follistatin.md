# Gene Therapy Follistatin

Bryan Johnson在2023年10月于洪都拉斯Próspera接受的实验性基因疗法，通过增加Follistatin蛋白促进肌肉生长并可能延长寿命。该疗法在美国属非法（未获FDA批准）。

## 生物学机制

- **Follistatin**：一种抑制Myostatin（肌肉生长抑制蛋白）的蛋白质
- **Myostatin**阻断→肌肉生长增加
- 在小鼠研究中：增加Follistatin可延长寿命
- 提供者：Minicircle公司，使用**细菌质粒**（圆形DNA片段）作为载体
- 质粒不整合入基因组，细胞利用其增加Follistatin蛋白产量
- 费用：**25,000美元/次**

## Bryan Johnson报告的结果

- 注射后16天：循环Follistatin增加**160%**
- 6个月后：肌肉质量增加**7%**，体重增加5%（提示净瘦体重增加）
- 声称的生物年龄降低：40岁以下5年，41-60岁7年，61岁以上近15年

## Dr. Matt Kaeberlein的批评（华盛顿大学）

| 批评点 | 详情 |
|-------|------|
| 监管规避 | 在Próspera进行以规避FDA监管，不信任运营商资质 |
| 证据不足 | 缺乏人体长期安全性和有效性证据 |
| 死亡风险 | 认为最终将有人在类似实验中死亡 |
| "关闭开关"的局限 | 四环素可"关闭"但不能100%有效，且不可逆转已发生的损伤 |
| 生物年龄测量的不充分性 | 仅用表观遗传年龄作为单一指标，不足以评估效果 |
| 利益冲突 | "科学不应在YouTube上进行。绝对没有理由信任这些人，他们试图向你出售某样东西" |

## 矛盾与争议

**Johnson声称的好处** vs **Kaeberlein的担忧**：
- Johnson：在人体数据中观察到肌肉增加和生物年龄降低
- Kaeberlein：肌肉增加很可能是预期效果，但长期后果未知；癌症风险未评估；单人n=1数据不具说服力
