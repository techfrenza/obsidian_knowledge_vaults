# Spermidine

亚精胺（Spermidine）是一种多胺（polyamine），通过触发自噬（autophagy）延长多种模式生物寿命，是Bryan Johnson长寿协议中的核心成分之一（每日10mg）。

## 分子生物学

亚精胺是含两个以上伯氨基的多胺。由腐胺（putrescine）合成（putrescine前体为精氨酸），并作为另一种多胺精胺（spermine）的前体。

合成路径：
```
精氨酸 →（精氨酸脱羧酶）→ 胍丁胺 → N-氨甲酰腐胺 → 腐胺 → 亚精胺 → 精胺
```

亚精胺能结合多种类型分子，支持细胞生长、DNA稳定性、细胞增殖和凋亡，功能类似生长因子。

## 食物来源

富含亚精胺的食物：葡萄柚、大豆、全谷物、鹰嘴豆、西兰花、绿茶、麦胚、成熟奶酪、日本榴莲（durian）等。地中海饮食天然富含多胺，可能是"蓝区"长寿现象的部分解释。

## 核心机制：自噬诱导

**亚精胺主要通过触发自噬（autophagy）发挥长寿效应**——自噬分解并回收受损细胞成分（包括功能失调的线粒体）。亚精胺也通过抑制mTOR途径加强自噬（mTOR通常抑制自噬）。

亚精胺缺乏和自噬机制缺陷均与缩短寿命、慢性应激和急性炎症相关。

## 功效领域

### 抗衰老与长寿

| 证据类型 | 结果 |
|---------|------|
| 酵母、线虫、果蝇 | 确认延长寿命 |
| 小鼠（MAP1S介导自噬） | 延长寿命，防止肝纤维化和肝癌 |
| 人类前瞻性队列（奥地利，2018） | 高亚精胺摄入与全因、心血管、癌症死亡率降低相关 |
| 日本队列（2023, N>29,000） | 未发现多胺摄入与全因死亡率的强关联；高亚精胺摄入可能与女性癌症死亡率升高相关 |

**矛盾点**：不同人群研究结论存在分歧，需更多研究。

### 心血管

2016年小鼠研究：亚精胺逆转心脏老化迹象，改善心脏结构和功能，同时恢复线粒体结构和功能。人类数据（2项研究）显示亚精胺摄入降低全因、心脏病和癌症死亡率。

### 认知功能

2021年Cell Reports：膳食亚精胺改善果蝇和小鼠的认知功能和线粒体功能，有少量人类早期数据。需更多剂量-反应数据。

### 肥胖代谢

2024年研究：肥胖小鼠中，亚精胺显著改善脂肪组织产热（促进脂肪燃烧），机制为：触发脂肪细胞自噬 + 增加FGF21生长因子。阻断FGF21则消除亚精胺的减脂效益。

### 抗炎

降低慢性炎症（inflammaging），防止免疫细胞功能障碍和细胞衰老加速。减少慢性炎症是另一个长寿机制。

### 脂质代谢与血压

- 亚精胺是脂肪细胞分化（adipogenesis）必需物质
- 从前脂肪细胞分化为成熟脂肪细胞需要亚精胺
- 腐胺（putrescine）摄入与较低收缩压相关
- 警示：一项绝经后女性研究发现较高亚精胺摄入与较大腰围、较高血压和BMI相关

## 安全性

天然存在于人体和饮食中，现有研究表明补充剂安全且耐受性良好，无已知副作用。

## 矛盾与争议

日本大规模队列（2023）与奥地利前瞻性研究结论相反，提示亚精胺对长寿的影响可能受人群饮食结构、基因背景等因素调节，不可简单推广。
