# 胰岛素抵抗检测

胰岛素抵抗检测是代谢功能障碍的**早期预警系统**。空腹血糖和HbA1c升高时，胰岛素抵抗已沉默累积10-15年；空腹胰岛素与HOMA-IR是更早期的窗口。

## 核心指标对比

| 指标 | 反映内容 | 窗口期 | 局限 |
|------|---------|--------|------|
| 空腹血糖 | 即时血糖水平 | 晚期（疾病已确立） | 受餐食/压力干扰 |
| HbA1c | 3个月平均血糖 | 中晚期 | 红细胞寿命影响准确性 |
| 空腹胰岛素 | 胰腺代偿程度 | **早期**（血糖正常时已升高） | 未纳入常规筛查 |
| HOMA-IR | 胰岛素抵抗综合指数 | 早-中期 | 研究工具为主，临床标准化不足 |

## HOMA-IR 计算与解读

**公式**：空腹胰岛素（μIU/mL）× 空腹血糖（mmol/L）÷ 22.5

| HOMA-IR评分 | 解读 |
|------------|------|
| <1.0 | 胰岛素敏感性良好 |
| 1.0–1.9 | 早期/轻度胰岛素抵抗 |
| 2.0–2.9 | 中度胰岛素抵抗 |
| ≥3.0 | 明显胰岛素抵抗 |

常数22.5来源于1985年原始模型研究，使健康成人基准值趋近1.0。

## 空腹胰岛素：被忽视的早期标志物

**最优值**：<5–6 μIU/mL  
**预警阈值**：>8–10 μIU/mL 提示代谢系统过负荷

空腹胰岛素升高（即使血糖正常）与以下指标关联：
- 内脏脂肪增多
- 甘油三酯升高、HDL下降
- 血压升高
- 炎症标志物上升
- 血管老化加速

### 与激素系统的交互

**男性**：胰岛素抵抗 → 抑制GnRH → 降低LH → 睾酮下降；同时激活脂肪芳香化酶，加速睾酮→雌二醇转化 → 形成自我放大循环。低睾酮+未诊断胰岛素抵抗者，单纯睾酮替代疗效差。

**女性**：胰岛素抵抗 → 扰乱卵巢功能 → 驱动多囊卵巢综合征的雄激素过多；加重围绝经期代谢逆风。

## HbA1c 的最优阈值争议

| 标准 | HbA1c阈值 | 来源 |
|------|---------|------|
| 传统诊断 | ≥6.5% = 糖尿病 | WHO/CDC |
| 标准正常上限 | <5.7% | ADA |
| 功能医学建议 | 4.6–5.3% | 功能医学从业者 |
| Cohen等研究 | 5.5%为更安全上限 | 同行评审研究 |

**极低HbA1c风险**：<4%时全因死亡率统计显著上升，提示HbA1c在人体内有正常生理功能，不应追求极低化。

## 胰岛素抵抗成因

| 因素类型 | 主要机制 |
|---------|---------|
| 内脏脂肪 | 释放炎症信号和脂肪酸，干扰肌肉/肝脏胰岛素响应 |
| 久坐 | 直接降低肌细胞胰岛素敏感性（独立于体重） |
| 精制碳水/添加糖 | 反复血糖波动，胰腺长期超负荷 |
| 睡眠不足 | 5小时/晚持续1周显著降低胰岛素敏感性（RCT证据） |
| 皮质醇过高 | 拮抗胰岛素的细胞作用 |
| 遗传/年龄 | 基础风险增加，但可通过生活方式大幅抵消 |

## 改善策略（证据等级）

| 干预 | 效果 | 起效时间 |
|------|------|---------|
| 阻力训练 | 24–48小时内改善胰岛素敏感性（急性效应） | 即时 |
| 有氧运动（≥150分钟/周） | 结构性改善葡萄糖处置能力 | 数周–数月 |
| 减少精制碳水 | 降低胰岛素需求，细胞敏感性恢复 | 数周 |
| 限时进食 | 改善胰岛素敏感性（无需体重下降，RCT验证） | 数周 |
| 减重5–7% | 糖尿病前期进展为糖尿病风险大幅下降（DPP研究） | 数月 |
| 充足睡眠 | 睡眠本身即代谢干预 | 即时 |

## 矛盾与争议

**HOMA-IR vs TyG指数**：甘油三酯-葡萄糖指数（TyG = 空腹TG × 空腹血糖）在识别代谢综合征上略优于HOMA-IR（NHANES横断面分析）；但两者测量胰岛素抵抗的**不同方面**——HOMA-IR与动脉硬化/早期肾脏变化相关性更强，TyG与大动脉硬度相关性更强，不可互相替代。
