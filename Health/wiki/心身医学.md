# 心身医学

心身医学（Psychosomatic Medicine）研究心理、社会因素与生理健康的双向调节机制。压力、创伤和负面情绪通过**神经-内分泌-免疫轴**转化为躯体症状；相反，身体干预（运动、呼吸、触摸）也能反向调节心理状态。2026年，技术谱系从循证金标准到辅助工具已形成分层体系。

## 核心机制

**认知-行为-情绪三角**：负面思维 → 激活杏仁核 → 应激激素（皮质醇）↑ → 躯体症状。CBT从思维层干预，打断这一循环。

**双侧刺激（EMDR/EFT）**：眼动或穴位敲打干扰工作记忆对创伤图像的保持，降低情绪负荷（去条件化）。

**渐进放松（PMR）**：有意识紧张-放松对比，训练副交感神经系统优势状态；Guided Imagery叠加多感官沉浸，增强神经可塑性。

**α/θ脑波窗口**：入睡前半梦半醒状态（hypnagogia）大脑暗示感受性最高，SATS和临床催眠均利用此窗口植入新信念。

## 整合医学推荐方案

**焦虑/日常压力**：CBT思维记录 + EFT快速降噪 + PMR+Imagery + Alpha双耳节拍（睡前）

**创伤/PTSD**：EMDR（专业指导）+ IFS部分对话 + Somatic Experiencing

**慢性疼痛**：PMR + Guided Imagery愈合意象 + EFT + 生物反馈

**个人成长/显化**：SATS类睡眠状态 + Bengston RIC（辅助心理训练）+ CFT

## 矛盾与争议

**Bengston能量治愈**：动物实验（小鼠癌症治愈率近100%）结果引人注目，但：
- 人体大型RCT缺失，无法形成A级证据 [C]
- "剂量反应"模式和"调理空间"概念无法被主流机制解释
- 研究者建议：作为辅助心理训练（类似目标priming），而非医学干预

**TFT思想场疗法**：EFT前身，部分RCT显示正面结果，但主流观点认为"思想场"能量框架证据不足，争议较大 [E]
