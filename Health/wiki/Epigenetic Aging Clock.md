# Epigenetic Aging Clock

表观遗传衰老时钟通过DNA甲基化模式估算生物年龄，是衰老研究的核心工具。2026年Adiv Johnson和David Sinclair的综述系统分析了41项人体干预研究。

## 第一代 vs 下一代时钟

| 类型 | 训练目标 | 局限性 |
|------|---------|-------|
| 第一代（Horvath 2013, Hannum 2013） | 纯粹预测年代年龄 | 不捕捉生活方式/健康信号 |
| 下一代（2018年起） | 与衰老相关结局关联 | 更响应干预，与全因死亡率更强相关 |

## 主要下一代时钟

- **DNAm PhenoAge**（Levine等，2018）：基于死亡率相关血液蛋白
- **GrimAge/GrimAge2**（Lu等，2019/2022）：蛋白质+代谢物估算
- **DunedinPACE**（Belsky等，2022）：输出衰老速率而非年龄
- **OMICmAge**（Chen等，2026）：多组学整合模型

## 可降低表观遗传年龄的干预（2026综述）

| 干预 | 证据等级 | 时钟影响 |
|------|---------|---------|
| 运动 | 强 | GrimAge显著降低（有氧+抗阻均有效） |
| 植物丰富饮食 | 中等 | 多个时钟改善 |
| GLP-1受体激动剂（司美格鲁肽） | 初步 | 表观遗传年龄降低 |
| 热量限制 | 中等 | 多个时钟改善 |
| 氯胺酮 | 初步（精神疾病适应症） | 降低 |
| Omega-3脂肪酸 | 中等 | 部分时钟改善 |
| 复合维生素矿物质 | 中等 | 降低 |
| 帯状疱疹疫苗 | 初步（2026新研究） | 降低炎症评分，减缓表观遗传老化 |
| 匹伐他汀（降胆固醇药） | 初步 | 降低 |

## 无效或有害干预（重要发现）

| 干预 | 结果 |
|------|------|
| 烟酰胺核糖苷（NR） | **无可检测效果** |
| 雷帕霉素 | **无可检测效果** |
| 抗衰老药（senolytics） | **多个研究无效果** |
| 血浆置换（plasmapheresis） | **加速表观遗传老化** |

## 局限性与注意事项

- 表观遗传年龄变化不等于临床结局改善
- 昼夜节律波动、急性应激可导致时钟暂时变化
- 细胞类型组成影响年龄预测
- 技术噪声可通过主成分分析（PCA）最小化
