## Hooks 草稿（X 传播版）

**Hook 1（反直觉框架）**：
"AI 不替代职位，它替代'能被写成 3 行 JSON 的工作内容'：Role + Input + Output。一个 $150K 的 CFO 里有多少工作能被这 3 行描述？比你想象的多得多。"

**Hook 2（可操作角度）**：
"7 个 Sub-Agent 能替代 $200K 的团队。但更重要的问题是：你自己的工作里，有多少部分可以被写成 Role + Tools + Output Format？审计完你自己，再来说 AI 会不会替代你。"
