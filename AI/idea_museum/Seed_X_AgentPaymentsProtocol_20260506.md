# Seed: AP2 协议与 Agent 法律主体性

**[Concept]** AP2（Agent Payments Protocol）非对称授权证明

**[Hook Insight]**  
大多数讨论 Agent 自主性的文章谈的是"Agent 能做什么"——  
AP2 问的是"Agent 的行为在法律上如何归责"。  
Mandates（授权证明）= 给 Agent 的有限授权书，限定金额、操作范围、时间窗口。  
**Agent 从工具变成可审计经济主体，这是 Web3 之后最被忽视的基础设施问题。**
