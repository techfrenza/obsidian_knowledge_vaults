# xhigh Effort — The Hidden Middle Tier

[Hook Insight]

> "你用 Opus 4.7 但没用 `xhigh`，就像开跑车只用三档。
> 不是模型不够强，是你没有踩到那个档位。"

Effort 层级解码：
```
high   → 日常编码、文档（大多数人默认停在这里）
xhigh  → 编码和 Agent 任务的最佳平衡点（官方默认首选，大多数人不知道）
max    → 极难子问题，成本最高（被滥用）
```

反直觉点：
- 主流用法：high（够用就好）或 max（难题用最强）
- 实际最优：**xhigh 是 Anthropic 为编码类任务设计的 sweet spot**，存在于两者之间

更深的洞见：API 设计者故意加了一个"大多数人不会主动选"的最优层级——这需要你真正读文档，而不是靠直觉。

类比：AWS Reserved Instances 和 On-demand 之间，存在一个大多数人不用但最优的 Savings Plans 层。
