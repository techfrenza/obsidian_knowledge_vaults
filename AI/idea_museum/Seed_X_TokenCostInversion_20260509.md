# Token Cost Inversion

[Hook Insight]

> "你省的每一个 Token，都是你未来要花时间 debug 的一次 Agent 猜测。
> Token 是最便宜的东西，工程师的时间是最贵的东西。
> 你在优化错了变量。"

**Garry Tan 13 年没写代码，靠 Tokenmaxxing 几个月产出几十万行代码。**
他的策略：不省 Token，烧 Token。

反直觉点：
- 主流工程师的直觉：减少 Token = 降低成本 ✓
- 实际情况：减少 Context = 增加 Agent 错误率 = 增加返工时间成本 ✗

公式：**Token 成本 $0.001 << 工程师一小时返工成本 $X**
