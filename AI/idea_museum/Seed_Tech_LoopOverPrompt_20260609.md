# Seed: Loop > Prompt

**Concept**: 同一个模型，聊天框里 60 分，放进设计良好的 Closed Loop 后可达 90 分——模型不变，架构决定上限。

**Hook Insight**: Prompt Engineering 优化起点，Loop Engineering 决定终点。未来顶级 AI 工程师不是最会写 Prompt 的人，而是最会设计反馈循环的人。

**Wiki Link**: [[Loop_Engineering]]

**Draft Hook**: 你花了多少时间优化 Prompt？同一个模型，换个设计良好的 Loop，分数从 60 跳到 90。Boris Cherny（Claude Code 负责人）说：我不再 Prompt Claude，我让 Loops 去 Prompt Claude。Prompt 决定起点，Loop 决定上限——你在优化哪一个？
