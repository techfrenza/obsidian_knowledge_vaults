# Dreaming 的 6 倍完成率不来自模型升级

## Hooks 草稿（X 平台）

草稿 1（数据驱动型）：
Harvey 法律 AI 的 Agent 完成率提升了 6 倍。
不是因为换了更强的模型。
不是因为优化了 Prompt。
是因为他们开启了 Dreaming——让 Agent 每晚回顾历史 Session，把失败经验固化为长期记忆。

你的 AI 比你想象的更健忘。它每次都从零开始。
而解决健忘的方法不是更聪明，是睡觉。

草稿 2（反直觉型）：
工程师逻辑：AI 完成率低 → 换更强模型
Anthropic 逻辑：AI 完成率低 → 让 Agent 学会从失败中记住教训

6x 完成率提升，与模型版本无关，纯粹来自跨 Session 记忆巩固。

你在投资模型升级，竞争对手在投资 Agent 记忆基础设施。
