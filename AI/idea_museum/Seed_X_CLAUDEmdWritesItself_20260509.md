# CLAUDE.md Writes Itself

[Hook Insight]

> "你以为 CLAUDE.md 是你写的文档。
> 错了。
> 它是从你所有的 corrections 里生长出来的。
> 每次你纠正 Claude，它就在暗中为下一个版本的自己立规矩。"

技术机制：
```
你纠正 Claude → correction log → 2 次出现 → 自动 promote 为 Hard Rule → CLAUDE.md 更新
```

类比：**宪法不是被写的，是被判例积累出来的。**

反直觉点：
- 直觉：我在告诉 Claude 怎么做
- 实际：我在给未来的 Claude 立法

这意味着：你对 Claude 的每一次不满，都是一次无成本的"宪法修正案"——如果你有自进化循环的话。
