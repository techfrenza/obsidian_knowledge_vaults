## [Concept]
SKILL.md 里 80% 写"不做什么"，比正面触发更重要。

## [Hook Insight]
反直觉：写 Skill 的本能是告诉 Agent "做什么"——但真正决定 Skill 稳定性的，是"不做什么"的边界。
Reviewer 模式里"替换 checklist.md 切换检查规则"本质上也是负触发：通过限制 Agent 只看 checklist，消除了 Agent 自由发挥的空间。

X 平台钩子：**"最好的 AI 指令不是告诉它能做什么，而是精确告诉它不能做什么。"**
