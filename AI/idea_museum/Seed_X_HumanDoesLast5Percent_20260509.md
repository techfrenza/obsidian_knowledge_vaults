# Human Does the Last 5%

[Hook Insight]

> "你以为 AI 能帮你做 80% 的工作。
> 你想错了方向。
> 真正的问题是：**你能不能把自己缩到只做 5%？**"

Plan-Eng-Review 模式：
```
/plan-eng-review → Agent 展开 10-20 种方案（消耗几万 Token）
                 → Agent 画 ASCII 图分析 pros/cons
                 → Agent 生成代码 + 测试
                 → Agent 自 review + QA

你的工作：选一个方向（vision + taste 判断）≈ 5%
```

反直觉点：
- 直觉：AI 做辅助，人类做决策
- Tokenmaxxing 模式：AI 做勘探 + 执行，人类只做最后的品味判断

更深的洞见：**"品味"是人类最后的护城河，不是知识，不是执行力，是 taste。**
Garry Tan 的 vision + taste 才是他在这个过程中真正不可替代的部分。
