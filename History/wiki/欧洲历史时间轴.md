# 欧洲历史时间轴

## 定位说明

本页为欧洲历史宏观时间线的导航节点，链接各具体专题页面。

## 史前至青铜时代

- **约4.5—4万年前**：克罗马农人入欧，尼安德特人逐渐消亡 → [[尼安德特人与丹尼索瓦人]]
- **约8500年前**：农业革命传入欧洲；身高下降、传染病增加 → [[农业革命与路径依赖]]
- **约4500年前**：[[雅姆纳亚与印欧扩张]] 进入欧洲；[[钟形杯文化]] 传播印欧语与父权制
- **约前1200年**：[[青铜时代崩溃]]，东地中海系统性坍塌

## 古典时代

- **前1600年**：迈锡尼文明兴起 → [[宫殿经济与迈锡尼]]
- **前509年**：罗马共和国成立 → [[罗马：公共美德与战争机器]]
- **前5世纪**：希腊黄金时代 → [[希腊哲学与认知革命]]、[[雅典戏剧与民主机器]]
- **前264—146年**：布匿战争 → [[汉尼拔与迦太基战略]]
- **前27年**：罗马帝国建立

## 中世纪

- **476年**：西罗马灭亡；中世纪开始
- **7—8世纪**：伊斯兰扩张；知识保存传递 → [[伊斯兰黄金时代]]
- **800年**：查理曼帝国；神圣罗马帝国雏形 → [[神圣罗马帝国]]
- **1066年**：诺曼征服英格兰
- **1096—1291年**：十字军东征 → [[中世纪骑士团与跨文化碰撞]]
- **13世纪**：蒙古入侵 → [[蒙古帝国与成吉思汗]]

## 近代早期

- **1348年**：黑死病，欧洲人口减少1/3
- **14—16世纪**：意大利文艺复兴 → [[文艺复兴与新教改革]]
- **1453年**：奥斯曼攻陷君士坦丁堡 → [[拜占庭帝国]]
- **1492年**：西班牙统一、驱逐摩尔人 → [[天主教双王与西班牙统一]]；哥伦布抵达美洲
- **16世纪**：新教改革 → [[新教伦理与资本主义精神]]
- **1517—1648年**：宗教战争，《威斯特伐利亚和约》确立主权国家体系

## 近代

- **17—18世纪**：科学革命 → [[科学革命的范式转移]]；荷兰黄金时代 → [[荷兰黄金时代与中产阶级崛起]]
- **1789年**：法国大革命
- **1815年**：维也纳会议，恢复秩序
- **1848年**：欧洲革命浪潮 → [[1848年革命与欧洲民族主义]]
- **1861年**：意大利统一 → [[意大利统一（Risorgimento）]]
- **1871年**：德意志统一 → [[德意志统一与俾斯麦]]
- **1914—1918年**：第一次世界大战

## 现代

- **1939—1945年**：第二次世界大战 → [[第二次世界大战终战与冷战起源]]
- **战后**：欧洲联合进程
