# 锡安主义与现代以色列建国

## 核心定义

锡安主义（Zionism）：19世纪晚期兴起的犹太民族主义运动，旨在为犹太人在巴勒斯坦建立主权国家，实现民族自决与安全保障。是对欧洲反犹主义（Antisemitism）系统性压迫的政治回应。

## 起源与历史背景

- **宗教根源**：《圣经》时代"上帝应许之地"叙事 + 流散（Diaspora）后对锡安的千年渴望。
- **世俗转化**：欧洲启蒙运动后，犹太人开始以民族国家框架而非纯宗教框架构想回归。
- **催化因素**：1890年代法国德雷福斯事件（反犹偏见即使在"启蒙"国家中也难以消除）→ 赫茨尔受到冲击。

## 关键人物与事件

| 时间 | 事件 |
|------|------|
| 1896 | 赫茨尔出版《犹太国》（Der Judenstaat）：主张建立主权国家是唯一解决"犹太问题"的途径 |
| 1897 | 第一届巴塞尔锡安主义大会；《巴塞尔纲领》：明确目标是在巴勒斯坦建立"由公共法律保障的犹太家园" |
| 1917 | 英国《贝尔福宣言》：支持在巴勒斯坦建立犹太民族家园 |
| 1939—1945 | 大屠杀（Holocaust）：600万犹太人遇难，极大加速了建国迫切性的国际认可 |
| 1948 | 以色列国宣告成立；锡安主义运动的历史高峰 |

## 内部分支

| 分支 | 核心主张 |
|------|---------|
| 政治锡安主义 | 外交路线，建立世俗主权国家（赫茨尔路线） |
| 劳工锡安主义 | 社会主义导向，集体农庄（基布兹）建国 |
| 文化锡安主义 | 希伯来语复兴与犹太文化重建（阿哈德·哈阿姆） |
| 宗教锡安主义 | 建国与弥赛亚救赎相结合 |
| 修正锡安主义 | 强硬民族主义，领土最大化（贝京的意识形态根源） |

## 主要争议

### 锡安主义 vs. 犹太教正统派
- 传统正统派（如纽图雷卡尔塔）认为只有弥赛亚降临才能建立以色列，世俗政治建国是僭越神圣时间表。
- 世俗锡安主义将民族国家框架世俗化，这在神学上与传统宗教期待存在根本张力。

### 基督教锡安主义
- 美国福音派支持以色列（"终末论"动机）：以色列重建被解读为《启示录》末世预言实现的前提。
- 地缘政治后果：美国的以色列支持政策深受宗教选民影响，参见[[锡安主义与基督教锡安主义]]。

### 巴以冲突框架
- 锡安主义视角：犹太人对受迫害群体实现民族自决的正当权利。
- 巴勒斯坦视角：殖民定居者行为，导致原住民流离失所（纳克巴/Nakba，1948年）。
- 参见[[矛盾与争议]]章节。

## 矛盾与争议

- 锡安主义是民族解放运动还是殖民主义？两种叙事框架在当代中东冲突中各有其政治动员功能，均有历史事实支撑。
- 以色列内部也存在世俗建国理念与宗教版图主张的持续张力。
