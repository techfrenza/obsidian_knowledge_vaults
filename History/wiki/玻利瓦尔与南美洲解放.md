# 玻利瓦尔与南美洲解放

## 核心定义

西蒙·玻利瓦尔（Simón Bolívar，1783—1830）是南美洲独立运动的核心军事与政治领袖，领导委内瑞拉、哥伦比亚、厄瓜多尔、秘鲁、玻利维亚五国独立（1810—1825），被尊为"解放者"（El Libertador）。

## 历史背景

- **殖民体系危机**：拿破仑1808年入侵西班牙，废黜波旁王朝，导致殖民地与宗主国合法性联系断裂，为独立运动提供政治窗口。
- **启蒙思想影响**：玻利瓦尔受卢梭、孟德斯鸠影响，也亲历法国大革命。但他对纯粹民主持怀疑态度，认为南美社会条件需要强力中央政府。
- **海地革命示范**：1804年海地独立（前身：法属圣多明各奴隶起义）是首个成功的拉丁美洲独立案例，但也引发精英阶层对"黑人革命"的恐惧。

## 军事历程

| 阶段 | 事件 |
|------|------|
| 1810—1812 | 委内瑞拉第一、第二共和国，均失败 |
| 1813 | 《战争通告》，开始"殊死战争"（guerra a muerte） |
| 1819 | 跨越安第斯山脉奇袭，博亚卡战役胜利，哥伦比亚独立 |
| 1821 | 卡拉沃波战役，委内瑞拉完全独立 |
| 1822 | 皮欣查战役，厄瓜多尔独立；与圣马丁会面于瓜亚基尔 |
| 1824 | 胡宁和阿亚库乔战役，秘鲁西班牙势力被消灭 |
| 1825 | 上秘鲁以玻利瓦尔命名为"玻利维亚" |

## 政治理念与失败的大哥伦比亚

- **大哥伦比亚联邦**：玻利瓦尔的理想是建立统一的南美联邦，但各地精英的地方利益和种族张力使之分裂（1830年解体）。
- **终身总统制度**：玻利瓦尔在玻利维亚宪法中设计终身总统职位，被批评者视为独裁倾向，激化了分裂。
- **晚年幻灭**：1830年病逝前叹言："美洲不可治理……犁海是徒劳。"

## 历史动力学分析

- **精英叛乱模式**：克里奥尔精英（美洲出生的西班牙裔）领导解放运动，主要动机是摆脱西班牙商业管制与税收，而非社会平等改革。
- **革命与制度的张力**：军事胜利未能转化为稳定制度，导致19世纪南美陷入"考迪罗主义"（caudillismo）——军阀强人循环统治。
- **外部支撑**：英国（海军保护、金融借贷）和海地（提供武器和物资）的支持对独立成功至关重要。

## 核心洞察

> 玻利瓦尔揭示了"解放者悖论"：军事领袖赢得独立，却无法建构持久制度。南美独立国家继承了殖民地的精英结构和土地分配不平等，仅替换了宗主国的远程控制为本地精英的直接统治。
