# Seed: AI幻觉防范悖论 — 越强大的模型越危险

## 核心权衡

在未解密文字/残缺历史证据的研究场景中，**模型能力越强（生成式LLM），其"置信度幻觉"风险越高；越弱但更透明的统计模型反而是更安全的工具。**

这是一个违反直觉的"能力-可靠性倒置"。

## 机制

```
生成式LLM（GPT/Claude级）：
  - 能力强：可以流畅"翻译"任何未知文字
  - 风险：模型无法区分"真正解码"与"合理编造"
  - 置信度表现：均高，无法从输出区分真假
  → 幻觉翻译风险极高

非生成式统计模型：
  - 能力弱：只输出概率分布、关联矩阵
  - 风险低：不"生成"意义，只呈现统计结构
  - 置信度表现：低值=未解决，高值=有结构依据
  → 假阳性率可测量
```

## 实证来源

Linear A（迄今未解密的米诺斯文字）破译尝试中，研究者明确选择：
1. **非生成式模型优先**：图优化、聚类、概率比对
2. **人类专家监督（HITL）**：AI生成音值假设 → 语言学家交叉审查 → 考古出土语境匹配
3. AI定位是**"假设生成器"**，而非翻译机

相比之下，多个团队使用GPT系模型的"Linear A翻译"实验，产生了看似合理但无法验证的输出，严重污染了学术讨论。

## 一般化规律

**在证据稀疏、真值不可知的领域，模型越强大越危险。** 能力是工具的优点还是缺点，取决于任务的可验证性：

| 任务类型 | 可验证性 | 推荐模型 |
|---|---|---|
| 文档摘要 | 高（原文在） | 生成式LLM |
| 图像识别 | 高（标注可比对） | 深度学习 |
| 未解密文字 | 低（无ground truth） | 统计+专家HITL |
| 历史归因 | 极低 | 专家主导，AI辅助 |

## 当代延伸

同样的悖论在AI辅助医疗诊断中正在浮现：GPT-4在模糊症状描述上的"诊断"比专科医生更"自信"，但其置信度与准确率的相关性远低于专科医生。
