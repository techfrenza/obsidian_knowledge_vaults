# Seed: "文明盛世"的400–600年自然时钟——复杂性建设与系统僵化的必然周期

## 核心洞察

[[LiDAR与人类代理人理论]]中引用 Joseph Tainter 的模式发现：人类历史上几乎所有成功的复杂文明，其从"建立共识"到"系统僵化"的**盛世期**均集中在 **400–600年**的时间窗口内。

这可能不是巧合，而是一个**社会复杂性建设速度与知识传承半衰期之间的结构性约束**。

## 机制推演

```
Phase 1 (0–150年): 共识建立期
  → 挑战驱动创新，文化凝聚力强，核心知识广泛分布

Phase 2 (150–350年): 繁荣期
  → 分工深化，专业化加速，人口峰值

Phase 3 (350–500年): 僵化期
  → 核心知识向少数精英集中（"知识特权化"）
  → 寻租行为替代生产行为
  → 精英过剩开始

Phase 4 (500–600年): 崩溃触发窗口
  → 任意外部冲击（气候/战争/疫病）消灭关键1%知识精英
  → 剩余99%无法维护复杂系统 → 快速降级
```

## 权衡

- **复杂性增加 → 效率提升，但脆弱性指数上升**
- **专业化越深 → 生产力越高，但知识继承路径越窄**
- 这是一个无法从内部解决的悖论：成功本身产生终结种子

## 与现代的对应

美国作为主导文明体系的建立（二战后，约1945年）：2026年已进入第81年。按400年周期，尚处Phase 2中期——但AI驱动的知识"黑盒化"（只有少数人理解底层原理）可能**压缩这一周期**。
