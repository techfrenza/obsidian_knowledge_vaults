# Seed: 人类活动使森林更茂盛（Anthropogenic Forest Enhancement）

## 核心洞察

**亚马逊"原始森林"里很多地方其实是人造的——而且比"真正的原始森林"更繁茂。**

Terra Preta（亚马逊黑土）区域的树木生长速度是周边未经人工处理土壤的**6倍**。这是刻意工程的结果，不是副产品：前哥伦布时期亚马逊居民通过混合木炭、骨粉与有机废物，将贫瘠红壤（oxisol）转化为永久高产碳汇，可持续耕作数百年。

## 权衡结构

| 传统"文明 vs. 自然"框架 | Terra Preta实证 |
|---|---|
| 人类定居 → 砍伐 → 退化 | 人类定居 → Terra Preta → 生物多样性↑ |
| 密度增加 → 资源耗尽 | 低密度布局 + 生态整合 → 高承载力 |
| 集权治理 → 大规模资源提取 | 分布式治理 → 可持续分散开发 |

## 技术洞察

**核心权衡**：Terra Preta的成立条件是**低密度城市主义 + 分布式治理**。一旦聚落密度超过临界点（集权化），这种生态增强模式会失效——因为中央化资源提取会破坏精心维护的土壤碳汇系统。

这揭示了一个反工业文明的设计原则：**人类干预可以是净生态正向的**，但前提是治理架构匹配生态尺度（分散而非集中）。这与现代"再野化"（rewilding）思路的本质差异是：前者是积极管理，后者是撤退管理。

## 延伸问题

- Terra Preta技术能否规模化应用于当代热带农业？阻碍是技术还是治理架构？
- 现代气候政策讨论中，是否系统性低估了"积极生态管理"相对于"保护性撤退"的价值？
