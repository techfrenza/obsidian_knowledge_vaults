## 技术核心逻辑

[[预测边界论]] §反证M-2记录了这一机制：

```
预测成功 → "系统有效的证据"
预测失败 → "概率性，本来就不保证"
         → 可归因于"诚心不足"
         → 可归因于"参数错误"
         → 可归因于"共业压制"
```

**波普尔可证伪性标准要求**：一个声称有预测能力的系统，必须能提前说明——在何种条件下，其预测将被证伪。玄学系统几乎从不提前设定失败标准。

## 对比

| 系统类型 | 失败机制 | 可证伪性 |
|---------|---------|---------|
| 现代天气预报 | 公布准确率统计，有可对比基线 | 有 |
| 医学临床试验 | 预设零假设，p<0.05才接受 | 有 |
| 玄学预测 | 失败可被任意归因吸收 | 无 |
| 太乙神数 | 全为回溯诠释，无前瞻数据 | 事实上无 |

**注意**：这不是说玄学没有价值——[[预测边界论]]明确指出其在认知框架、心理投射、意义建构上有真实价值。问题在于：用"科学语言"为不可证伪的系统背书，是认识论混淆。
