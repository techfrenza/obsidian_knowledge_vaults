**Concept**: 邵子神数 is a pre-filled lookup table disguised as divination — it provides definitive answers for any input combination, almost always favorable.

**Hook Insight**: The "神数" (divine numbers) system is not actually divining your fate dynamically — it is a pre-authored encyclopedia that assigns poetic verses to every possible combination of birth data. The same parent zodiac combination produces different results just by changing the "刻数" (quarter-hour of birth). The system can theoretically cover any input and produce "great fortune" — making it structurally unfalsifiable.
