# 增删卜易

清代野鹤老人所著，影响深远的六爻占卜经典。以近五百个真实卦例为核心，化繁就简，强调用神旺衰为断卦根本。

## 核心创新

- **删繁就简**：删除"卦身"、"世身"、"星煞"、"本命"等干扰因素
- **用神为本**：所占之事的代表爻（用神）的旺衰、刑冲克害是断卦关键
- **四处影响力**：月建（月将）、日辰、卦中动爻、变爻——四处生克冲合决定吉凶
- **多占法**：若一卦意向模糊，可次日再占或由亲人代占，数卦合参（打破"再三渎"禁忌）

## 关键概念

| 概念 | 规则 |
|------|------|
| 旬空（空亡） | 旺相或发动之爻虽空不为空（"动不为空"）；休囚无气之爻逢空才是真空 |
| 月破 | 月建冲之为月破；动而逢破或变而逢破，在实破之日依然能显现祸福 |
| 进神 | 爻动化同类（寅化卯为进），象征事业渐进、家道渐丰 |
| 退神 | 象征渐渐凋零、有始无终 |
| 六冲变六合 | 散而复聚，先难后易，极佳吉兆 |
| 六合变六冲 | 先合后离，始吉终凶 |

## 分类占断要点

| 类型 | 核心爻 | 关键规则 |
|------|--------|---------|
| 求名 | 官鬼爻+父母爻 | 旺官持世或生世为吉；忌子孙爻发动（克官） |
| 求财 | 妻财爻+子孙爻 | 财爻生世/持世/克世皆吉；忌兄弟爻劫财 |
| 近病 | 用神 | 逢旬空、化空或六冲往往不药而愈 |
| 久病 | 用神 | 遇空破六冲或随鬼入墓多为不治 |

## 修行心态

- **至诚感神**：占卜必须至诚，不可心怀二念
- **趋吉避凶的实务**：凶灾非完全不可避——知险后可时空上采取避让（"克在内宜于外避"）
