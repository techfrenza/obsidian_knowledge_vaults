# 大六壬

"三式"（[[太乙神数]]、[[奇门遁甲]]、[[大六壬]]）之一，以天干地支、十二神将与四课三传为核心工具，用于具体事务（出行、婚姻、天气、诉讼）的实时占断。《四库全书》著录为"六壬大全"，列术数类四。

## 系统架构

| 层次 | 组成 | 说明 |
|------|------|------|
| 天地盘 | 天盘（旋转）+ 地盘（固定十二支） | 两盘叠合确定神将位置 |
| 四课 | 由日干、日支推导 | 分上下、克贼，确定初传 |
| 三传 | 初传→中传→末传 | 代表事件的起、中、终 |
| 十二神 | 登明、河魁、从魁…… | 各司其职，与五行方位对应 |
| 十二将 | 天一贵人、螣蛇、朱雀…… | 吉凶将加临判断得失 |

## 四课取法（入手法）

| 法 | 条件 | 说明 |
|----|------|------|
| 贼克法 | 下克上为"重审"，上克下为"元首" | 最基础的取发用法 |
| 比用法 | 多克取阳日用阳、阴日用阴 | 同性相比 |
| 涉害法 | 路上多克者为用 | 孟深仲浅季休 |
| 遥克法 | 无克时取神遥克日 | 蒿矢/弹射 |
| 昴星法 | 无遥无克，阳仰阴俯取酉 | 极端情况备用 |
| 别责法 | 四课不全三课备 | 刚日乾合，柔日支前三合 |
| 八专法 | 两课无克 | 阳顺阴逆 |
| 伏吟/返吟法 | 天地盘相重/相冲 | 特殊课体 |

## 十二神（月将）系统

十二神即十二支神，依太阳躔度（月将）逆布天盘：

| 支 | 神名 | 五行 | 对应月将 |
|----|------|------|---------|
| 亥 | 登明 | 水 | 正月将 |
| 戌 | 河魁 | 土 | 二月将 |
| 酉 | 从魁 | 金 | 三月将 |
| 申 | 传送 | 金 | 四月将 |
| 未 | 小吉 | 土 | 五月将 |
| 午 | 胜光 | 火 | 六月将 |
| 巳 | 太乙 | 火 | 七月将 |
| 辰 | 天罡 | 土 | 八月将 |
| 卯 | 太冲 | 木 | 九月将 |
| 寅 | 功曹 | 木 | 十月将 |
| 丑 | 大吉 | 土 | 十一月将 |
| 子 | 神后 | 水 | 十二月将 |

## 与三式的定位比较

| 体系 | 定位 | 时间尺度 | 应用场景 |
|------|------|---------|---------|
| [[太乙神数]] | 天，宏观国运 | 年/历史周期 | 朝代兴衰、战争 |
| [[奇门遁甲]] | 地，战略布局 | 日/时 | 军事部署、择时 |
| 大六壬 | 人，具体事务 | 时/刻 | 婚姻、出行、诉讼 |

## 思想根源

《四库全书》序言指出六壬渊源：
- 数根于五行，五行始于水，"举阴以起阳，故称壬；举成以该生，故用六"
- 由干支→四课，类比两仪四象；由发用→三传，类比一生二、二生三
- 六十四课皆原本羲爻，是"易象之支流推而衍之者"

## 矛盾与争议

- 天乙贵人阴阳顺逆：曹震圭主"昼丑夜未"，《四库》依圣祖《星历考原》纠正此讹
- 十二宫分野说多有拘牵旧说，《六壬大全》沿用而注附订正
