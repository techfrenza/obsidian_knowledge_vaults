# 子平真詮

清代沈孝瞻（字燡燔，乾隆己未进士）所著子平命理专著，共三十九篇。评注者章君安（字君安）整理刊行，序言由胡焜（字倬空甫）撰写于乾隆四十一年（1776年）。被誉为子平命理的"真诠"（即真正的诠释）。

## 著作背景

| 项目 | 内容 |
|------|------|
| 原著 | 沈孝瞻（山阴人，乾隆进士） |
| 评注 | 章君安 |
| 刊行 | 宣平沈明府署 |
| 篇目 | 39篇（手录形式） |
| 地位 | 被公认为子平命理理论化、体系化的最高水平著作 |

## 核心理论贡献

| 贡献 | 内容 |
|------|------|
| 用神中心论 | 一切分析围绕用神展开，而非神煞 |
| 月令主导 | 月令决定用神，是格局的基础 |
| 透藏论 | 天干透出 > 地支藏，透清者格局高 |
| 四吉四凶可互换 | 官财印食是吉神，但可破格；杀伤枭劫是凶神，但可成格 |
| 有情无情之辩 | 生克之间是否"有情"决定格局成败 |

## 天干阴阳论（核心段落）

沈孝瞻对甲乙的界定：
- 甲为木之气（在天流行），乙为木之质（在地承载）
- 庚为秋天肃杀之气，辛为人间五金之质
- 因此：甲以庚为官（气对气），乙以庚为杀（质对气）

此"气质分阴阳"论是其最重要的原创理论。
