# 三命通会

明代万民英（号育吾山人）所著，十二卷，收录于《四库全书》。历代子平八字命理学的**集大成之作**，体系严密，例证丰富，自明代以来谈星命者几乎"家有其书"。

## 哲学基础

- **天人合一**："天垂象，示吉凶"，"虽天道玄远，亦不外人事"
- **五行中和**：五行太过则损，不及则亏；"金赖土生，土多金埋"——强调平衡而非极端

## 断命核心方法

| 要素 | 规则 |
|------|------|
| 日干为主 | 以日干（日主）代表己身，是论命核心 |
| 月令为本 | 月令（提纲）决定格局清浊贵贱，是最重要的分析节点 |
| 四柱分工 | 年（太岁，根基）、月（行运起点，用神来源）、日（帝皇之象）、时（近侍之臣） |

## 六格（十神）体系

| 十神 | 关键特征 |
|------|---------|
| 官星（正官） | 禄也，宜健旺清高，忌冲刑破害；重见则作煞论 |
| 财星 | 马也，养命之源，喜藏不喜露；财官讲"旺"不讲"多" |
| 印绶 | 生我者，如父母之荫，主聪明智慧，畏财破印 |
| 食神 | 寿星，能制煞生财，忌枭神（偏印）夺食 |
| 七煞（偏官） | 克我之物，有制为权，无制为鬼；煞刃俱全主大权大贵 |
| 伤官 | 我生者，伤官见官祸患百端；伤尽方作贵 |

## 重要格局

- **魁罡格**：庚辰、壬辰、戊戌、庚戌四日，叠化重逢者发福非常，忌见财官
- **弃命从煞**：煞神太重、日主无依时，喜行煞旺及财乡
- **财官双美**：壬午、癸巳日自坐财官，主富贵双全

## 运势理论

- **大运**：司十年之休咎，重地支
- **流年（太岁）**：一年之主宰
- **反吟伏吟**：岁运与日柱相对（反吟）或相同（伏吟），多主不利六亲或破财
