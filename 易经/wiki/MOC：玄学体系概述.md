# 玄学体系概述

中国传统玄学体系的**四大支柱**：易经解卦、生辰八字命理、占卜和风水。共同构成宇宙认知模型与人生命运解析系统，历经数千年发展。

## 四大支柱

| 支柱 | 侧重 | 核心概念 |
|------|------|---------|
| [[周易核心三义]] / 易经解卦 | 宇宙变化规律，决策指引 | 阴阳、[[六十四卦]]、卦爻辞、承乘比应 |
| 生辰八字命理（[[子平法]]、[[紫微斗数]]） | 个体先天命格与运势轨迹 | 四柱、五行、[[十神定位]]、星曜飞化 |
| 占卜体系（术数决策） | 具体事务短期预测与决策 | [[纳甲法]]六爻、[[梅花易数]]、**三式**（[[奇门遁甲]]/[[大六壬]]/[[太乙神数]]） |
| 堪舆风水 | 空间环境与人居气场和谐 | 峦头（形势）、理气（数理）、[[九星翻卦法]] |

## 占卜体系分类

### 基于易经的方法（易占）
- **易经解卦**：卦辞、爻辞综合分析，象数理占
- **[[梅花易数]]**：数字、时间、声音或外应起卦，感应研判
- **[[高岛易断]]**：至诚无息，不离经文，直解卦爻辞

### 五大神数（高阶术数）
| 神数 | 侧重 |
|------|------|
| [[太乙神数]] | 宏观国运、战争、重大灾害（三式之首） |
| [[奇门遁甲]] | 战略布局、时空决策（帝王之术） |
| [[大六壬]] | 具体事务（出行、婚姻、天气）人事分析极细腻 |
| [[紫微斗数]] | 个人长期命运轨迹与性格倾向 |
| [[邵子神数]] | 个体命运精算，六亲细节（6144条诗文） |

## MECE三域拆解（功能分工）

| 域 | 定位 | 代表系统 |
|----|------|---------|
| **命理域（静态）** | 先天禀赋与长期轨迹 | [[子平法]]、[[紫微斗数]]、[[邵子神数]] |
| **占卜域（动态）** | 具体特定事务短期预测 | [[纳甲法]]六爻、[[梅花易数]]、三式 |
| **堪舆域（空间）** | 优化物理环境气流 | 峦头形势、[[九星翻卦法]]、[[罗盘]]、[[玄空风水]] |

## 底层运作机制（第一性原理）

1. **阴阳五行动能系统**：宇宙万物产生与变化来自固有的阴阳对立统一性
2. **时空信息编码（象数理）**：将复杂现实抽象为卦象（符号）、数（量化）、理（规律）
3. **共时性与全息关联**：部分包含整体全部信息；通过当下偶然现象感应整体运行状态

- 八字五行与职业选择存在弱相关性（r=0.21，p<0.05），统计学显著但效应量小（解释方差仅4.4%）
- 预测属概率性参考模型，不提供100%绝对必然性；但此框架存在无法证伪的防御风险
- 不替代人的主观能动性：易经强调"人谋鬼谋"
