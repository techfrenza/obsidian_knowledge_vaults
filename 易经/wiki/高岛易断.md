# 高岛易断

日本明治维新时期易学大师**高岛嘉右卫门**（号吞象）所创立的易学占断体系。以"至诚通神"为核心，以卦爻辞直解为方法，是近代日本易学的集大成著作。

## 核心理念

| 理念 | 内容 |
|------|------|
| 至诚通神 | 人若忘失"至诚通神之道"，神人隔绝；占卜核心在于消除杂念、屏息凝气 |
| 至诚无息 | 揲蓍瞬间停止呼吸、心无杂念，使占卜结果"无不应验如神" |
| 简化筮法 | 推崇"中筮法/略筮法"，认为简化更容易进入至诚无息状态 |
| 卦爻辞优先 | 基本上只重视卦辞爻辞，不侧重变卦和卦象推演，认为文字即神明直接启示 |

## 作者生平

- 自幼熟读儒家经典，因入狱研读《易经》残卷而精通易学
- 出狱后通过商业活动实践易学，将所得财富捐献社会公益（铁路、街灯）
- 应用范围：个人命运、婚姻、健康、营商、功名，至国家气运、战征、外交
- 明治二十七年预测中日甲午战争，占得"乾之小畜"（结果与史实不符）

## 占断方法

1. **简化起卦**：使用三枚铜钱或竹签，通过默祷直接抽取动爻
2. **本卦优先**：侧重本卦卦象与爻辞直解
3. **至诚为要**：占卜者平日应静坐禅修提升精神境界

## 与荣格心理学的关联

荣格"共时性"原理（Synchronicity）为"至诚通神"提供了现代心理学诠释：占卦所得卦象与提问者心理处境之间并非偶然，而是潜意识与外部事件的有意义巧合。见[[荣格共时性]]。
