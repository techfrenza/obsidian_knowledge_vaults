# 六壬大全

清乾隆《四库全书》著录的大六壬集成著作，共十二卷，撰人不详，卷首题"怀庆府推官郭载骋校"，为明代所刊。是现存最完整的[[大六壬]]文献总汇。

## 基本信息

| 项目 | 内容 |
|------|------|
| 卷数 | 12卷 |
| 校订 | 怀庆府推官郭载骋 |
| 收录 | 乾隆四十六年，纪昀、陆锡熊等总纂 |
| 性质 | 六壬诸书遗文汇编，"博综简括，固六壬家之总汇" |

## 内容结构（十二卷）

| 卷次 | 主题 |
|------|------|
| 卷一 | 起例（入手法、十干寄宫、八专伏吟等基础法） |
| 卷二 | 神将释（十二神详解，含象征、主事、类神） |
| 卷三~五 | 四课三传技法 |
| 卷六~七 | 各类占问（婚姻、出行、诉讼等） |
| 卷八~十 | 专题占断 |
| 卷十一~十二 | 附录（课体汇考，终） |

## 《四库》纠正的错误

1. **天乙贵人问题**：沿用曹震圭"昼丑夜未"之说；《四库》依《星历考原》附订订正
2. **十二宫分野**：多拘牵旧说，未能订正，注明"姑仍其旧录之"
