# 格局

[[子平法]]中以月令（出生月份地支）为核心，判断一人能力倾向与社会成就层级的分析框架，是[[十神定位]]之上的更高层次。

## 主要格局类型

| 格局 | 月令/用神 | 代表能力倾向 |
|------|----------|------------|
| **正官格** | 月令正官 | 体制内任职、规范管理 |
| **财格** | 月令财星（正/偏） | 经商、财务管理 |
| **印格** | 月令印星（正/偏） | 学术、教育、文化 |
| **食神格** | 月令食神 | 技艺、创作、服务业 |
| **伤官格** | 月令伤官 | 艺术、技术、批判性工作 |
| **七杀格** | 月令七杀 | 军事、竞争性行业（制杀则显权） |
| **特殊格局** | 从旺/从强/一行得气等 | 极端命造，论法不同 |

## 格局与[[十神定位]]的关系

- 十神定位：揭示性格与六亲关系（"命的道理"的基础层）
- 格局：揭示个人在社会中的能力定位与职业倾向（"命的道理"的中层）
- 喜忌用神：在格局基础上进一步分析趋吉避凶（最高层，也最复杂）

梁湘润强调：大多数普通人只需看财官格局即可，不必过度深入喜忌分析。

## 格局续论（《梁湘润传承班笔记》）

- **日主喜忌再谈**：甲至癸十天干各有不同的格局偏好与忌神
- **生旺库**：格局强弱需结合生旺库（临官、帝旺、墓）判断
- **财官互看**：财滋杀/印化杀/食制杀，格局间有复杂的制化关系
