# 断易天机

成书于明万历丁酉（1597年）的卜筮秘藏典籍，集中国古代易学大师、卜筮名家权威著述于一书，1993年由辽宁大学出版社整理注译出版。

## 基本信息

| 项目 | 内容 |
|------|------|
| 原著年代 | 明万历丁酉（1597年） |
| 注译者 | 汤梓顺、韩铭生（1993年版） |
| 整理者 | 虎易（电子版校订） |
| 出版 | 辽宁大学出版社，1993年4月第一版 |

## 内容特色

1. **集成性**：收录周文王、姜子牙、鬼谷子、孙膑、张良、京房、诸葛亮、郭璞、李淳风、李虚中、袁天纲、[[wiki/邵雍]]等卜筮大师专题论文。
2. **体系完整**：从入门基础（八卦正象、纳支法、六亲定义）到提高专论，易理与卜筮有机结合。
3. **历史案例**：384条爻辞均附历史人物真实占断案例（吕后谋汉、蔺相如送璧、诸葛亮讨南蛮等）。
4. **之卦断法**：明确提出由之卦断死生、断过去/未来十五年——为《卜筮正宗》《增删卜易》所不具备的独特方法。
5. **韵文行文**：朗朗上口，便于记忆。

## 技术体系

- [[纳甲法]]：纳支（六十甲子纳音）、安世应法、六神配置
- [[六亲体系]]：官鬼、父母、妻财、兄弟、子孙五类
- [[六神]]：青龙、朱雀、勾陈、螣蛇、白虎、玄武配爻

## 示例：山风蛊卦（晋侯疾病案）

- 上卦艮（山）=少男，下卦巽（风）=长女 → 女惑男之象
- 官鬼酉金持世（病爻），妻财两现（一男两女），土生金 → 断为贪色过度
