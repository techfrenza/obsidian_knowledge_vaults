# 麻衣神相

北宋陈抟所撰的系统相术著作，约成书于元末明初大量刊印。是中国古代对人体相貌进行系统叙论的代表性典籍。

## 基本信息

| 项目 | 内容 |
|-----|------|
| 撰者 | 陈抟（北宋李和之弟子，河南南阳内乡人） |
| 性质 | 相术（观察面相、体态以判断人生吉凶） |
| 理论基础 | 人面本前世道德所表，知其像则懂人生吉凶祸福 |

## 核心体系：十三部位

面部被划分为十三个部位区域，各对应不同的人生领域：

| 部位顺序 | 位置 | 代表领域 |
|---------|-----|---------|
| 第一（天中/天岳） | 额头最高处 | 早年运势 |
| 第二（天庭/日角） | 额正中 | 早中年命运 |
| 第五（印堂） | 两眉间 | 命宫（学问、寿命）|
| 第六（山根） | 鼻根 | 中年 |
| 第九（准头） | 鼻尖 | 财运 |
| 第十（人中） | 鼻下凹槽 | 人口与仆从 |
| 第十二（承浆） | 下唇下 | 晚年/田宅 |
| 第十三（地阁） | 下巴 | 老年运势 |

## 流年运气

以面部特定部位对应人生年龄段（流年法）：

- 1—14岁：耳轮至天轮
- 15岁：火星（额正中）
- 16岁：天中
- 三五岁一部位，依次推进至百岁
- **男左女右**原则贯穿全部流年判断

## 十二宫体系

| 宫位 | 面部位置 | 判断内容 |
|-----|--------|---------|
| 命宫 | 印堂（两眉间） | 寿命、学问、总体命运 |
| 财帛宫 | 鼻（准头+兰台） | 财富多寡 |
| 兄弟宫 | 两眉 | 兄弟关系与数量 |
| 田宅宫 | 两眼 | 房产与家业 |
| 男女宫 | 眼下（泪堂） | 子女状况 |
| 奴仆宫 | 地阁 | 下属与仆人 |

## 气色动态判断

仅静态部位不足，气色变化同样重要：

| 气色 | 含义 |
|-----|------|
| 红黄 | 喜庆、财禄进益 |
| 青 | 官非、口舌是非 |
| 黑 | 病厄、死亡之兆 |
| 白 | 丁忧（丧事） |

## 相术哲学

"人的命运不是生而定终身，但能从长相上侦破命运的某种密码"——强调面相是**概率线索**而非绝对宿命，与[[预测边界论]]的框架相通。
