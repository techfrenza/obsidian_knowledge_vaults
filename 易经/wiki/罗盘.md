# 罗盘

堪舆（风水）的核心实操工具，又称"罗经"，源自"指南车（司南）"，历经5000年演变。综合地磁子午线、二十四山方位、八卦五行、干支甲子、天文历法等多层系统，是"包罗万象、作经纬天地之妙用"的复合测量仪器。

## 基本结构

| 部件 | 说明 |
|------|------|
| 外盘（底盘） | 方形，代表"地"；固定内盘 |
| 内盘（盘面） | 圆形可转动，代表"天"；各层知识刻于其上 |
| 天池 | 中心指南针所在；底盘标有东南西北十字红线 |
| 天心十道 | 两条垂直相交红线，覆盖方位读数 |

> 天圆地方：外盘方形代地，内盘圆形代天。

## 种类

| 类型 | 用途 |
|------|------|
| 三合盘（杨公盘） | 三合派、八宅派专用；含三针（正针/中针/缝针） |
| 三元盘（蒋盘/太易盘） | 玄空派、飞星派专用 |
| 综合盘 | 兼具两种特征 |

## 实战使用要领

1. **确定坐向**：站在大门外约7步处，面对大门量度
2. **立极**：寻找建筑物中心点（正方形取对角线交点）
3. **定向**：调天心十道与山向对齐，旋内盘使磁针对准天池南北线
4. **八宫放射**：从中宫立极点向八方放射线，测各宫方位

**注意**：现代钢筋建筑干扰磁场，可用军用罗盘在建筑物外10米处定向后校正。

## 关键原则

- **层数越低（楼层越低）风水越好**：地气影响力随高度递减，地铺最强
- **到山到向（八运2004-2023）**：乾巽、丑未、巳亥六种山向大旺丁财
- **上山下水**：与"到山到向"相反，坤艮、寅申、辰戌六种山向为大凶

## 罗盘辟邪说

民间认为罗盘集五行八卦、时空代表于一盘，可平衡五行；灵界惧怕时间观念的提醒，故见罗盘而避。
