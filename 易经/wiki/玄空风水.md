# 玄空风水

以"飞星盘"为核心工具，结合元运（九运）分析住宅与地形气场吉凶的风水体系。代表著作为清代沈竹礽《沈氏玄空学》，其中"阳宅三十则"是阳宅实操核心纲领。

## 基本框架

| 概念 | 内容 |
|------|------|
| 元运 | 以60年为一元，三元九运，每运20年 |
| 飞星盘 | 将九宫飞星（一白至九紫）按起造年份与山向排布 |
| 山星 | 坐山飞星，主丁口（人丁兴旺） |
| 向星 | 朝向飞星，主财气 |
| 旺星 | 当令之星（当运旺气） |

## 阳宅三十则核心规则

### 城乡取裁差异（第一则）

| 环境 | 取裁方法 |
|------|---------|
| 乡村（气涣） | 以山水兼得为佳 |
| 城市（气聚） | 邻屋凹凸高低代山，街道阔狭曲直代水；低/阔/曲动者为水，高/直/凸者为山 |

### 挨星原则（第二则）

- 以受气之元运为主
- 山向飞星与客星加临为用
- 阴宅重向水，阳宅重门向（门向纳气）
- 门外有水放光，较路尤重

### 大门与屋向关系

| 情形 | 判断法 |
|------|-------|
| 大门正开 | 以屋向为主 |
| 大门旁开 | 合屋向+门向两盘观之 |
| 屋大门小 | 不吉（屋向门向皆旺则无妨） |
| 新开旺门 | 竟用门向，不用屋向 |

### 飞星与建筑要素对应

| 建筑要素 | 飞星规则 |
|---------|---------|
| 造灶 | 火门向一白（水火既济）、三碧四绿（木生火）吉；六白七赤（火克金）凶；二黑五黄最忌 |
| 井 | 在水里龙神生旺方作文笔，衰死克煞方主凶 |
| 塔 | 在一四、一六方主科名；七九、二五方主灾祸 |
| 竹木 | 旺方有树遮蔽不吉，竹无碍（竹通气） |

### 流年叠加判断

- 衰死到向：流年飞星再到，主伤丁
- 旺星不到向时，逢流年旺星到向，反转主发祸
- 财气看向水旺方加太岁，功名看向上一白四绿方

## 特殊规则（逢囚不囚）

- 二、四、六、八进屋，向星入中逢囚不囚——因中宫有明堂（气空）可作水论
- 一、三、五、七进屋，入中便囚；但向上有水放光亦囚不住

## 鬼怪与阴阳卦

| 条件 | 结果 |
|------|------|
| 衰死方屋外有高山屋脊（屋内不见，名"暗探"）+运衰+阴卦 | 出鬼 |
| 衰死方+运衰+阳卦 | 出怪 |
| 阴阳并见 | 出神 |
| 枯树冲射+运衰+阴卦 | 出鬼 |

## 与其他风水流派的区别

| 流派 | 核心工具 | 侧重 |
|------|---------|------|
| 玄空飞星 | 飞星盘（元运+山向飞星） | 时间+空间动态 |
| 形势派 | 山川形势龙穴砂水 | 空间形态 |
| 理气派（[[九星翻卦法]]） | 九星配卦 | 静态理气 |
