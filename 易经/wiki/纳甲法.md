# 纳甲法

六爻卜筮的核心技术框架，将天干（甲乙丙丁...）纳入八卦，再配合地支生成卦爻的五行属性、六亲关系和吉凶判断。

## 基本构成要素

| 要素 | 作用 |
|------|------|
| 纳支（地支配爻） | 确定每爻的五行属性 |
| [[六亲体系]] | 官鬼/父母/妻财/兄弟/子孙，判断人事关系 |
| 安世应法 | 确定世爻（占问者）和应爻（对方/结果） |
| [[六神]]配爻 | 青龙/朱雀/勾陈/螣蛇/白虎/玄武，增加象意维度 |
| 用神 | 根据占问类型选取关键爻 |

## 五行生旺死绝

- 十二月建 × 爻的五行 → 判断该爻旺相/休囚/死绝
- 推四季旺神：春木旺、夏火旺、秋金旺、冬水旺、四季土旺

## 六十甲子纳音

六十甲子配五音（宫商角徵羽），用于判断大限流年中爻的附加属性。

## 之卦断法（《断易天机》特色）

普通卜筮书忽视之卦；本书明确提出由**变爻所得之卦**判断死生，并可追溯过去十五年、推断未来十五年。

## 实例（山风蛊卦）

```
巽宫：山风蛊（归魂）
六神   本卦爻
螣蛇  ▄▄▄▄▄ 兄弟丙寅木（应）
勾陈  ▄▄▄▄  父母丙子水
朱雀  ▄▄▄▄  妻财丙戌土
青龙  ▄▄▄▄▄ 官鬼辛酉金（世）←用神（测病）
玄武  ▄▄▄▄▄ 父母辛亥水
白虎  ▄▄▄▄  妻财辛丑土
```
官鬼酉金持世，妻财两现（土生金），鬼临青龙 → 断为贪色过度。
