# 毕法赋

宋代凌福之撰写的[[大六壬]]核心判断口诀集，共六十法（部分传本七十二法），每法两句对偶，逐一对应六壬课体的吉凶判断规律。《四库全书》六壬大全序言将其与《心镜》《开云观月歌》并列为术家最重要的参考经典之一。

## 核心体例

| 条目格式 | 示例 |
|---------|------|
| 序号+口诀（七言对句） | "第一法：前后引从升迁吉 第二法：首尾相见始终宜" |
| 双法配对，奇偶互补 | 第三/四法为"帘幕贵人高甲第 / 催官使者赴官期" |

## 六十法主题分类

| 主题 | 典型法 | 判断要点 |
|------|--------|---------|
| 贵人吉应 | 1、3、5、45法 | 贵人临干、帘幕贵人、六阳数足 |
| 财富与财亏 | 13、14、27、28法 | 传财化鬼则财休，鬼化财则钱险 |
| 空亡处理 | 15-18法 | 脱上逢脱防虚诈，空上乘空事莫追 |
| 胎财（孕事） | 19、20法 | 胎财生气主怀孕，死气主损胎 |
| 干支关系 | 23、24法 | 彼求我事支传干，我求彼事干传支 |
| 阴阳日特殊 | 25、26法 | 金日逢丁凶，水日逢丁财动 |
| 人宅关系 | 29、30法 | 眷属丰盈居狭宅凶，屋宅宽广致人衰 |
| 讼狱 | 37、38、43、44法 | 末助初兮三等讼，闭口卦体两般推 |
| 富贵格 | 41、42法 | 干支逢禄马为富贵，传内遇三奇尊崇 |
| 贵人受克 | 49、50法 | 两贵受克难干贵，二贵皆空虚喜期 |

## 文献地位

六壬术家将毕法赋列为"蓍蔡"（最权威参考），原因：
1. 六壬断事繁杂，毕法赋提供可操作的课体→判断映射
2. 口诀形式便于记忆，60法覆盖主要吉凶场景
3. 历代注家多有阐发，形成六壬核心教学体系
