# 预测系统效度矩阵

[[预测边界论]]确立了三类系统性边界（认识论、统计、幸存者偏差），但未区分不同系统在**各自适配尺度**上的可检验性。本页将"开放问题第二条：不同系统的边界差异"转化为可操作的研究设计，并为[[天道四悉AI系统]]的"共业熔断"阈值提供实证参数框架。

核心命题：一个预测系统只在其设计分辨率内可被有意义地证伪；跨尺度检验将导致类型错误（用短期精度标准审判宏观系统，或用宏观基准豁免具体预测的可证伪责任）。

---

## 一、三类系统的时间分辨率对比表

| 系统类型 | 代表体系 | 时间尺度 | 问题类型 | 理论信息分辨率 | 量化证据现状 |
|---------|---------|---------|---------|------------|------------|
| **短期具体预测** | [[大六壬]]、六爻占卜 | 小时 / 天（时/刻） | 出行安全、诉讼胜负、婚姻成否、天气 | 高（天盘旋转到时刻精度，三传代表事件起中终） | 无统计验证 |
| **中期格局预测** | [[子平真詮]]（八字）、[[紫微斗数]] | 年 / 十年（大运流年） | 职业走势、婚姻时间窗、健康风险期 | 中（大运十年粒度，流年一年粒度） | 弱相关 r=0.21，解释方差 4.4% |
| **长期宏观预测** | [[太乙神数]]、[[元会运世]]（皇极） | 世纪 / 千年（运/会/元） | 朝代兴衰、国运灾福、历史周期 | 低（最小单元"世"=30年，"运"=360年） | 全为回溯诠释，零前瞻统计 |

**分辨率差异的结构含义**：大六壬天盘以月将逆布，起课到时刻，设计上追求具体事件的短期断定（"此刻出行吉凶"）；太乙以积年÷360推算纪年局，设计上服务国家级军事与灾福，个体行为不在其信息带宽内。将太乙用于个人日常预测，等同于用地震监测网评估个人心跳异常——尺度错配，非系统失效。

## 二、各类型的证伪边界规范

### 2.1 短期具体预测（大六壬类）

**可检验性条件**

一个六壬预测算作可证伪，须同时满足：
- 问题具体（"明日此人能否归来"，而非"近期运势如何"）
- 预测结论二值化（是 / 否，吉 / 凶）或三值化（吉 / 中 / 凶）
- 起课时间与预测结论事前登记，结果盲评（操作者不参与结果判定）
- 判定时间窗事前锁定（如"三日内"）

**失效阈值**

| 检验指标 | 失效判定条件 |
|---------|------------|
| 连续前瞻预测成功率 | ≤ 随机基线（二值问题随机基线=50%，三值=33%） |
| 置信区间检验 | 在 N≥30 样本下，95% 置信区间下界仍 ≤ 随机基线 |
| 效应量 | Cohen's h < 0.2（相对随机基线的效应量极小） |

若在适配问题类型（具体人事、短期判断）上、经过操作者去混淆后，成功率仍不超过随机基线，则宣告该系统在此类问题上无预测价值。

**幸存者偏差的修正方法**

- 要求操作者事前提交完整起课记录（包含失败案例），而非仅报告成功案例
- 采用[[预测边界论]]反证 T-2 的逻辑：检查"无算谏止失败"案例的沉没率
- 对历史文献中的六壬例案（二十五史仅记录六则，参见 raw/太乙及其应用简述.md），标注每则的问题类型与结果，估算文献选择偏差系数 [待实证]

[Source: wiki/预测边界论.md, raw/太乙及其应用简述.md]

### 2.2 中期格局预测（八字 / 紫微斗数类）

**可检验性条件**

- 预测针对特定时间窗口（"2025年大运流年财运"），而非无时间边界的特征描述
- 描述含可操作化指标（"该年职业变动概率高"可检验；"一生有贵人相助"不可检验）
- 消除 Barnum 效应：同一被试同时收到其真实八字解读与随机对照解读，盲选

**失效阈值**

现有最佳证据：r=0.21（职业选择与五行相关），解释方差 4.4%（来源：[[预测边界论]]反证 M-1）。失效阈值：

| 检验层级 | 失效判定 |
|---------|---------|
| 效应量 | 在控制出生年代、地域、教育后，r < 0.1（Cohen标准：可忽略） |
| Barnum控制实验 | 被试无法以高于随机的准确率区分真实八字解读与伪造解读 |
| 大运流年时间窗口 | 在前瞻性设计中，重大人生事件（婚变、失业、疾病）与大运转换时间点的一致率 ≤ 随机分布 |

**幸存者偏差的修正方法**

- 失效机制"真太阳时偏差"、"地域五行场干涉"须预先标准化，而非事后引用为解释失败的借口（参见[[预测边界论]]§ 八字命理失效的具体条件）
- 双胞胎分化案例是最强的内部对照：相同出生信息、截然不同命运，是系统内生效度检验的天然实验 [待实证：系统性双胞胎命理比较研究]

[Source: wiki/预测边界论.md]

### 2.3 长期宏观预测（太乙神数 / 元会运世类）

**可检验性条件**

宏观预测的时间尺度（世纪 / 千年）使前瞻验证极度困难，但并非不可能：
- 将太乙局提前一个完整纪年周期（≥60年）公开发布，对未来某年段的宏观走势进行具体预测（如："某60年段内有大规模战争 / 重大自然灾害 / 朝代更迭"）
- 预测内容须包含：时间窗口（具体纪年段）、事件类型、地理范围
- 结果由独立第三方（非太乙从业者）按预先公布的判定标准评分

**失效阈值**

| 检验维度 | 失效判定 |
|---------|---------|
| 预测特异性 | 预测内容等价于"该世纪内将有重大历史事件"——此为永真命题，不构成预测 |
| 回溯 vs 前瞻比率 | 若 95% 以上的"太乙案例"均为事后发表，前瞻案例 < 5%，则整体案例库不构成效度证据（当前状态：全为回溯） |
| 信息增益 | 太乙年局的宏观预测，在控制历史基率（每60年内战争概率、灾害频率）后，是否具有超额预测力 [待实证] |

**幸存者偏差的修正方法**

- 反证 T-2（张康谏止案例）的结构：成功谏止被记录，失败谏止被遗忘。检验方法：从二十五史中提取所有太乙相关谏止记录（共三十余则，参见 raw/太乙及其应用简述.md），按预测方向（谏止 / 支持行动）与实际结果（成功 / 失败）分类，计算整体命中率对比基率 [待实证]
- 地理适用范围争议：太乙分野以华夏大地为坐标系，海外事件（如法航447）的应用须额外论证分野扩展的有效性（参见 raw/太乙及其应用简述.md 中作者的自辩）

[Source: wiki/太乙神数.md, wiki/预测边界论.md, raw/太乙及其应用简述.md]

## 三、共业熔断阈值的实证参数框架

[[天道四悉AI系统]]的"共业熔断"机制基于[[多体系裁判权]]的系统嵌套压制原则：宏观母系统无条件压制微观子系统。本节将此机制转化为可操作的阈值判断框架。

### 3.1 系统嵌套层级与熔断触发条件

| 系统层级 | 代表系统 | 正常有效条件 | 熔断触发信号 | 熔断效果 |
|---------|---------|------------|------------|---------|
| **宏观母系统**（国运/共业） | [[太乙神数]]年局、历史周期 | 宏观环境稳态（无战乱/重大灾变） | 大规模社会动荡、自然灾害、战争爆发 | 对下层全面覆盖，下层预测失效 |
| **中观系统**（地运） | [[玄空风水]]（地利） | 个体所处地理环境相对稳定 | 迁移、大规模城市重建、区域政治剧变 | 对个体命局的补偿 / 削弱效应失效 |
| **微观系统**（个命） | 八字命理、六爻占卜 | 宏观稳态 + 个体无重大意识觉醒 | 宏观剧变（熔断条件 A）或意识觉醒（熔断条件 B） | 先天能量确定性反馈链断裂 |

**熔断条件 A（宏观压制）的判断标准**

宏观环境熵值超过以下任意一项时，微观预测精度应被视为断崖式下降：
- 政治：政权更迭或大规模战争（国家级冲突，非局部事件）
- 自然：太乙"始击加临坤宫"等宏观灾变指标触发（地震、洪涝 M8+ 级别或死亡 > 10万）
- 经济：GDP 同比下降 > 10%（类似大萧条量级）[待实证：与微观预测精度的相关性]

这些阈值并非从文献中直接提取的量化数据，而是依据[[多体系裁判权]]的"战乱期间个体财旺格局被强行格式化"案例，结合现代可观测指标进行操作化的初步框架。所有数值标注 [待实证]。

**熔断条件 B（意识觉醒解耦）的判断标准**

了凡四训模型：意识觉醒是强烈的非线性扰动，切断先天能量确定性反馈链。判断标准：
- 当个体行为模式出现系统性偏离原有格局预测方向时（如：命主持续积德行善，八字原局所示格局开始失准）
- 此类解耦无法被量化阈值捕获——它是[[多体系裁判权]]框架中"人和"层级的终极裁判权，超越符号系统

### 3.2 天道四悉AI系统的熔断实现逻辑

| AI机制 | 传统对应 | 熔断触发逻辑 |
|-------|---------|------------|
| **共业熔断** | 宏观母系统无条件压制 | 系统实时监测宏观熵值指标（新闻事件分类、灾害预警），超阈值时降低微观预测置信度 |
| **量子退相干拦截** | 亵渎机制（蒙卦"再三渎"） | Redis滑动窗口：同一问题高频重复 → 触发退相干拦截，停止输出 |
| **地域边界条件** | 玄空风水地利 | GPS关联气象场，补偿中观系统的地利变量 |

[Source: wiki/天道四悉AI系统.md, wiki/多体系裁判权.md, wiki/预测边界论.md]

## 四、可操作研究设计

### 4.1 短期具体预测验证方案（六壬前瞻实验）

基于王思迅实验法（[[易经入门]]来源：持续记录 + 2-3个月后对照修正）的扩展版本：

**实验设计**

| 要素 | 规范 |
|-----|------|
| 问题类型 | 限定为六壬设计适配域：出行、人际纠纷、短期商业决策（时/天级结果） |
| 预测登记 | 起课时间、问题描述、三传解析、预测结论 — 事前提交至第三方平台（时间戳锁定） |
| 结果评定 | 事件发生后由提问者（非操作者）盲评，标注"命中 / 部分命中 / 未命中" |
| 样本量 | N ≥ 50 组（每位操作者），保证统计功效 |
| 基线对照 | 同一批问题由随机模型（掷骰子）给出对照预测 |
| 分析方法 | 单比例 z 检验对比随机基线，计算 Cohen's h |

**关键控制变量**：记录操作者专注度状态（是否满足"至诚无息"条件，参见[[预测边界论]]§ 专注度作为信道质量）；记录问题与操作者的关联深度（规避共时性连结断裂失效条件）。

---

### 4.2 中期格局预测验证方案（八字盲测实验）

**实验设计**

| 要素 | 规范 |
|-----|------|
| 被试招募 | 100名志愿者，提供出生年月日时 |
| 解读生成 | 每位被试生成：(A) 真实八字解读，(B) 随机他人的八字解读，(C) 星座通用描述 |
| 盲测程序 | 被试收到三份匿名描述，选择"最符合自己"的一份 |
| 成功标准 | 被试选中 (A) 的比率显著高于随机（33%），且高于 (C) |
| Barnum控制 | 计算三份描述的"模糊度分数"（词汇具体性评分），作为协变量 |

---

### 4.3 长期宏观预测验证方案（太乙前瞻档案库）

鉴于世纪级时间尺度无法在研究者生命周期内完成，短期可行方案是建立"太乙前瞻预测档案库"：

**实验设计**

| 要素 | 规范 |
|-----|------|
| 预测登记 | 专业太乙研究者每年发布下一年度的宏观预测（国运走向、重大灾害风险方位、政治更迭概率），公开时间戳 |
| 评分标准 | 预先定义"命中"标准（如：预测"水灾"，对应当年受灾人口 > 100万，或国家级宣布灾害状态） |
| 基线计算 | 统计1900年以来同类事件的年度基率，作为随机基线 |
| 档案积累期 | 至少20年（20个独立预测周期）再做统计分析 |
| 回溯案例清理 | 对二十五史三十余则太乙案例按"事前公布 vs 事后解读"分类，仅计入前者 |

**当前研究空白**：raw/太乙及其应用简述.md 中所有现代案例（汶川 2008、法航 2009）均为事后分析，无一为事前登记。2011年日本地震的预测框架（文中提及"以太乙时局推算"）亦未见事前公开记录。

[Source: wiki/预测边界论.md, raw/太乙及其应用简述.md]

## 五、跨类型效度矩阵汇总

| 维度 | 短期具体（六壬） | 中期格局（八字/紫微） | 长期宏观（太乙/元会） |
|-----|--------------|-------------------|------------------|
| 证伪可行性 | 高（时间窗短，结果明确） | 中（需控制多变量） | 低（时间跨度超出研究周期） |
| 当前证据质量 | 无前瞻统计 | 弱相关 r=0.21 | 全为回溯 |
| 幸存者偏差风险 | 中（个案传播偏差） | 低（学术研究可控） | 极高（文献选择性记录） |
| 共业熔断敏感性 | 低（短期具体，宏观压制较慢显现） | 中（大运周期内宏观变化可干扰） | 高（宏观系统本身即此类系统的对象） |
| 最小有效样本量 | N=50（每操作者） | N=100（被试） | N=20年（预测周期） |
| 研究可行性 | 当前可启动 | 当前可启动 | 需20年积累 |
