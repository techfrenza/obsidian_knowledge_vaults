# 十二宫体系

[[紫微斗数]]命盘由12个固定宫位组成，每宫对应人生一个维度。命宫为枢纽，其他宫位围绕命宫形成结构性关联。

## 十二宫名称与意义

| 宫位 | 代表维度 |
|------|---------|
| 命宫 | 个性、先天格局、生命主轴 |
| 兄弟宫 | 手足关系、平辈情谊 |
| 夫妻宫 | 感情婚姻 |
| 子女宫 | 子嗣、部属、创意 |
| 财帛宫 | 财运、金钱观、收入方式 |
| 疾厄宫 | 健康体质、生命力 |
| 迁移宫 | 外出、社会适应、他乡运 |
| 交友宫（奴仆宫）| 人际关系、下属 |
| 事业宫（官禄宫）| 工作事业、职位 |
| 田宅宫 | 不动产、家庭居住 |
| 福德宫 | 精神生活、内在享受 |
| 父母宫 | 父母关系、文书印信 |

## 三方四正

| 概念 | 定义 | 应用 |
|------|------|------|
| 三方 | 本宫 + 顺时针第5宫 + 逆时针第5宫 | 互相扶持的三个宫位 |
| 四正 | 三方 + 对宫 | 推断最重要的四宫参照 |

命宫三方：命宫、财帛、事业。女性三方：命宫、福德、夫妻（不同于男命）。

## 身宫

身宫是修正宫位，可落于命、夫妻、财帛、迁移、事业、福德六宫中任一：
- 加强该宫的影响力
- 表示此人一生注意力的重点所在

## 庙旺平陷

| 状态 | 含义 |
|------|------|
| 庙 | 最明亮，对所在宫影响最大 |
| 旺 | 明亮，影响强 |
| 平 | 遇吉增强，遇凶削弱 |
| 陷 | 暗淡，逢吉稍补，逢凶更凶 |

## 对宫应用

宫中无星时看对宫；两宫相对的克害关系同样重要。六组对宫：命-迁、夫妻-交友、子女-父母、财帛-田宅、疾厄-福德、兄弟-事业。

## 历史定位

斗数由陈希夷（陈抟）相传所创，源自"十八飞星"等早期术数演变，重新定义十二宫并加入三方四正后独立成体；明清两代大成，但普及度历来低于[[子平法]]（因起盘复杂、理论基础较子平为弱）。
