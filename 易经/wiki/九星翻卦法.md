# 九星翻卦法

中国最古老的风水术数之一，又称"天星风水学"或"地母九星翻卦"。以先后天八卦和[[河图洛书]]为基础，结合[[纳甲法]]原理，推演阴阳宅周围星峰、来去水对人居吉凶的影响。

## 九星名称与代数

| 代数 | 星名 | 游年名称 | 属性 |
|------|------|---------|------|
| 1 | 贪狼木星 | 生气 | 吉 |
| 2 | 巨门土星 | 天医 | 吉 |
| 3 | 禄存土星 | 祸害 | 凶 |
| 4 | 文曲水星 | 六煞 | 凶 |
| 5 | 廉贞火星 | 五鬼 | 凶 |
| 6 | 武曲金星 | 延年 | 吉 |
| 7 | 破军金星 | 绝命 | 凶 |
| 8 | 左辅（辅弼） | 伏位 | 吉 |
| 9 | 右弼（辅弼） | 伏位 | 吉 |

四大吉星：贪、巨、武、辅；四大凶星：禄、文、廉、破。

## 翻卦原理

基于先天八卦序（乾兑离震巽坎艮坤），从主卦的上爻开始依序变爻：
- 变爻顺序：**上 → 中 → 下 → 中 → 上 → 中 → 下**（共7变，第8变还原主卦）
- 阴变阳、阳变阴，每变出一个新卦，对应一颗星

地母翻卦（以坤卦为例）：
```
坤（辅）→ 艮（贪1）→ 巽（巨2）→ 乾（禄3）→ 离（文4）
→ 震（廉5）→ 兑（武6）→ 坎（破7）→ 坤（辅8，还原）
```

## 八卦纳甲与二十四山

**纳甲一气**决定二十四山对应的九星位置：

| 卦 | 纳甲山（二十四山） | 对应坤宫九星 |
|----|------------------|------------|
| 坤 | 坤、乙 | 辅弼（伏位） |
| 艮 | 艮、丙 | 贪狼（生气） |
| 巽 | 巽、辛 | 巨门（天医） |
| 乾 | 乾、甲 | 禄存（祸害） |
| 离 | 壬、寅、午、戌 | 文曲（六煞） |
| 震 | 庚、亥、卯、未 | 廉贞（五鬼） |
| 兑 | 丁、巳、酉、丑 | 武曲（延年） |
| 坎 | 癸、申、子、辰 | 破军（绝命） |

## 三种翻卦方法

| 方法 | 用途 |
|------|------|
| **地母翻卦法**（九星翻卦） | 测室外星峰、来龙坐山 |
| **二十四山翻卦法** | 一卦管三山，测室外星峰和来去水 |
| **辅星水法** | 从向山起辅，专测室外水法来去吉凶 |

> 三法用法不同，不可混用。山法用地母翻卦掌，水法用辅星水法。

## 辅星水法九星断语（部分）

| 星 | 来水 | 去水 |
|----|------|------|
| 辅弼 | 丁财两旺，子孙贤孝 | 生灾破财，小人暗算 |
| 贪狼 | 财福绵长，先苦后甜 | 家运不兴，子孙不孝 |
| 巨门 | 福寿康泰，丁财来旺 | 财运不济，子孙不孝 |
| 武曲 | 旺官旺财，子孙孝贤 | 家业不兴，出人愚笨 |
| 破军 | 破财损丁，官事不断 | 子孙贤良，官运亨通 |
| 廉贞 | 官灾火光，破财损伤 | 财源广进，大利官场 |

## 实战应用步骤

1. 确定中宫，用罗盘定坐向分金
2. 以坐山（或来龙）所属卦为起点
3. 用翻卦掌从对宫起贪狼（"乾兑互翻、离震互翻、坎巽互翻、坤艮互翻"）
4. 顺序排出九星：贪巨禄文廉武破辅
5. 对照门、灶、床、水口等位置判断吉凶

## 历史渊源

相传源自汉代黄石公，据《青囊经》载，后为各派风水所采用。三合派与三元派均认为此门学理验证率极高，古称"断验如神"。
