# 遗传密码

## 定义
遗传密码（Genetic Code）是将 mRNA 上三联体碱基序列（密码子，codon）翻译为氨基酸序列的对应规则，共64个密码子编码20种氨基酸及终止信号。

## 书中语境
第15章"The Genetic Code"：从 Nirenberg 的无细胞翻译实验破解第一个密码子（UUU=苯丙氨酸），到整套密码表的完整解读及其特性。

## 关键洞见

| 特性 | 内容 |
|------|------|
| 简并性（Degeneracy） | 大多数氨基酸由多个密码子编码（除 Met 和 Trp 各一个） |
| 通用性（Universality） | 几乎所有生物共用同一套密码（线粒体和少数原核生物有极少例外） |
| 非重叠性（Non-overlapping） | 密码子连续阅读，不重叠 |
| 无标点性（Comma-free） | 密码子间无分隔符，阅读框（reading frame）由 AUG 起始密码子确定 |

- **起始密码子**：AUG（编码甲硫氨酸/Met）是唯一的起始信号，也确定了阅读框。
- **终止密码子**：UAA、UAG、UGA——不编码氨基酸，是终止信号（由释放因子识别）。
- **简并性的保护意义**：同义突变（synonymous mutation）改变密码子但不改变氨基酸，部分缓冲了点突变对蛋白质的影响。
- **历史意义**：遗传密码的破解（1961-1966）证明信息流从 DNA → RNA → 蛋白质，是分子生物学的里程碑。
