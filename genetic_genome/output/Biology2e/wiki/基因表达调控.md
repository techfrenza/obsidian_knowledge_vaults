# 基因表达调控

## 定义
基因表达调控（Gene Expression Regulation）是细胞控制基因何时、何地、以何种强度产生蛋白质的多层次机制，使同一基因组的不同细胞形成不同表型。

## 书中语境
第16章"Gene Expression"：从原核操纵子模型到真核多层调控的系统性比较，以癌症为基因调控失常的病理实例。

## 关键洞见

### 原核生物调控——操纵子（Operon）
- **乳糖操纵子（Lac Operon）**：经典"负调控"模型——阻遏蛋白（Repressor）与操纵子（Operator）结合时抑制转录；乳糖存在时，异乳糖（allolactose）与阻遏蛋白结合，解除阻遏。
- **Trp 操纵子**：色氨酸充足时作为共阻遏物激活阻遏蛋白，抑制自身合成基因的转录（负反馈）。

### 真核生物调控——多层次

| 调控层次 | 机制 |
|----------|------|
| 表观遗传 | DNA甲基化（沉默基因）、组蛋白修饰（乙酰化开放/去乙酰化压缩染色质） |
| 转录水平 | 转录因子结合增强子/沉默子；染色质重塑 |
| 转录后 | 可变剪接；mRNA稳定性（3' UTR序列、miRNA） |
| 翻译水平 | 翻译起始因子磷酸化；核糖体结合 |
| 翻译后 | 蛋白质折叠、修饰、降解（泛素蛋白酶体途径） |

- **miRNA / siRNA**：小非编码RNA通过与靶mRNA互补结合，触发其降解或抑制翻译——RISC复合物介导的基因沉默。
- **癌症本质**：肿瘤抑制基因（p53等）或原癌基因（Ras等）的突变导致基因表达调控失控，细胞无限增殖。
