# 生物技术与基因工程

## 定义
生物技术（Biotechnology）指利用分子生物学工具操纵生物体的遗传物质，以产生具有医疗、农业或科研价值的生物产品或功能；基因工程是其核心技术。

## 书中语境
第17章"Biotechnology"和"Genomics"：从限制性内切酶和重组DNA技术的基础工具，到基因组学、蛋白质组学和个性化医疗的前沿应用。

## 关键洞见

| 核心工具 | 功能 |
|----------|------|
| 限制性核酸内切酶（Restriction Endonuclease） | 识别特异DNA序列并切割，产生粘性末端或平端 |
| DNA连接酶（DNA Ligase） | 将DNA片段连接形成重组DNA |
| 聚合酶链反应（PCR） | 体外扩增特异DNA片段，指数级放大 |
| 凝胶电泳 | 按大小分离DNA/RNA片段 |
| Sanger测序 | 双脱氧链终止法，读取DNA序列 |
| 下一代测序（NGS） | 大规模并行测序，使全基因组测序成本骤降 |

- **重组蛋白生产**：将人类基因插入细菌或酵母质粒表达系统，生产胰岛素（1982年）、生长激素、EPO等——开创生物制药时代。
- **基因敲除/敲入（Knockout/Knock-in）**：模式生物（小鼠、斑马鱼）的基因功能研究标准方法。
- **CRISPR-Cas9**：第三代基因编辑技术（Book 17章已涵盖基础概念），以RNA引导Cas9核酸酶精确切割靶位点，效率和灵活性远超前代技术。
- **基因组学悖论**：人类基因组约2万个蛋白编码基因，少于线虫（约2万）——复杂性来自调控网络、可变剪接和蛋白质互作，而非基因数量。
