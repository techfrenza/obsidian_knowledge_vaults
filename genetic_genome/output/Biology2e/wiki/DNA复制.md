# DNA复制

## 定义
DNA复制（DNA Replication）是以亲代双链DNA为模板，按碱基配对原则合成两条相同子代双链DNA的过程，采用半保留复制机制。

## 书中语境
第14章"Basics of DNA Replication"、"DNA Replication in Prokaryotes"和"DNA Replication in Eukaryotes"：从 Meselson-Stahl 实验证实半保留机制，到两类生物具体分子机制的比较。

## 关键洞见

| 关键酶 | 功能 |
|--------|------|
| 解旋酶（Helicase） | 解开双链，形成复制叉 |
| 引物酶（Primase） | 合成 RNA 引物（DNA pol 需要3'-OH） |
| DNA聚合酶III（原核）/ δ/ε（真核） | 5'→3' 合成新链，同时具有3'→5'校读 |
| DNA聚合酶I | 替换 RNA 引物为 DNA |
| DNA连接酶 | 连接冈崎片段，封闭切口 |
| 拓扑异构酶 | 释放解链产生的超螺旋张力 |

- **半保留复制（Semiconservative）**：每条子代双链含一条亲代链 + 一条新合成链，Meselson-Stahl 用 15N/14N 密度标记于1958年直接证明。
- **前导链与滞后链**：DNA pol 只能 5'→3' 合成，双链方向相反，因此一条链连续合成（前导链），另一条链分段合成冈崎片段（Okazaki fragment，滞后链）。
- **端粒问题**：线性真核染色体每轮复制末端缩短；端粒酶（Telomerase，含RNA模板）延伸端粒重复序列，体细胞中活性低，生殖细胞和癌细胞中高活性。
- **校读精度**：DNA pol 的 3'→5' 外切酶活性实时校读，错误率约 10⁻⁷，加上修复机制达 10⁻⁹-10⁻¹⁰。
