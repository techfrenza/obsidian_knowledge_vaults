# DNA修复机制

## 定义
DNA修复（DNA Repair）是细胞检测并纠正DNA损伤（碱基错配、化学损伤、双链断裂）的多种酶促机制，维护基因组完整性。

## 书中语境
第14章"DNA Repair"：介绍主要修复途径及其临床意义。

## 关键洞见

| 修复机制 | 修复的损伤类型 | 关键酶 |
|----------|----------------|--------|
| 错配修复（MMR） | 复制引入的碱基错配 | MutS/MutL识别，MutH切除 |
| 碱基切除修复（BER） | 氧化/脱氨损伤的单个碱基 | DNA糖基化酶识别，AP内切酶切割 |
| 核苷酸切除修复（NER） | 化学加合物（紫外损伤：胸腺嘧啶二聚体） | 识别复合物切除约30 nt片段 |
| 双链断裂修复 | | |
| - 同源重组（HR） | 双链断裂（高保真，需姐妹染色单体模板） | Rad51（真核），RecA（原核） |
| - 非同源末端连接（NHEJ） | 双链断裂（快速但易出错） | Ku蛋白结合末端，DNA-PKcs配合 |

- **p53的守门员角色**：DNA损伤激活p53 → 转录激活 p21（抑制CDK）→ 细胞周期停滞修复；修复失败则激活凋亡。p53突变是约50%人类癌症的共同特征。
- **着色性干皮病（Xeroderma Pigmentosum）**：NER基因缺陷，无法修复紫外损伤 → 皮肤癌风险超1000倍——直接证明NER的保护功能。
- **Lynch综合征（遗传性非息肉结肠癌）**：MMR基因（MLH1/MSH2等）胚系突变，微卫星不稳定性，终生结肠癌高风险。
