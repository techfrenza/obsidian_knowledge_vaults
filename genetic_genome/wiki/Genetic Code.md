# Genetic Code

The genetic code is the complete set of rules by which nucleotide triplets (codons) in mRNA are translated into amino acids or stop signals during protein synthesis.

## Core Properties

| Property | Description |
|----------|-------------|
| Triplet | Three nucleotides = one [[Codon]] = one amino acid (or stop signal) |
| Universal | Nearly identical across all organisms, from bacteria to humans |
| Degenerate | Multiple codons can encode the same amino acid (e.g., leucine has 6 codons) |
| Non-overlapping | Each nucleotide belongs to exactly one codon in a reading frame |

## Start and Stop Codons

- **AUG** (methionine): Universal start codon; defines [[Translation]] initiation and reading frame
- **UAA, UAG, UGA**: Stop codons; signal peptide release, not amino acid insertion

## Reading Frame

Reading frame is determined by the position of AUG. The same mRNA sequence produces entirely different polypeptides in different frames. Frameshift mutations (insertions/deletions of 1–2 nucleotides) disrupt the frame downstream of the mutation, typically abolishing protein function. [[CRISPR-Cas9]] knockouts exploit this by generating indels via [[Nonhomologous End Joining (NHEJ)]].

## Discovery

The genetic code was deciphered in the 1960s by Nirenberg, Matthaei, Khorana, and others using cell-free translation systems and synthetic polynucleotides.

## Connection to Degeneracy and Wobble

The redundancy of the genetic code is partly explained by wobble base pairing at the third codon position in [[tRNA]] anticodon–codon interactions. This allows one tRNA to recognize multiple codons.
