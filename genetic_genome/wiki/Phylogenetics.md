# Phylogenetics

Phylogenetics is the study of evolutionary relationships among organisms using molecular sequences, morphological characters, and behavioral traits to construct phylogenetic trees representing branching histories.

## Core Concepts

- **Phylogenetic tree**: A diagram showing the hypothesized evolutionary relationships between organisms; tips = extant (or sampled) taxa; internal nodes = common ancestors
- **Lineage**: An unbroken chain of ancestors and descendants
- **Clade**: A group comprising an ancestor and all its descendants (monophyletic group)
- **Branch length**: Represents evolutionary time or number of substitutions

## Data Sources

- Morphological characters (classical)
- DNA/RNA sequences (modern; dominant)
- Protein sequences

## Key Analytical Methods

| Method | Description |
|--------|-------------|
| Maximum Parsimony | Minimizes total evolutionary changes |
| Maximum Likelihood | Selects tree maximizing probability of observing the data given a model |
| Bayesian Inference | Posterior probability of tree topologies |
| [[D-Statistic (ABBA-BABA Test)]] | Tests for gene flow/[[Introgression]] between lineages |

## Core Problem: Ghost Lineages

Most past species are extinct and unsampled. [[Ghost Lineage|Ghost lineages]] introduce systematic errors in phylogenetic analyses, particularly in [[D-Statistic (ABBA-BABA Test)|introgression tests]]. The more unsampled lineages exist, the higher the probability of misinterpreting gene flow events.

## Relevance to Human Evolution

Phylogenetics of modern humans detected [[Introgression]] from Neanderthals and Denisovans into modern human genomes using ABBA-BABA tests. Subsequent analysis revealed that the distant outgroup (chimpanzee) makes ghost introgression misinterpretation likely for these tests (relative outgroup distance = 0.873).
