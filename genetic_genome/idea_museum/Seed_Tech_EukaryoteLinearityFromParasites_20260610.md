# Eukaryotic Chromosome Linearity as Pathological Origin

## Technical Core Logic

The canonical assumption is that linear chromosomes are an "upgrade" over prokaryotic circular chromosomes — enabling complex regulation, recombination, and cell-cycle control. However, the evolutionary evidence supports a pathological origin:

- The transition from circular to linear chromosomes correlates with endosymbiosis events, during which horizontal gene transfer of group II introns (ancestral retrotransposons) created persistent double-strand breaks in the ancestral circular genome
- Cells unable to rejoin these breaks had to evolve capping mechanisms — proto-telomeres formed from repetitive retrotransposon insertions at break ends
- *Drosophila* still uses HeT-A, TART, TAHRE retrotransposons instead of TTAGGG repeats, preserving this ancestral mechanism
- Subtelomeric regions today are enriched in repetitive elements, consistent with their retrotransposon origin

## Trade-off Table

| Aspect | Prokaryotic Circular | Eukaryotic Linear |
|--------|---------------------|-------------------|
| Replication efficiency | Complete via single origin | Requires multiple origins + telomerase |
| End-protection burden | None | Entire shelterin complex needed |
| Regulatory complexity | Lower | High (chromatin, nuclear envelope) |
| Evolutionary origin | Ancestral default | Forced by genome parasite invasion |

## Key Implication

The "end-replication problem" (telomere shortening per division, Hayflick limit, cellular aging) is an evolutionary artifact of the initial damage-control response — not a designed feature of eukaryotic biology. Aging via telomere shortening is a side-effect of ancestral genome defense.
