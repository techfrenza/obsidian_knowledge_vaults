# X Hook Drafts

Hook 1 (counter-intuition):
CRISPR, mismatch repair, NHEJ — we think of DNA repair as the guardian of genome stability. But the oldest error-correction system in biology isn't an enzyme. It's the genetic code itself. 64 codons for 20 amino acids, with redundancy placed exactly where random mutations land most often. ~70% of point mutations are silenced before they ever affect a protein.

Hook 2 (question):
Why does the genetic code have 64 codons for only 20 amino acids? The standard answer is "degeneracy." The deeper answer: evolution front-loaded error tolerance into the code architecture, so that most mutations that DNA polymerase makes by accident are automatically silenced. The code doesn't just translate. It absorbs error.

Hook 3 (historical):
The genetic code was finalized ~4 billion years ago. DNA repair enzymes evolved later. This means for some period, the genetic code's degeneracy WAS the entire mutation-buffering system. Before NHEJ. Before HDR. Before mismatch repair. The code came first.
