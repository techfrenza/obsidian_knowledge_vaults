# Hal Puthoff与SRI遥视研究

哈尔·普索夫（Hal Puthoff）是斯坦福大学实验物理学博士，红外激光发明者，1970年代在斯坦福研究所（SRI）建立了远程观察（Remote Viewing）实验框架，开创了后来[[遥视与星门计划]]的科学基础。

## 遥视研究启动路径

1. **植物实验启发**：克里夫·巴克斯特（Cleve Backster）将测谎仪连接植物观察到反应信号，提示非传统物理场域的存在。
2. **英戈·斯旺（Ingo Swann）招募**：艺术家兼通灵者，在纽约城市学院实验中影响了温度测量设备。
3. **SRI量子芯片实验**：斯旺在多层屏蔽（电磁/磁/超导/声学）内准确描述设备内部，并改变量子芯片振荡速率。
4. **CIA介入**：中情局注意到普索夫的高级安保许可及SRI实验结果，资助初步项目（约5-6万美元），最终演变为持续23年的星门计划。

## 帕特·普莱斯苏联目标事件

- CIA副局长建议普莱斯描述苏联塞米巴拉金斯克设施。
- 普莱斯描述了屋顶大型起重机和球形物体，后经卫星图像确认。
- 此事件成为遥视在情报领域可行性的关键证据。
