# 3I/ATLAS星际彗星

3I/ATLAS是2025年7月由智利ATLAS巡天系统发现的第三颗确认星际彗星，继1I/'Oumuamua（2017）和2I/Borisov（2019）之后。2026年6月22日，由Martin Cordiner团队在《Nature》发表的JWST分析结果确认其极端古老的银河系早期起源。

## 关键发现（2026年Nature论文）

| 参数 | 测量结果 | 意义 |
|------|---------|------|
| 氘-氢比（D/H） | 太阳系彗星的~30倍 | 形成于极低温（<30K）的极古老环境 |
| 甲烷（CH₄） | 首次在星际天体上直接探测到 | 富含挥发性有机物，暗示前生物化学 |
| 彗发主导成分 | CO₂主导，伴H₂O、CO、OCS、水冰 | 与太阳系彗星组成有显著差异 |
| 每日出水量 | 相当于70个奥运游泳池的水蒸气 | 活跃的表面过程 |

## 宇宙学意义

- **起源时期**：极高D/H比指向宇宙"正午"（cosmic noon）时代（约100亿年前）形成于金属贫乏原行星盘
- **化学多样性**：证明星际访客的化学组成远比预想多样，挑战"太阳系代表平均宇宙化学"的假设
- **前生物暗示**：富含有机前体分子（甲烷、CO）的极古老物质，为星际播种（panspermia）假说提供间接支持

## 与[[信息矩阵现实]]和[[全息原理]]的关联

3I/ATLAS携带的古老宇宙化学信息，支持宇宙中"化学信息守恒"的概念——信息不随时间消失，而是以不同形态在宇宙中传播，与[[It from Bit信息本体论]]的信息不灭原则存在概念层面的呼应。

## 与前两颗星际天体的比较

| 天体 | 特征 |
|------|------|
| 1I/'Oumuamua（2017） | 无彗发，异常加速，来源争议最大 |
| 2I/Borisov（2019） | 化学组成与太阳系彗星相似，"最正常"的星际访客 |
| 3I/ATLAS（2025） | 极端化学异常，最古老，首次检测到星际甲烷 |
