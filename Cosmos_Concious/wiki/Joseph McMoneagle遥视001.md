# Joseph McMoneagle遥视001

约瑟夫·麦克莫尼格尔（Joseph McMoneagle，生于1946年），代号"Remote Viewer No. 001"，是[[遥视与星门计划]]中表现最突出的遥视者，1984年以军职退役，此后作为顾问持续参与至1995年项目终止。

## 关键履历

| 时期 | 事件 |
|------|------|
| 1964 | 加入美国陆军 |
| 1969 | 越南直升机事故，经历[[濒死体验NDE]] |
| 1978 | 被招募入星门计划（时代号GRILL FLAME） |
| 1978 | 在门罗研究所接受双耳节拍意识训练 |
| 1984 | 军职退役，继续以顾问身份参与 |

## 主要遥视任务成果

| 经典案例 | 遥视任务描述 | 事实验证结果 |
|---------|------------|------------|
| 苏联"台风级"潜艇案（1979） | 双盲条件下画出巨大厂房内正在建造的双壳体潜艇草图，预测112天内下水 | 侦察卫星证实：苏联台风级战略核潜艇 |
| 寻找非洲坠毁飞机（1979） | 在地图上精准圈出坠机地点 | 美国特种部队据此率先找到残骸 |
| 百万年前的火星（1984） | 盲测"火星，100万年前"，描述金字塔、方尖碑和正在衰落的巨人种族 | 部分与JPL探测卫星细节视觉印证 |
| SCUD导弹定位 | 提供隐藏导弹位置描述 | 已报告作情报参考 |
| 詹姆斯·多齐尔将军营救（1979） | 描述帕多瓦某公寓建筑细节 | 据报对救援有参考价值 |

**1984年退役时获颁功绩勋章（Legion of Merit）**，授勋词中公开写明其利用超感官知觉提供了其他技术手段无法替代的关键情报。

## 濒死体验与遥视能力的关联

McMoneagle在1969年的直升机事故中经历了[[濒死体验NDE]]，他本人认为这次体验激发了其后续遥视能力的发展——与[[过滤器模型]]预测一致（大脑过滤器损伤后意识感知扩展）。

- [[出体体验OBE]]：McMoneagle的濒死体验涉及出体感知。

- [[受控遥视意识时间机器]]：时间环理论——McMoneagle认为遥视本质是从未来向过去传递信息。

- [[遥视科学训练协议]]："去学习"训练哲学由McMoneagle提出。
- [[门罗研究所]]：McMoneagle在TMI接受双耳节拍意识训练，退役后成为TMI遥视总教练。
