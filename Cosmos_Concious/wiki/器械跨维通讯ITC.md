# 器械跨维通讯ITC

器械跨维通讯（Instrumental Trans-Communication, ITC）指利用电子设备捕捉来自非物质存在（如逝者灵魂）的声音、影像或信号，最常见形式为电子声音现象（Electronic Voice Phenomena, EVP）。

## 主要技术形式

| 技术 | 方法 |
|------|------|
| EVP | 安静环境中录音，回放时发现未察觉的声音 |
| 视频ITC | 摄像机捕捉异常影像 |
| Frank's Box | 快速扫描无线电频率，据称产生实时通讯 |

## 代表性研究者

- **康斯坦丁·劳迪夫（Konstantin Raudive）**：声称进行72,000次录音并捕获灵魂声音，因主观性受批评。
- 美国EVP协会（AA-EVP）推动标准化方法，但科学共识不足。

## 科学争议

- 怀疑论主流解释：**空想性错视（pareidolia）**——大脑将随机噪声模式识别为有意义声音。
- 无线电干扰与声学伪像是常见替代解释。
- Frank's Box难以复制，缺乏独立验证。

## 意识框架定位

ITC属于[[死后沟通ADC]]的技术辅助版本，而ADC通常是自发的。两者共同构成意识存续的现象学证据群，尽管ITC的科学地位弱于前者。

- 与[[高奇特性现象]]归属重叠（技术与灵性的交界地带）。
- [[灵媒研究]]中灵媒作为人肉中介，ITC尝试绕过中介直接技术捕获。

## 矛盾与争议

ITC现象与[[整合信息理论IIT]]、[[全局神经工作空间理论GNWT]]等主流意识理论存在根本矛盾：后者均要求意识依附于物理神经基底，无法解释无肉体的意识通过电子设备传递信息。
