# 全息原理

Holographic Principle：**三维时空区域内的所有物理信息，可被完整编码在其二维边界上**。由't Hooft和Susskind基于黑洞热力学提出，AdS/CFT对偶（Maldacena 1997）将其数学化。

## 核心内容

黑洞热力学揭示：黑洞的熵（信息量）正比于**视界面积**，而非体积。这意味着：
- 三维体积（体积）中的信息 ≤ 其二维表面所能编码的最大信息量（贝肯斯坦上限）
- 推广：任何有界区域的全部物理内容，原则上可由其边界的量子信息**完整重建**

**暗示：三维空间和其中的物质，可能只是二维量子信息的投影。**

## AdS/CFT对偶（具体数学实现）

反德西特时空（AdS）中的引力理论 ≡ 其边界上的共形场论（CFT，无引力量子多体系统）

- **Ryu-Takayanagi公式**：$S_A = \text{Area}(\gamma_A)/(4G_N)$
  边界子区域A的纠缠熵 = bulk中极值面面积 / (4G)
- 边界纠缠"投影"出体积几何
- 直接含义：时空几何是量子信息/纠缠的几何表示

## 时空从量子信息涌现（Takayanagi 2025）

2025年最新工作：
- 整个bulk几何由海量纠缠量子比特填充，**每Planck面积 = 一对Bell态纠缠**
- 纠缠熵的第一定律 → 推导出爱因斯坦方程
- 时空弯曲 = 纠缠演化的几何表达
- Tensor network（MERA）模型：量子电路的纠缠结构自然生成AdS几何

## 与黑洞信息悖论的联系

全息原理提供了[[黑洞信息悖论]]的解决框架：
- 黑洞内部不再是经典时空，而是**量子信息的纯编码模式**（"逻辑地址"）
- 落入黑洞的信息被重排为纠缠模式，外部辐射是解码密钥
- 岛公式（Island Formula）+ 复制虫洞 = 全息原理在蒸发黑洞中的具体应用
