# 情感神经科学（Affective Neuroscience）

情感神经科学（Affective Neuroscience）研究大脑如何处理情绪，由Jaak Panksepp于1990年代初命名，填补了认知神经科学长期忽视情感的空白。该领域对于理解意识的情绪维度、[[内感受与意识]]的整合机制以及意识的主观质性（qualia）具有重要意义。

## 核心脑区

| 结构 | 功能 |
|------|------|
| 杏仁核（Amygdala） | 检测情绪显著性，学习哪些刺激具有情绪意义，产生恐惧反应 |
| 海马体（Hippocampus） | 情绪记忆的编码与提取 |
| 扣带皮层（Cingulate Cortex） | 情绪体验的意识化、疼痛感知 |
| 眶额皮层（Orbitofrontal Cortex） | 情绪决策、奖励评估 |
| 岛叶（Insula） | 内感受（身体内部状态的感知），连接生理状态与情感体验 |

Panksepp确认了七个基本情感系统（SEEKING/RAGE/FEAR/LUST/CARE/PANIC/PLAY），认为这些系统跨哺乳类动物高度保守，为情感的进化普遍性提供了神经基础。

## 与意识研究的关联

- **情感是意识的核心**：Antonio Damasio的研究表明，缺乏情感处理的理性决策能力同样受损——情绪不是"意识的杂质"，而是其构成要素
- **[[内感受与意识]]**：岛叶作为内感受中枢，将心跳、呼吸等身体信号整合为情绪体验，内感受信号塑造意识的"自我感"
- **[[预测加工理论]]**：情绪是预测处理框架中的"预测误差信号"——情绪告诉大脑当前状态偏离了预期，驱动行为调整
- **[[濒死体验NDE]]**：NDE中报告的"压倒性爱与宁静"涉及情感神经系统的极端激活，Panksepp的CARE和PANIC系统可能在临终状态下出现异常解除抑制
- **[[冥想修行体系]]**：慈悲冥想（Loving-Kindness）的神经机制正是通过脑岛和TPJ的激活实现情感共鸣的可训练性，与Panksepp的CARE系统高度对应
- **[[情感-意识-非局域信息桥接]]**：岛叶-杏仁核-扣带皮层回路作为情感强度→过滤器渗透率→Psi效应量的完整因果链的神经解剖基础

## 与跨物种意识的关联

Panksepp的七大基本情感系统在哺乳动物（甚至鸟类）中均可识别，为[[跨物种意识]]提供了情感层面的证据——意识不是人类专属，情感体验在进化中具有深层连续性。
