# 赛斯资料

《赛斯资料》（The Seth Material）是美国通灵者简·罗伯茨（Jane Roberts, 1929-1984）通过与非物质实体"赛斯"（Seth）的对话创作的灵性哲学系列，1963年至1984年间持续产出，是[[超心理学]]与灵性运动的核心文本之一。

## 核心教义

| 概念 | 内容 |
|------|------|
| 现实创造 | "你创造自己的现实"——信念、思想和情感投射为外在体验 |
| 多重现实 | 宇宙是多维的，每一选择产生"可能性现实"分支，类似[[信息矩阵现实|量子多世界模型]] |
| 意识本质 | 意识是宇宙根本，物质是其投射；一切存在都源自"一切万有"（All That Is） |
| 时间观 | 时间是物质层面的幻象；高维中时间是同时性的，过去/现在/未来并行存在 |
| 多重生命 | 灵魂同时在多个维度体验不同生命（simultaneous lives），非线性轮回 |

## 与其他框架的关联

- 与[[I+C+S统一场论]]的信息本体论高度共振：意识先于物质
- 与[[区块宇宙模型]]的"时间同时性"概念平行
- 与[[阿卡西记录]]：赛斯材料中描述的宇宙意识档案与阿卡西记录功能一致
- 与[[全息原理]]：全息宇宙中每部分包含整体，呼应赛斯的"意识全息性"
- 与[[轮回转世研究]]：赛斯的"同时性多重生命"挑战传统轮回的线性模型

## 方法论

赛斯通过简·罗伯茨的深度催眠/出神状态（trance state）传递信息，丈夫罗伯特·巴茨负责文字记录。从1963年到简去世，产出包括《灵界的讯息》（Seth Speaks）、《个人实相的本质》（The Nature of Personal Reality）等系列著作。

## 矛盾与争议

简·罗伯茨晚年死于类风湿性关节炎，与赛斯"信念创造现实"的教义形成悖论——她未能通过改变信念疗愈自身。支持者解释为"潜意识信念"层面的抵抗；批评者视之为教义失效的证据。

主流学界将《赛斯资料》归类为新纪元灵性文学，而非科学文本。其"意识创造现实"框架与[[预测加工理论]]存在表面相似但机制不同。

## 历史地位

在[[超心理学]]史上，赛斯资料是20世纪最广泛传播的通灵材料之一，影响了新纪元运动并为后来的[[量子疗愈催眠技术QHHT]]等实践提供了理论基础。

## 赛斯与块宇宙/非局域意识框架的交叉解读

从[[区块宇宙模型]]和[[非局域意识]]框架看，赛斯20世纪60-70年代所描述的形而上学与现代量子物理学的核心概念高度对应：

| 赛斯命题 | 现代物理/意识科学对应 |
|---------|-------------------|
| 时间是幻象，高维中一切时间并存 | 块宇宙四维时空；同时性的相对性 |
| 意识先于物质，物质是意识投射 | 意识本体论优先层；Wheeler的It from Bit |
| 可能性现实的分支 | 量子多世界诠释 |
| 梦境访问多维现实 | 过滤器松开时的非局域信息访问 |
