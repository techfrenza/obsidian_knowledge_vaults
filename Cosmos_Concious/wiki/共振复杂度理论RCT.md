# 共振复杂度理论RCT

共振复杂度理论（Resonance Complexity Theory, RCT）由Michael Arnold Bruna（2025年）提出，主张**意识从神经振荡活动的稳定干涉模式中涌现**，这些模式必须超过复杂性、相干性、增益和分形维度的临界阈值才能产生意识体验。

## 核心命题

**意识 = 自我维持的时空吸引子**。当神经振荡通过建设性干涉和递归反馈形成稳定的时空吸引子时，意识作为场动力学的自然结果而涌现。

与[[整合信息理论IIT]]的关键区别：IIT聚焦信息整合的数学结构（Φ值），RCT提供**具体物理实现机制**——波干涉、相位同步和递归反馈。

## 复杂度指数（CI）

$$CI = \alpha \cdot D \cdot G \cdot C \cdot (1 - e^{-\beta\tau})$$

| 分量 | 含义 |
|------|------|
| D（分形维度） | 共振模式的嵌套空间复杂性 |
| G（信号增益） | 振荡活动的整体能量/幅度 |
| C（空间相干性） | 跨场的相位对齐程度 |
| τ（吸引子停留时间） | 共振配置的时间稳定性 |

**乘积形式的意义**：所有分量必须同时存在；任一因素缺失，CI归零，无意识涌现。

## 五条基础公理

1. 干涉产生稳定波模式
2. 吸引子从稳定、递归的波模式中形成
3. 吸引子跨时间和尺度分层嵌套（慢波为快波提供脚手架）
4. 信息存储在波的几何形态中（类似全息压缩）
5. **波模式即体验本身**——吸引子不是体验的表征，而是体验本身

## 神经振荡层级与意识

| 频段 | 功能 |
|------|------|
| Delta/Theta（1-8 Hz） | 广域整合的慢波脚手架 |
| Alpha/Beta（8-30 Hz） | 认知协调与注意调制 |
| Gamma（30-100 Hz） | 局部高分辨率同步，感知整合 |

关键：高频gamma活动只有在被低频慢波锚定（phase-locking）时才有意义——**嵌套干涉晶格**（nested interference lattice）。

## 濒死状态的意识涌现

与[[濒死体验NDE]]相关的直接实验证据（Borjigin等，2013年，PNAS）：大鼠心跳停止后30秒内，出现**全局同步gamma振荡激增**，前后向皮层连接性超过清醒状态5-8倍，theta-gamma跨频率耦合增强。这为濒死体验的高清晰度报告提供了神经生理学框架。

## RCT与IIT的互补

RCT不是替代IIT，而是为IIT的抽象因果结构提供**物理实现机制**。CI可能是Φ的经验代理——基于可测量的时空共振而非假设性的因果结构计算。

## 矛盾与争议

RCT目前是独立研究者的预印本理论（arXiv 2025），尚未完整通过同行评审。CI的精确阈值缺乏来自人类神经影像的直接验证。数学框架完整，但神经生物学细节（如突触可塑性、神经调质）被简化处理。
