# Courtney Brown与法赛研究所

考特尼·布朗（Courtney Brown）是美国埃默里大学（Emory University）政治学终身教授，同时是民间遥视领域最具系统化推动力的人物。他将冷战时期的军方遥视技术带入现代互联网时代，并创立了**法赛研究所（The Farsight Institute）**。

## 双重身份

| 层面 | 内容 |
|------|------|
| 学术身份 | 埃默里大学政治学终身教授，专长定量研究方法、高级统计学、非线性数学建模 |
| 边缘探索 | 1990年代跟随前军方遥视教官 Ed Dames 系统学习结构化遥视（SRV） |

他的数理统计背景使其在设计遥视实验时拥有极强的规范性。

## 法赛研究所（1995年创立）

**科学去盲实验协议**：遥视者在"双盲"乃至"三盲"状态下进行感知，不知道目标的任何信息——包括时间、地点、类别。多名独立遥视者结果经过交叉比对与统计概率分析。

**透明化贡献**：将大量遥视过程完整录制为视频，公开受试者原始笔录和手绘图纸，展示异常认知如何从潜意识"翻译"成物理图像。

## 核心研究项目

- **时间线遥视**：针对未来全球重大灾难、气候变化或地缘政治进行多重时间线遥视
- **地外智能考古**：遥视古代金字塔建造过程、火星历史、地外文明设施结构
- **UAP现象深度透视**：针对回收外星飞行器界面、EBO生理特征进行战术级遥视反向工程
- **"保险库（The Vault）"**：数十年遥视文字记录数据仓库

## 理论主张（争议性高）

布朗通过法赛研究所提出的宇宙观包含高度推测性内容：
- 人类本质是 ISBY（不朽的精神生命体），肉体仅为载体
- 地球被描述为运营中的"监狱行星"
- 两派外星文明（自由意志派 vs 威权派）之间的干预

> **注意**：上述主张属 [E] 级证据——无法溯源，自我引用循环风险高。与科学遥视协议本身的方法论质量须分开评估。

## 科学评价的分歧

| 立场 | 观点 |
|------|------|
| 支持者 | 利用贝叶斯概率和定量方法，为ESP提供了可重复、可标准化的实验范式 |
| 科学批评者 | 选择目标"不可证伪"（如遥视数万年前的火星），归为伪科学 |
| 军方流派批评 | 将遥视"娱乐化"和"科幻化"，损害领域严肃性 |

## 矛盾与争议

布朗证明了即使在双盲条件下，多个独立遥视者可产生高度同构的细节描述（[C]级），但他所选择的**不可证伪目标**使统计验证从根本上无法完成。这与 [[Hal Puthoff与SRI遥视研究]] 和 [[Edwin C. May星门计划科学总监]] 采用可验证目标的科学路径形成对比。
