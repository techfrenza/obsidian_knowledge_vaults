# 怀特海过程哲学

阿尔弗雷德·诺思·怀特海（Alfred North Whitehead，1861–1947）在《过程与实在》（*Process and Reality*，1929）中建立的**有机哲学**（Philosophy of Organism），以**过程、创造性与相互依存**取代传统实体哲学，是20世纪最重要的形而上学体系之一。

[Source: raw/Process and Reality by Alfred North Whitehead  Literature and Writing  Research Starters.md]

## 核心命题

**宇宙是过程而非实体。** 传统哲学以静态"实体"（substance）为基础；怀特海以"实际事件"（actual occasions）为最终实在——每个事件在生成（becoming）中存在，在消逝中被后继事件所继承。

> "That *how* an actual entity *becomes* constitutes *what* that actual entity *is.*"

## 范畴体系

### 终极范畴：创造性（Creativity）

创造性是宇宙的最高形而上学原理，一切事物（包括上帝）都从属于此原理。创造性也是**新颖性**（novelty）的原理——解释宇宙中新事物不断涌现的根本原因。

### 存在范畴（八类）

| 范畴 | 说明 |
|------|------|
| 实际实体（Actual entities） | 宇宙的终极事实，替代传统"特殊实体" |
| 把握（Prehensions） | 实体间的具体关系，携带情感、目的、因果 |
| 关联（Nexūs） | 实际实体在一起性中的特定事实 |
| 主观形式（Subjective forms） | 把握的内在特质 |
| 永恒客体（Eternal objects） | 纯粹潜在性，类似柏拉图理念 |
| 命题（Propositions） | 真/假的潜在性 |
| 多元性（Multiplicities） | 多元实体的析取 |
| 对比（Contrasts） | 把握中的综合模式 |

### 双极结构（Dipolar Structure）

每个实际事件具有：
- **物理极（Physical pole）**：与其他已成为事件的把握——接受因果影响
- **心理极（Mental pole）**：对永恒客体的把握——引入新颖性与目的

此结构提供了一种非笛卡尔的心物解决方案：**一切事件都有某种程度的"经验"（experience）**，意识是高层级经验的涌现形式。

## 感受的优先性（Primacy of Feeling）

怀特海以**感受（feeling）**取代海格尔的范畴思维层级。宇宙在最底层是"向量感受"（vector feelings）的系统：
- 因果关系在感受层面被直接感知（非休谟归纳推断）
- 主观性不是人类专属，而是宇宙的基本属性
- 这构成了**泛经验论（panexperientialism）**的哲学基础

## 汇聚（Concrescence）与满足（Satisfaction）

实际事件经历**汇聚**——将各种把握整合为最终统一状态（满足）。满足后事件客观化，进入其他事件的构成，实现"客观不朽"（objective immortality）。

主观目标（Subjective aim）：每个事件向其自身终极实现的内在"诱引"——对应上帝在过程中发挥的**lure for feeling**作用。

## 上帝的双重本性

| 本性 | 特征 | 说明 |
|------|------|------|
| 原始本性（Primordial nature） | 自由、完整、永恒、缺乏完全现实性 | 无限潜在性的统一，包含所有永恒客体，是宇宙的"诱引" |
| 后继本性（Consequent nature） | 被决定、不完整、永续、完全现实 | 对世界事件的反应，将时间事件"拯救"入自身生命 |

上帝不是宇宙的例外，而是形而上学原理的**首要例证**。上帝被世界所制约，同时将世界转化后传回——"伟大的伴侣，能理解的共同受苦者。"

## 矛盾与争议

- **可证伪性**[C]：怀特海的形而上学体系过于宏大，难以接受具体实验的直接检验，被许多分析哲学家视为"思辨过度"
- **意识扩展的边界**[C]：若所有事件都有"经验"，经验的最低限度如何界定？避免泛心论的空洞化
- **反驳康德的理由**[C]：怀特海宣称回归前康德思维，但批评者认为其体系只是另一种先验建构
