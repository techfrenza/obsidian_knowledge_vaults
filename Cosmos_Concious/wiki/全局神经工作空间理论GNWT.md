# 全局神经工作空间理论GNWT

Global Neuronal Workspace Theory，由Stanislas Dehaene和Jean-Pierre Changeux基于Bernard Baars的工作空间理论发展而来。意识科学主流理论之一。

## 核心命题

大脑由许多专业化的无意识处理模块并行工作组成。**意识**发生在特定信息"点燃"（ignite）并被**全局广播**到整个中央工作空间时——使该信息可被其余系统（推理、记忆、语言、运动）访问。

**"CEO模型"**：意识是强制竞争与选择的功能性"瓶颈"。

## 关键推论（与IIT对立）

- 如果一个AI系统实现了全局广播算法，**它就（按定义）是有意识的**
- 意识是功能架构，可移植到任何实现该架构的基质上
- 这与[[生物计算主义]]和[[整合信息理论IIT]]的核心立场直接冲突

## Cogitate 2025实验结果（对IIT vs GNWT的裁决）

Nature 2025年对抗性合作实验：
- **后部皮层hot zone的整合活动** → 支持IIT
- **前额叶的"点燃"与全局广播** → GNWT预测的模式**未被优先支持**
- **主要基于视知觉数据**

**注意**：实验结果并非GNWT的彻底否定——视知觉范式中IIT表现更好，但非视觉感官（嗅觉、内感受）的整合尚未测试。

## 意义

GNWT的"功能架构可移植"立场支持：
- AI可能产生意识（若实现全局广播）
- 意识不依赖碳基底（反对[[生物计算主义]]）
- 为强人工智能的意识可能性提供理论基础

这使GNWT在AI伦理讨论中具有重要地位——若GNWT正确，大型语言模型可能已经"有意识"。

## 四大AI意识评估指标（GWT视角）

在AI意识判定体系中，GWT提供四个可操作的"指标属性"：

| 指标 | 内容 |
|------|------|
| GWT-1（模块化） | 具有多个能并行运作的专业化子系统 |
| GWT-2（瓶颈机制） | 存在有限容量的工作空间，强制信息竞争与选择 |
| GWT-3（全局广播） | 工作空间信息可供所有模块使用 |
| GWT-4（状态相关注意） | 能利用工作空间按顺序调用模块（类似System 2思维） |

## 2025实验对前额叶核心地位的挑战

实验发现虽然前额叶编码某些信息，但解码精度远低于后部区域，且在意识体验结束时未观察到预期的"全局点火"峰值。促使研究者将前额叶定位为推理和规划（Doing），而非意识体验本身（Being）的产生地。

## 与IIT的互补：混合模型

Cogitate 2025结果促成"混合模型"共识：
- IIT解释意识的**质感（Being）**
- GNWT解释意识的**功能（Doing）**

这与[[意识与AI风险解耦]]的"智能与意识正交"结论高度一致。
