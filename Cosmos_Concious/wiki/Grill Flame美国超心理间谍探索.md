# Grill Flame美国超心理间谍探索

Grill Flame（1978–1995）是美国政府冷战期间最早的超心理军事情报计划之一，属于[[遥视与星门计划]]的前期阶段，由国防情报局（DIA）和陆军情报与安全司令部（INSCOM）联合资助，在马里兰州米德堡执行。

## 项目背景

**苏联威胁驱动**：1970年代情报显示苏联每年投入数亿卢布研究"心理电子学"（psychotronics），美国启动对等研究评估其可行性。Grill Flame是对这一威胁的直接响应。

## 项目演化名称

```
Gondola Wish → Grill Flame → Center Lane → Sun Streak → Stargate
```

## 核心运作

- **基地**：米德堡2560和2561号楼，INSCOM "G分队（Detachment G）"
- **核心遥视者**：Ken Bell、[[Joseph McMoneagle遥视001]]（代号Viewer 001）、Mel Riley
- **方法**：使用[[Ingo Swann受控遥视奠基人]]和[[Hal Puthoff与SRI遥视研究]]开发的坐标遥视（CRV）协议

## 关键任务案例

### Rosemary Smith的苏联飞机定位（1976年）
Rosemary Smith通过遥视准确标示出坠毁于扎伊尔的苏联飞机位置，CIA在两天内找到残骸并回收重要技术。这是项目最被引用的操作性成功案例 [C]。

### 伊朗人质危机监控（1979–1980年）
遥视者被部署用于监控被扣押美国使馆人质，尝试了解他们的位置、健康状况和看守情况。结果的具体性仍有争议 [C]。

### Joe McMoneagle的火星遥视
McMoneagle声称通过遥视"看到"了火星表面百万年前的场景——此说法超出项目正式目标，成为遥视史上争议最大的案例之一 [D]。

## 终止与评估（1995年）

CIA委托美国研究院（AIR）进行回顾性评估，由Jessica Utts和Ray Hyman主导：
- **Utts（支持方）**：遥视产生了统计显著结果，效应量超过许多标准心理学研究 [A]
- **Hyman（怀疑方）**：方法论存在缺陷，无法排除其他解释；未在情报行动中被有效使用 [A]
- **CIA最终决定**：项目终止并解密
