# Psi与Ganzfeld实验

## 核心定义

**Psi（ψ）**是[[超心理学]]的核心术语，指超出已知物理规律的异常心理现象（anomalous mental phenomena）。不预设机制，仅描述统计异常。

## Psi的两大类别

| 类型 | 子类 | 说明 |
|------|------|------|
| 超感官知觉（ESP） | 心灵感应（Telepathy） | 非感官渠道信息传递 |
| | 遥视（Clairvoyance） | 感知远处或隐藏物体 |
| | 预知（Precognition） | 感知未来事件 |
| | 回知（Retrocognition） | 感知过去事件 |
| 意念致动（PK） | 宏观/微观PK | 意识直接影响物理系统（随机数生成器、骰子） |

**特点**：效应微弱（命中率略高于随机）、强调双盲与元分析、与[[量子零点场]]和[[阿卡西记录]]理论有关联但无公认机制。

## Ganzfeld ESP测试

**Ganzfeld**（德语"全场"）是超心理学最标准化的感官剥夺实验协议，由Charles Honorton于1970年代发展完善。

### 实验流程

1. **接收者**：进入感官剥夺状态（乒乓球护目镜+均匀红光、白噪声耳机）
2. **发送者**：在隔离室观看随机选定的目标刺激（动态视频/图片）
3. **任务**：接收者自由报告内在意象，测试后从4个备选（1真+3诱饵）中选最匹配项
4. **评分**：随机命中率25%（4选1）；元分析显示实际命中率约30-32%

### 研究结果

- **支持**：Storm et al. 元分析显示30-32%命中率，统计显著；PRL实验室结果更强
- **争议**：Milton & Wiseman 1999年元分析报告无显著效应；批评者指出发表偏差与方法学问题
- **效应量**：较小但为psi研究中最可靠的协议之一

## 科学地位

主流科学视Psi效应为争议性议题，可能解释包括：
- 真实信息场效应（[[超心理学]]支持者立场）
- 统计假阳性与发表偏差
- 量子纠缠介导的非局域信息传递

Ganzfeld与[[遥视与星门计划]]共同构成超心理学实验证据的两大支柱。

## 关键洞见

反直觉发现：感官**减少**反而使信息接收效率**提高**——与[[过滤器模型]]（大脑作为减压阀）高度一致。当外部噪音被剥夺，内在"信号"更易浮现。
