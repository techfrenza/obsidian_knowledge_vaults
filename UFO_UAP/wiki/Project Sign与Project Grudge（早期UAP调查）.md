# Project Sign与Project Grudge（早期UAP调查）

美国空军1947–1952年间的两个连续 UAP 调查项目，构成官方 UAP 研究史的最早阶段。Sign 初步倾向于地外起源假说，Grudge 明确转向否定性公关任务，共同奠定了此后官方虚假信息政策的制度基础。

## Project Sign（1947–1949）

- **成立背景**：1947年 [[Roswell事件与Ramey Memo|罗斯威尔事件]] 及肯尼斯·阿诺德目击事件后，目击案例激增，空军于 [[赖特-帕特森空军基地（Wright-Patterson AFB）]] 成立第一个正式调查组。
- **初期立场**：部分成员撰写《情势评估报告（Estimate of the Situation）》，得出"UFO 是外星飞船"的正式结论。
- **内部清洗**：报告提交后，空军参谋长霍伊特·范登堡（Hoyt Vandenberg）将军下令**焚毁/销毁**该报告，理由是"缺乏充分证据"。
- **信息架构**：运行于 [[MJ-12委员会（Majestic 12机构独立专条）]] 的限制性信息传递框架下，只有经过筛选的"安全"报告才向后续公开项目传递。

## Project Grudge（1949–1952）

- **任务转变**：接替 Sign 后，核心任务从科学调查转变为**公关驳斥**——通过将目击解释为自然现象、气象气球或飞行员错觉，平息公众焦虑。
- **明确禁令**：明确要求不再考虑地外起源假说（ETH）。最终报告声称已解释69%的报告案例。
- **态度特征**：研究者一致评价 Grudge 的调查态度为"敌对和怀疑"，结论草率。

## 双层机制：公开欺骗与秘密研究

Project Sign → Grudge → [[Robertson Panel（罗伯逊小组）]]（1953）→ [[Condon Committee（科恩登委员会）]]（1968）→ [[AARO]]（2022）构成美国官方UAP态度演变的完整链条。

**双层结构**的关键洞察：

| 层级 | 机构 | 职能 |
|------|------|------|
| 公开层 | Sign / Grudge / Blue Book / Condon | 否定性公关；转移公众注意力；维护保密 |
| 隐秘层 | CIA科学情报处 / 巴特尔研究所 / 私人承包商 | 实质性材料与技术分析；信息流向 [[Legacy Program（遗产计划）]] |

[[政府UAP虚假信息战术]] 中记录的"嵌入真相的毒丸"策略，正是从这一时期的项目运作中制度化的。

## 《情势评估报告》的命运

Sign 所写的地外起源结论报告被销毁一事，是已知最早的官方 UAP 信息压制文件记录案例（B 级证据：机构行为，有当时空军人员证词支撑）。

这一事件证明：至少在1948–1949年，空军内部已存在支持地外起源假说的正式分析意见，随后被行政权力强制压制——与后来 [[Condon Committee（科恩登委员会）]] 的 Low Memo 构成50年政策延续的两端书档。

## 矛盾与争议

- 《情势评估报告》已被销毁，现存内容仅来自当时参与人员的事后回忆（C 级证据），无法独立核实具体结论措辞。
- Grudge 的69%"已解释率"长期受到批评：麦克唐纳等人指出，许多"已解释"案例的解释质量极低，强行归类以完成解释率目标。
