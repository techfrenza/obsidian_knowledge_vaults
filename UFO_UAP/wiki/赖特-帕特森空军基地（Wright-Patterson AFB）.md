# 赖特-帕特森空军基地（Wright-Patterson AFB）

位于俄亥俄州代顿市的美国空军基地，是美国最大的空军基地之一，同时也是 UAP 研究者和吹哨人证词中出现频率最高的设施，被描述为美国 UAP 回收飞行器研究和非人类实体（EBE）存储的核心地点。[Source: raw/赖特-帕特森空军基地、秘密站点、机密计划、北欧人型实体、银河联邦及NHI层级体系.md]

## 历史背景

**官方功能**：
- 美国空军材料司令部（AFMC）总部
- 空军研究实验室（AFRL）
- 外来技术部（Foreign Materials Division / FTD）

**UAP 历史关联**：
- 项目蓝皮书（Project Blue Book，1952–1969）的运行基地
- 1947年罗斯威尔残骸据称被运送至此
- 1933年意大利马真塔坠毁飞行器据称最终转移至此（见[[1933年意大利马真塔UFO坠毁事件]]）

## 核心设施：18号机库与蓝实验室

### 18号机库（Hangar 18）
UAP 研究者证词中反复提及的设施，据称是非人类起源飞行器（NHI aircraft）和生物残骸的存储地点。

**相关证词**（均为 C/D 级）：
- 前国会议员 Barry Goldwater 曾多次尝试获得访问权，均被时任 Curtis LeMay 将军拒绝，据 Goldwater 描述 LeMay 的拒绝"措辞极为强烈"
- 多名前飞行员和情报官员在国会证词中提及"代顿的18号机库"为存储设施

### 蓝实验室（Blue Lab，编号 WP-61）
根据[[MJ-12特种作战手册（SOM-1）]]中的描述，蓝实验室（亦称"蓝室"）专门负责：
- 接收和编目从坠毁事件回收的非人类生物实体（EBE）遗体
- 处理和分析回收的飞行器残骸构件

## 相关秘密计划

与赖特-帕特森直接关联的计划代号：

| 计划 | 功能 | 与基地的关系 |
|------|------|------------|
| Project Blue Book | 1952–1969年官方 UFO 调查 | 运行基地 |
| Project Blue Fly | 快速反应坠毁回收 | 回收飞行器的最终目的地 |
| Project Moon Dust | 全球航天器残骸回收 | 接收和分析节点 |

## 与其他保密设施的关系

赖特-帕特森在 UAP 秘密设施体系中的位置：

```
坠毁/回收事件（现场）
    ↓
Project Blue Fly（快速响应）
    ↓
赖特-帕特森 18号机库/蓝实验室（初步分析存储）
    ↓
Area 51/S4（深度逆向工程）
```

这一链条来自多个独立但彼此引用的证词，整体属于 C 级证据层级。

## 认识论评估

赖特-帕特森在 UAP 叙事中的特殊之处在于它同时兼具：
1. **真实已知的秘密技术历史**：基地确实运行了大量与外国技术分析相关的高度保密计划（如苏联飞机分析）
2. **无法独立核实的 UAP 声明**：EBE 存储和 UAP 残骸声明从未获得文件支持

这种混合性质使其成为 UAP 叙事中最难评估的设施之一——技术保密的真实性为 UAP 声明提供了可信度背景，同时也使真正秘密与 UAP 叙事的边界永久模糊。

## 矛盾与争议

- **Goldwater 的尝试**：Barry Goldwater 在多封公开信件中确认了他被拒绝访问的经历，这是该设施存在高度保密区域的 B 级证据，但不能证明保密内容为 UAP 相关
- **公开与保密的界限**：基地的公开官方功能（材料测试、飞机开发）提供了将任何异常活动归入常规保密的合理封面
