# 莫苏尔球体（Mosul Orb）

2022年由美军 MQ-9 无人机在伊拉克莫苏尔上空拍摄的金属球体 UAP 案例，通过《信息自由法》（FOIA）披露后成为近年最受关注的政府确认 UAP 记录之一。AARO 前负责人公开承认"全球各地均有此类球体进行有趣机动"。

## 事件记录

- **拍摄时间**：2022年4月16日（部分报告称2022–2023年之间）
- **拍摄平台**：美军 MQ-9 侦察无人机，伊拉克莫苏尔市上空
- **披露方式**：通过 FOIA（信息自由法）申请获得解密
- **追踪时长**：传感器追踪约8–10秒（不同来源报告有差异）

## 物理特征

| 特征 | 描述 |
|------|------|
| 形态 | 小型固体金属球体（Metallic Orb），颜色为黑暗或银色 |
| 尺寸 | 约2英尺直径（或智能汽车大小，来源有差异） |
| 推进 | 无任何可见推进装置 |
| 运动 | 保持恒定方向和速度飞行；热红外对比度清晰 |
| 机动 | 在密集城市区域上空高速穿过；或在战斗群附近缓慢移动 |

满足 [[五项可观测指标（Five Observables）]] 中的：低可观测性（无热尾迹）、反重力升力（无推进装置）。

## 官方态度

- **肖恩·柯克帕特里克（Sean Kirkpatrick，AARO前负责人）** 公开承认："全球各地都有这种金属球体在进行有趣的机动。"
- **Tim Phillips（AARO代理主任）** 证实：此类"金属球体"或"火球"自1944–1945年以来就持续出现在政府报告中，始终未得到解释。
- **约翰·科索斯基（John Kosowski，现任）** 承认对这种"真正的异常"感到困惑，现有数据不足以支持结论性分析。

## 在UAP球体现象中的位置

莫苏尔球体是全球金属球体 UAP 现象的最新高质量军方记录，与以下案例构成连续证据链：

| 案例 | 时间/地点 | 特征 |
|------|----------|------|
| Foo Fighters（火球战斗机） | 1944–1945年，欧洲/太平洋战场 | 紧随战斗机飞行的发光球体 |
| [[布加球体（Buga Sphere）]] | 2012年，哥伦比亚布加市 | 公开视频记录，Garry Nolan"99%地球制品"评估存争议 |
| 莫苏尔球体 | 2022年，伊拉克 | MQ-9 热成像确认；FOIA 解密；官方承认异常 |

[[Patrick Jackson球体网络理论]] 将全球范围内的金属球体解释为单一 AI 网络的前端节点，与 [[冯·诺依曼探测器（Von Neumann Probes）]] 的理论预测一致。

## 矛盾与争议

- AARO 官方态度：承认异常性，但拒绝提供技术性解释或分类。
- 部分分析者认为球体可能是高级侦察气球或未知地球制造物（D 级推测）。
- 仅有约8–10秒的传感器追踪，数据量不足以排除常规解释——这一点与 [[Tic Tac事件与海洋探针假说]] 中的多传感器融合数据相比显著薄弱。
