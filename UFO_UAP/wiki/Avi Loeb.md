# Avi Loeb

以色列裔美国天体物理学家，哈佛大学天文学系前系主任。UAP/星际物体研究领域唯一进入全球顶尖主流学术机构核心的人物，以公开主张'Oumuamua可能具有人工起源而引发广泛争议。

## 学术背景

| 项目 | 内容 |
|------|------|
| 机构 | 哈佛大学天文学系，曾任系主任（2011–2020） |
| 研究领域 | 宇宙学、第一代恒星、黑洞、星际物体 |
| Galileo Project | 2021年创立，专门以科学仪器寻找地外技术签名（technosignatures） |

## 核心贡献

### 'Oumuamua假说（2017）
- 首个经过太阳系的已知星际天体，运动轨迹存在非引力加速
- Loeb提出其可能是外星文明的光帆或废弃探测器 [C]
- 主流天文学界倾向于彗星脱气或非标准天体解释 [A/B]
- 争议核心：非引力加速的物理机制至今无定论

### 3I/ATLAS（2025）
- 第三个已知星际物体，Galileo Project第一时间参与观测

### Galileo Project
- 在哈佛园区部署多传感器阵列监测异常空中现象
- 目标：以可重复、同行评审的方式收集UAP数据，脱离证词依赖

## 认识论立场

Loeb是UAP研究中最鲜明的"科学方法优先"倡导者：拒绝内部人士证词，强调仪器数据；批评UAP研究界过度依赖叙事而非测量。这使他与[[David Grusch]]式的吹哨人路径形成方法论对立。

## 矛盾与争议

- 部分天文学家批评他将'Oumuamua的外星假说过度推广，损害了科学公信力 [A级反驳：多篇Nature/ApJ论文提供替代解释]
- Galileo Project迄今未发布经同行评审的UAP发现
- 支持者认为他是将UAP研究带入主流学术的唯一可行路径
