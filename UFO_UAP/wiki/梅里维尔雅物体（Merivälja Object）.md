# 梅里维尔雅物体（Merivälja Object）

1969年在爱沙尼亚塔林郊区梅里维尔雅发现的地下不明金属物体。KGB介入调查长达数十年，材料分析显示其合金特性在地球条件下无法制造。欧洲最著名的潜在非人类技术遗迹案例之一，全部证据属C/D级（无物体本体公开展示）。

[Source: raw/苏联不明飞行物秘密档案.md]

## 发现经过

- **时间**：1969年夏季，爱沙尼亚塔林皮里塔区，Hõbekuuse tee 34号私人住宅
- **发现者**：维尔戈·米特（Virgo Mitt，汽车修理工兼岩石收藏者）与妻子维薇卡-埃维·米特在挖井时于地下约6.5–8米深度撞击到极硬金属物体
- **初步处理**：维尔戈用气动钻头连续敲击数日才打下碎片；大部分碎片被浇筑进井壁，少量保留为矿物标本
- **推测规模**：Igor Volke等研究者根据磁力测量推测地下存在两个物体：椭圆盘状主体（约17×22米）与手榴弹状模块（约2×4米）

## KGB调查过程

| 阶段 | 内容 |
|------|------|
| 1969–1970年代 | 爱沙尼亚科学院地质所赫伯特·维伊丁初步分析 |
| 1970–1980年代 | 莫斯科国防部实验室亚历山大·杰耶夫长期驻点，竖井挖掘至10米+ |
| 1980年代后期 | 莫斯科方面携装满美元的外交箱高价购买房产（被拒绝） |
| 文件状态 | 全部标注"绝密"，至今未完全解密 |

## 材料分析

| 测试机构/时期 | 结论 | 层级 |
|-------------|------|------|
| 爱沙尼亚科学院（1969–1970年代） | 40+种元素合金，物理上不可能在地球制造；暗示在无重力环境中冷却成型 | [C] |
| 苏联国防部实验室（1970–1980年代） | 判定为"极度异常"，列为绝密 | [C] |
| 后续测试（2012–2017年） | 给出较平庸结论，研究者质疑样本真实性 | [D]（存疑） |

**核心异常**：合金含40+种元素（含铁、钛等），物理特性显示其在无重力环境中凝固，地球重力效应缺失。

## 异常现象记录

- **电磁干扰**：设备失灵、GPS/声纳故障、传感器损坏
- **Poltergeist效应**：书籍自行飞过房间、枕头被撕碎、家犬对不可见物体狂吠
- **健康损害**：接触碎片者出现烧伤、心力衰竭、精神问题；房主维尔戈后来瘫痪，其子出生时患有罕见脑损伤；多名参与调查的官员"事后很快去世"（无法独立核实）
- **物理反击**：一名实验室助理接触碎片时遭强烈电击并失去知觉

## 当前状态

- 物体据信仍深埋原址，保护层从未被突破
- 现任房主拒绝研究人员使用地质探测雷达进行非侵入性扫描
- 在爱沙尼亚已成为"国家神话"，核心物证和原始碎片照片至今缺失

## 矛盾与争议

- 2012–2017年后续测试给出平庸结论，但研究者指出无法确认测试样本是否为原始碎片（可能已被替换）——这一不确定性使早期异常分析结论既不能被证实也不能被推翻
- Poltergeist效应与健康损害的因果关系从未经过独立科学调查，所有相关描述来自单一信源链（Volke通过受害家庭转述）
- 苏联"携外交箱美元购地"的细节未见独立文件，属二手口述 [D级]
