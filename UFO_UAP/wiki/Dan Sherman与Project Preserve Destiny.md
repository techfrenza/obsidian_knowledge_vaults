# Dan Sherman与Project Preserve Destiny

丹·舍曼（Dan Sherman），美国空军退休技术中士，声称被NSA招募参与代号"命运预留计划"（Project Preserve Destiny, PPD）的极机密心灵感应通信项目，因基因改造而具备"直觉传达者"（Intuitive Communicator）能力。

## 项目结构

| 要素 | 内容 |
|------|------|
| 掩护身份 | 电子情报（ELINT）专家 |
| 真实身份 | NSA招募的直觉传达者 |
| 项目分类 | "灰色项目"——隐藏在"黑色项目"之内的更高级别机密 |
| 设施地点 | NSA地下设施 |

## 跨代基因操纵

- 舍曼被告知，其母亲在1960年代怀孕期间被外星人绑架，外星人对胎儿时期的他进行了**基因改造（Genetic Management）**
- 这种操纵使其具备成为"直觉传达者"的生物学基础
- 支持John Ramirez关于CIA研讨会上提及外星人DNA与人类混合体的报告（参见[[John Ramirez：CIA基因研究声明]]）

## 训练方法

1. **心理哼鸣训练**：通过耳机听取特定音调，在大脑中进行心理哼鸣，直到能通过意识控制电脑屏幕上的正弦波对齐
2. **药物辅助**：每日服用两种无味药片，据信增强大脑特定区域功能
3. **感知开发**：训练将外来信息与自身思维明确区分（描述为"大脑织锦"）
