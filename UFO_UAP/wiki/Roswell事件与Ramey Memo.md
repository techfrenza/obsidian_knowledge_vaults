# Roswell事件与Ramey Memo

1947年7月初新墨西哥州的不明物体坠毁事件，是现代UAP披露运动的核心历史节点。军方最初公告"回收飞碟"，数小时内改口为"气象气球"。Ramey Memo（含义模糊的照片中电报）成为双方争议最持久的实物证据。

## 基本时间线

| 日期 | 事件 |
|------|------|
| 1947年7月初 | 不明物体在新墨西哥州Corona附近坠毁 |
| 1947年7月8日 | RAAF公共信息官Walter Haut发布新闻稿："回收一架飞碟" |
| 1947年7月8日（数小时后） | Eighth Air Force指挥官Roger Ramey在Fort Worth召开新闻发布会，改称"气象气球及Rawin雷达目标" |
| 1990年代 | 空军报告将坠毁物归因于Project Mogul（监测苏联核试验的秘密气球项目） |

## Ramey Memo的争议

Ramey在新闻发布会照片中手持一份电报，与DuBose上校和Marcel少校同框，旁边是"气象气球残骸"。

### UFO研究者解读（David Rudiak等）
- 识别出关键词："DISK"（飞碟）、"VICTIMS OF THE WRECK"（残骸受害者）
- 解读：电报提及将"飞碟"和"尸体"送往Wright Field，同时使用"气象气球"作为掩盖叙事
- Danny Sheehan声称在1970年代通过耶稣会联系进入National Archives，看到放大后的电报包含"DISC"和"BODIES"字样

### 质疑与反驳
- 原始照片（Bettmann Photo Archives）质量低，文字模糊；1994年空军报告称无法通过数字化处理清晰辨认
- 批评者质疑：处理机密材料的将军不太可能在新闻发布会上公开持有敏感电报
- 近期AI分析尝试生成内容，但未获广泛认可，可能是AI基于既有UFO叙事的推测
- 2002年Journal of Scientific Exploration研究：解读受研究者信念影响，不同条件下识别词语存在差异

## Matilda MacElroy案例的关联

Roswell幸存外星人"艾罗"（Arrol）的案例声称始于同一事件，详见[[玛蒂尔达·麦克尔罗伊与艾罗案例]]。

## 意义

- 成为"政府掩盖外星存在"叙事的核心参照点
- 1994–1997年空军报告承认无任何飞机坠毁记录，但也未找到外星证据
- 奠定[[Legacy Program（遗产计划）]]起源神话
- 参见[[Kecksburg事件（1965年宾夕法尼亚州坠落物）]] — 同时代的类似坠落物回收与军方掩盖事件，二者模式高度相似

## 矛盾与争议

- Project Mogul解释提供技术替代方案，但无法完全解释"受害者"描述
- 社会背景：1947年冷战初期，公众对飞碟兴趣高涨，可能影响早期报道和集体记忆
- Ramey Memo解读存在确认偏误风险
