# NHI实体分类体系（Skywatcher视角）

根据 [[Project Skywatcher|天眼计划]] 中 [[James Fowler]] 与团队的系统分类，基于高物理传感器数据、高光谱图像与灵能/意识交互记录，观测到的不明异常现象被归纳为11个核心飞行器/实体类别。

## 11个UAP类别

### 1. 光球/能量球体（Orbs / Spheres）
- **特征**：最常见形态，高发光球体（白光、金光、橙光或蓝光）
- **行为**：无视空气阻力悬停、高速转向、"8字型"或急锐角飞行
- **交互**：对人类意识或电磁信号产生直接回应

### 2. 蛋形/无缝椭圆体（Egg-shaped / Ovoid Craft）
- **特征**：长约20英尺珍珠白色无缝体，表面极度光滑
- **无**：可见推进系统、接缝、窗户或尾喷
- **案例**：[[Jake Barber]]与[[J2（James Hodgkins）]]驾驶过的"Nanu"蛋形飞行器

### 3. 黑色三角形（Black Triangles）
- **特征**：等边或等腰三角形，哑光黑，三角顶端有发光灯头，中央圆核发光
- **能力**：低空极慢速完全静音盘旋，目击者眼前直接改变外观（伪装成民用客机）

### 4. 八角形/多边形碟体（Octagonal / "8-Gon" Craft）
- **特征**：八个对称部分组成，结构极其规整
- **交互**：与高阶意识接口绑定，回收过程伴随强烈感情/心理冲击

### 5. Tic Tac形/飞艇体（Tic Tac / Capsule Craft）
- **特征**：胶囊或Tic Tac软糖外形，纯白色，无翼无尾，两侧微小柱状凸起
- **行为**：极高加速度，海面与万米高空瞬间垂直移动，无音爆或热迹

### 6. 金属圆盘/经典飞碟（Metallic Discs / Flying Saucers）
- **特征**：传统碟形，金属质感（银色、铜色或珍珠白），中间圆顶
- **痕迹**：低空着陆时地面发热电磁印记或电子设备瘫痪

### 7. 跨介质/水下异常物体（Transmedium / USOs）
- **特征**：无缝在太空、大气层、低空、海洋间穿行
- **行为**：入水出水无水花或激波，完全无视流体力学阻力

### 8. 等离子体/形态改变体（Plasma / Polymorphic Entities）
- **特征**：非固定硬质结构的流体形态，发光等离子体或变形能量块
- **行为**：飞行中分裂成多个小球体或聚合成大型整体，高度自我修复

### 9. 巨型结构/母船（Large Scale Structures / Motherships）
- **特征**：数百英尺甚至足球场大小，雪茄形、巨大圆盘或金字塔形
- **功能**：高空或深空悬停，作为小型球体/侦察飞行器的释放与回收平台

### 10. 跨维度"门户"与光斑（Dimensional Portals / Flashers）
- **特征**：非实体飞船，空中无预警光爆发、裂隙或橙色/蓝色"门户"球体
- **功能**：其他飞行器或实体直接从光斑/门户驶出或消失，不同维度交织的物理节点

### 11. 拟态/伪装物体（Mimic / Cloaked Craft）
- **特征**：高级主动伪装技术
- **能力**：折射率或云层/大气伪装（伪装成云朵、民用客机、甚至星星），仅在高光谱相机、红外传感器或灵能激活状态下可见

## 关联理论

- **意识-飞行器接口**：多数飞行器与 [[灵能（Psionics）与UAP意识接口|灵能接口]] 相关
- **跨维度性**：门户类和拟态类暗示 [[维度间假说（IDH）]] 的可能性
- **集群行为**：球体常表现编队活动，暗示某种分布式控制或群体意识
