# NHI实体分类体系（Skywatcher视角）

由 [[Project Skywatcher（天眼计划）]]、[[Jake Barber与UAP回收证言]] 及 [[J2（James Hodgkins）人物档案]] 的接触记录综合构建的实体分类框架。与传统UFO学的外星人分类不同，本框架特别强调**意识层次优先于生物形态**，并将部分实体定义为高维意识的物质投射而非独立物种。

## 六类核心实体

### 1. "女士"与高维引导者（The Lady / Higher-Dimensional Guides）

| 属性 | 内容 |
|------|------|
| 外观 | 蓝色光调、庄严美丽的女性跨维度实体 |
| 角色 | 被视为"大揭秘（Disclosure）"进程幕后最高精神引导者 |
| 接触方式 | 通过"灵能覆盖（Cyanetic Overlay）"直接在意识层面指导高阶灵能资产，参见[[意识与UAP技术接口（MOC）]] |
| 功能 | 教导如何驾驶非人类飞行器；展示其他现实平面图景 |

与 [[Chris Bledsoe人物档案]] 中"The Lady"的描述具有高度相似性——独立接触者使用几乎相同的名称描述相似实体。另见 [[Ryan Bledsoe接触经历]] 中家族三代目击同一实体的交叉印证。[C级证据：多独立证人描述相似，但无物理验证]

### 2. 小灰人 / 基因生物（Grays / Genetic Entities）

| 属性 | 内容 |
|------|------|
| 形态 | 矮小体型、大头、斜杏仁黑眼、苍蓝灰色皮肤 |
| 本质界定 | 非拥有独立灵魂的自然演化生物，而是"软组织无人机"或"肉体机器人（Biologics）" |
| 功能 | 高阶智能用于执行地表采样、物理操作和工具任务的生化载体 |

与 [[Dan Burisch人物档案]] 的J-Rod研究形成补充。[[EBO生物特征与嵌合基因组]] 中的16条环状染色体特征与此框架下"人工合成"定性一致。

### 3. 高白人（Tall Whites）

| 属性 | 内容 |
|------|------|
| 形态 | 身高7-8英尺、肤色极度苍白、白发蓝眼 |
| 行为 | 高度组织化、家庭化活动；在特定军方基地区域有固定轨迹 |
| 飞行器 | 等边三角形或蛋形白色飞行器 |

详见独立专条：[[Tall Whites与查尔斯·霍尔（51区共处经历）]]

[D级：亲历者叙事，缺乏物理证据]

### 4. 螳螂人 / 监护者（Mantis / Manted Entities）

| 属性 | 内容 |
|------|------|
| 形态 | 身高7-8英尺，头部与肢体结构酷似螳螂 |
| 能力 | 极强的思维扫描与神经压制能力；可通过心理投影改变外观 |
| 角色 | 在灵能接触过程中充当"指挥者"或"医疗监护者" |

[D级：多位接触者独立描述相似特征，但存在文化采样偏差风险]

### 5. J-Rod 与未来人种（J-Rod / Future Human Biologics）

| 属性 | 内容 |
|------|------|
| 形态 | 与小灰人相似但具备独特的基因退化痕迹与神经结构 |
| 起源假说 | 来自未来时间线的人类演化分支 |
| 互动目的 | 与人类合作进行基因采样，修复自身时间线中的基因缺陷 |

详见 [[Dan Burisch人物档案]]（J-Rod的直接照护记录）。与 [[Mike Masters与未来人类时间旅行假说]] 和 [[Amy Eskridge人物档案]] P47/P52框架形成三角互照。[C/D级证据]

### 6. 不朽精神体与合成载体（IS-BEs / Immortal Spiritual Beings）

| 属性 | 内容 |
|------|------|
| 本质 | 超越肉体的永恒精神存在；可附着于活体神经飞船、合成傀儡或光球 |
| 哲学框架 | 意识大于肉体；三维物理生物是精神存在的可选载体 |
| 相关文本 | [[玛蒂尔达·麦克尔罗伊与艾罗案例]] 中的宇宙论框架 |

[D/E级：高度形而上学，无可证伪的实证锚点]

## 跨类别共性发现

| 模式 | 描述 |
|------|------|
| 意识优先 | 所有高阶实体均通过意识/灵能接口（而非物理手段）与人类互动 |
| 形态可塑性 | 螳螂人、高白人等实体可改变在接触者眼中的外观 |
| 功能分工 | 小灰人/高白人执行工具任务；螳螂人监护；"女士"型实体承担引导/教育功能 |
| 技术-意识耦合 | 飞行器类型与实体类型存在对应关系（高白人↔蛋形白色飞行器；参见[[James Fowler人物档案]] 11类分类） |

## 矛盾与争议

- 此分类框架的全部数据来源均为私人机构内部记录，未经独立机构交叉验证 [C/D级]
- "软组织无人机"定义（小灰人）与[[Deborah Jordan-Kauble（黛博拉·乔丹-考布尔）]]的绑架案例描述（更具自主性的互动）存在明显张力
- 最强反驳论据：所有NHI形态描述均与1950-70年代科幻文化高度重合（选择偏差 vs. 独立描述之争）；接触者背景多为西方文化，缺乏全球文化代表性
- IS-BE框架来自[[玛蒂尔达·麦克尔罗伊与艾罗案例]]（争议性文本）与Scientology创始人Hubbard的"Thetan"概念存在结构性相似 [认识论互保风险]
