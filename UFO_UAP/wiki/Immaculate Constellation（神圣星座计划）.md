# Immaculate Constellation（神圣星座计划）

据吹哨人证词揭示的未公开特别访问计划（Unacknowledged Special Access Program，uSAP），任务是利用美国军事情报资源对全球 UAP 和疑似复制飞行器（ARV）进行系统性图像情报（IMINT）收集，并通过 AI 系统（[[Sentient（NRO AI情报过滤系统）]]）对相关数据进行隔离管理。[Source: raw/Immaculate Constellation.md]

## 发现经过

**时间**：约2018年
**发现方式**：五角大楼一名国防情报官员在整理错误归档文件时意外发现，文件标题伪装为"2018 Shrivever 战争游戏"（无明显分类标记）

**文件结构**（约12–15页）：
1. 通用标题页，仅显示"Immaculate Constellation"名称
2. Luis Elizondo 照片及计划起源说明（建立于 AATIP 2017年曝光之后）
3. 计划任务描述
4. 多个图像情报收集案例

## 计划架构

- **性质**：父级 SAP（Parent SAP），内含多个子级 SAP（"星星"）
- **上级机构**：美国国防情报副部长办公室（USDI）
- **建立背景**：在 Luis Elizondo 2017年辞职并公开披露 AATIP 后建立，属于对此前项目曝光的保密性内部回应

## AI数据隔离机制

文件揭示的关键技术特征：

1. 通过[[Sentient（NRO AI情报过滤系统）]]对进入普通情报渠道的 UAP 数据进行实时拦截
2. 被拦截数据转入 Immaculate Constellation SAP 隔离存储
3. 即使持有最高 SCI 许可的分析人员，若无专项 SAP 授权，仍无法访问这些数据
4. 吹哨人形容这是"两面神（Janus）系统"——向内接收所有数据，向外仅输出经授权过滤的产品

| 机构 | 与 Immaculate Constellation 的关系 |

| 国会 | 吹哨人报告引发 Rubio 参议员质问"执行机构是否绕过国会运作60年" |

## 信源评级与可信度评估

**文件本身**：B/C 级（来自声称亲眼看到文件的单一吹哨人；文件内容已提交国会）
**吹哨人身份**：已向国会提交报告，并通过国务院预出版审查系统（"无需删节"批准）

**支持可信度的因素**：
- 报告已进入国会记录
- Rubio 等参议员对此内容的激烈反应
- 内容与其他独立来源（Grusch 等）的部分描述吻合

## 矛盾与争议

- **单一来源问题**：整个 Immaculate Constellation 叙事主要依赖一名匿名吹哨人，独立验证极其困难
- **计划名称独特性**：吹哨人表示在他自己写报告之前，此前仅见过该名称一次——高度隔离的信息可能也意味着信息不完整或理解片面
- **Kirkpatrick 的回应**：前 AARO 主任从未公开回应对其"歪曲事实"的具体指控
