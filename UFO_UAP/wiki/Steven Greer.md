# Steven Greer

美国急诊科医生，Disclosure Project创始人，CE-5（第五类接触）协议的主要倡导者。UAP研究界最具争议的公众人物之一：既是规模最大的披露运动组织者，也是被研究界批评最多的人物。

## 背景

| 项目 | 内容 |
|------|------|
| 职业背景 | 急诊科医生，1990年代初开始全职从事UAP研究 |
| Disclosure Project | 1993年创立，汇集超过500名政府/军事/情报内部人士证词 |
| CE-5协议 | 基于冥想/意识主动引导的人类发起接触方法，详见[[CE-5协议与意识接触]] |

## 核心贡献

### Disclosure Project（2001年国会新闻发布会）
- 2001年5月在国家新闻俱乐部召开新闻发布会，展示超过20名前政府/军事内部人士证词
- 规模为当时最大的系统性UAP内部人士证词汇集
- 要求美国国会举行UAP公开听证会——这一要求直到2023年才实现

### CE-5协议
- 主张人类可以通过意识技术（冥想、集体意图）主动联系NHI
- 声称已记录超过100次成功接触事件，但均为目击者自述，缺乏仪器数据 [D级]

## 矛盾与争议

- **财务透明度**：批评者指出其组织的财务运作缺乏透明度，捐款使用存疑
- **反军事工业立场**：Greer将几乎所有UAP掩盖归因于"军事工业复合体"，被批评为过度简化 [D/E级推断]
- **被主流研究者孤立**：[[Luis Elizondo]]、[[David Grusch]]等主流披露者刻意与Greer保持距离
- **CE-5证据**：接触事件无第三方仪器核实，主要依赖参与者主观报告
- 支持者认为他2001年的工作为2017年后的披露浪潮奠定了公众认知基础

## 认识论立场

Greer是UAP研究界少数明确持"所有NHI均为善意"立场的人物，这与持中立或警惕立场的研究者（如[[Jacques Vallée]]）形成根本分歧。
