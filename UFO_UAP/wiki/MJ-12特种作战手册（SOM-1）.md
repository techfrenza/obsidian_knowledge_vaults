# MJ-12特种作战手册（SOM-1）

《MJ-12特种作战手册》（Special Operations Manual 1，SOM-1），据称1954年编制的绝密操作手册，为MJ-12单位提供处理UFO、地外技术和实体的指导，1994年匿名泄露。

## MJ-12组织背景

据称1947年9月24日由美国总统通过特别机密命令成立，目的：
- 控制、收容并探索自1940年代后期以来与地球沟通互动的UFO及EBEs（地外生物实体）
- 直接向总统负责
- 由国防部长James V. Forrestal和Vannevar Bush建议组建

## 手册泄露过程

- 据称1954年编制
- 1994年3月7日以**未冲洗的35毫米Trix胶卷**形式匿名邮寄给研究者Don Berliner
- 手册中已提及51区S4站点——该信息直到1989年才由Bob Lazar公开（比泄露早5年）

## 法医真实性分析

研究者Ryan Woods、Stan Friedman等进行了法医分析：

| 证据 | 说明 |
|------|------|
| 胶片材质 | 1954年生产的35毫米Trix未冲洗胶卷 |
| 术语使用 | "craft tape"而非"duct tape"，符合1954年运输术语 |
| 拼写惯例 | "screw driver"（两词），"First Aid"大写，符合1950年代中期前习惯 |
| 地名缩写 | 新墨西哥州写为"NMEX"而非现代"NM" |
| 拼写错误 | "desicant"（应为desiccant），表明手动编辑非计算机处理 |
| 印刷特征 | 字母"Z"凸起，符合1954年热铅印刷机特征 |

## 安全分类与保密措施

- 安全级别：**"Magic Eyes Only"**，比"绝密（Top Secret）"高两级
- 官方立场：否认MJ-12存在
- 保密理由：防止公众知晓引发社会冲击；防止先进技术落入敌国

## 核心操作目标（六项）

1. 回收所有外星/地外材料和设备
2. 回收非地球起源实体及遗骸
3. 建立和管理绝密执行团队
4. 在美国大陆建设安全设施（如S4、Dulce基地）
5. 与CIA协调回收落入外国的地外技术
6. 对所有行动维持最高级别保密

## 矛盾与争议

| 支持真实性 | 质疑真实性 |
|-----------|-----------|
| 法医分析显示1954年制作 | FBI调查认定为伪造文件 |
| S4站点信息超前Lazar5年 | 无独立官方确认 |
| 多名研究者深入分析 | 匿名来源，无法核实供应链 |

**FBI立场：** 联邦调查局于1988年调查后，将MJ-12文件标记为"BOGUS"（伪造）。

## 与现代披露的关联

- AATIP/AAWSAP的结构和目标与SOM-1描述的MJ-12职能高度相似
- David Grusch 2023年国会证词涉及多层次秘密回收计划，与SOM-1框架呼应
- 揭示了SAP（特殊访问计划）体系的潜在历史根源
