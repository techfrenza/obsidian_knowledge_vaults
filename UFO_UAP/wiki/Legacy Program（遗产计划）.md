# Legacy Program（遗产计划）

美国政府及私人承包商被指运行长达数十年的秘密UAP坠毁回收与逆向工程计划，脱离国会监督，资金来源不透明，由CIA、空军、能源部及洛克希德·马丁等主要防务承包商控制。

## 定义与历史起源

- **长期性与秘密性**：Lue Elizondo将其描述为"美国政府研究UAP的传统且长期持有的努力"，可追溯数十年
- **起源节点**：核心被认为源于**1947年罗斯威尔坠毁事件**；依据《艾森豪威尔简报文件》旨在对非人类飞行器和实体进行科学研究
- **Majestic 12关联**：被认为与MJ-12秘密委员会（12名精英军政科学家，由杜鲁门总统设立）相关
- **1933年意大利马真塔**：David Grusch指该事件是已知最早的坠毁回收案例，飞行器二战后经轴心国流向美国

## 核心活动与资产

- **回收与逆向工程**：在美国境内（新墨西哥州Aztec和Kingman）及全球回收多架非人类飞行器，部分完整，部分残缺
- **生物遗骸**：多名证人声称遗产计划持有非人类生物实体（EBE）尸体，甚至曾关押活体生物
- **数据积累**：积累超过**80年**的机密数据、照片和视频
- **Hal Puthoff**：指出该计划自20世纪40年代以来一直在阴影中运作

## 权力结构与监督缺失

| 层级 | 说明 |
|------|------|
| 核心控制者 | CIA、空军、能源部、少数核心国防承包商管理层 |
| 私人承包商 | 洛克希德·马丁、诺斯罗普·格鲁曼等 |
| 监督状况 | 脱离国会和白宫有效监督；职业官僚通过SAP将信息"隔离" |
| 资金来源 | "虹吸"独立研发资金（IRAD）和结余资金 |

**Marco Rubio（参议员）在闭门简报中质疑：执行部门是否在没有国会监督的情况下运行了该计划60年。**

## 对新项目的压制

- Puthoff透露，当2008年AAWSAP计划设立时，遗产计划人员设置官僚障碍，最终导致AAWSAP在2010年失去资金
- "洋葱效应"：多层分级制度隐藏涉及外星技术的"灰色项目"于受法律保护的"黑色项目"之下

## 举报人指控

- **David Grusch（2023）**：正式举报，称美国政府拥有非人类技术并一直非法向国会隐瞒逆向工程计划
- **Dylan Borland / Jake Barber**：指控遗产计划相关人员实施行政报复、非法监视乃至更严重犯罪
- **国会立法努力**：《UAP披露法案》试图通过"征收权"强制私人实体交出可能持有的非人类技术资产，但相关条款遭到削弱

## 国际参与

- Ross Coulthart指出加拿大科学家长期参与该遗产计划
- 澳大利亚与美国在秘密UAP调查和数据交换方面有悠久合作历史

## 矛盾与争议

- 所有核心指控仍为证词性质，缺乏公开物证
- Steven Greer认为威胁叙事是虚假信息，真正的威胁来自"内部流氓秘密组织"而非外太空
- 分离文明（Breakaway Civilization）概念：Richard Dolan认为基于回收技术发展出一个独立于主流社会的秘密文明
