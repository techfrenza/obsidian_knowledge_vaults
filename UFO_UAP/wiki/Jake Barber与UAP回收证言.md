# Jake Barber与UAP回收证言

杰克·巴伯（Jacob "Jake" Barber），曾用笔名Alva Douglas。官方掩护身份为美国空军飞机机械师，实为机密航空航天承包商（推测为Northrop Grumman/Lockheed Martin）的"红队"（Red Team）专家。30余年为美国政府执行高风险UAP回收任务，2023年从内部倒戈成为吹哨人。

## 双重身份与隐蔽结构

| 层面 | 内容 |
|------|------|
| 官方身份（掩护） | 美国空军飞机机械师 |
| 真实角色 | 机密航空航天承包商红队专家（Sheep-dipped，官方档案抹除） |
| 训练背景 | Pre-CCT特种战术中队训练；NATO最高机密许可 |
| 专长 | 利用非传统思维探测军事系统漏洞，反向渗透测试 |
| 曾用笔名 | Alva Douglas |

## 关键回收事件

### 蛋形飞行器（The Egg / "Nanu"）
- 回收地点：墨西哥科亚梅（Coyame）附近
- 长约20英尺，珍珠白色无缝表面，飞行完全静音，无可见推进系统或热信号
- 在测试场用直升机长线悬挂系统吊走

### 八角形飞行器
- 八个对称部分的碟状物体
- 运输中巴伯遭受**意识附身（Consciousness Attachment）**：感受到被称为"女士"（The Lady）的女性能量实体入侵，情不自禁流泪
- "女士"实体与[[J2（James Hodgkins）人物档案]]和[[Chris Bledsoe人物档案]]中描述的实体具有高度一致性

## P3计划（Psionics项目）

巴伯揭露的秘密意识研究项目，与[[Dan Sherman与Project Preserve Destiny]]相互印证：

| 要素 | 内容 |
|------|------|
| 灵能资产来源 | 儿童、左撇子、原住民社区、同性恋男性、具有童年创伤者 |
| 资产内部代称 | "粉红资产"（Pink Assets），被视为"生物硬件设备" |
| 召唤方式1 | 人控召唤（冥想+意识场连接），类CE-5协议 |
| 召唤方式2 | 机器召唤（特定核物质诱饵）；飞行器被诱骗后用标量武器击落 |
| 生物制剂 | 飞行器内发现的"软组织无人机"或"肉体机器人"，非有意识生命 |

## 健康受损

- 因护送"神秘盒子"任务遭受严重辐射伤害
- 症状：全身毛发脱落（普秃症）、皮肤剥落、心脏杂音
- 受损模式与[[John Burroughs与Rendlesham Forest事件|John Burroughs（Rendlesham Forest事件）]]的辐射症状高度一致，构成跨案例交叉印证 [C级]
- 接受[[Garry Nolan的UAP研究|加里·诺兰教授]]治疗

## 反情报策略：DOPSR特洛伊木马

- 以笔名Alva Douglas撰写科幻小说《以太哨兵》（Sentinels of Ether）
- 将小说提交DOPSR（国防部预出版安全审查办公室）进行官方安全审查
- **红队底线测试**：观察哪些内容被国防部涂黑，反向确认其为真实绝密程序 [B级]
- 方法论：科幻包装作为主动探测机密边界的情报手段

## 2023年华盛顿国家新闻中心发布会倒戈

- 原任务：作为红队资产潜入Steven Greer发布会，收集情报、诱捕并逮捕吹哨人
- **现场倒戈**：听取证人陈词后决定反水，公开承认并证实吹哨人故事的真实性
- 揭示Legacy Program中存在"Bad Actors"愿意通过暗杀（Wet Works）保护机密
- 透露：数名国会议员因调查UAP而在家中遭受死亡威胁，反向寻求Barber的人身保护

## 权力碎片化批评

- **章鱼形态碎片化**：高层（大脑）完全不知道一线（触手尖端）在做什么
- **私人公司控制**：核心技术流失至私营航空航天公司，政府失去中央控制权
- **程序失控**：政府缺乏对UAP项目全貌的整合视角

## Skywatcher Technologies

- 因不愿等待政府"缓慢揭露"，联合成立[[Project Skywatcher（天眼计划）|私人公司]]
- 目标：利用私人资金，在2025年向公众进行公开UAP召唤演示
- 从Legacy Program招募专家，打破政府信息垄断

## 矛盾与争议

- 无法通过公开渠道独立核实身份背景 [E级]
- 八角形飞行器"女性能量"体验过于主观 [D级]
- DOPSR涂黑证明程序存在真实记录 [B级]，但不等于直接证实UAP非地球来源
- 关于"肉体机器人"的描述与[[区分独立进化外星生物与生物机器人的方法]]中的生物学标准相关
