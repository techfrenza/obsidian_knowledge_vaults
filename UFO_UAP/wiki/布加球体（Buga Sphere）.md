# 布加球体（Buga Sphere）

## 定义

2025年3月2日坠落于哥伦比亚布加（Buga）地区的**神秘金属球体**，是近年来UAP/异常物体研究的核心争议案例之一。

**来源性质**：部分私人/大学机构研究，大量社交媒体传播。无NASA官方介入确认，无完整同行评审报告。

## 基本参数

- **重量**：约4.5磅（约2公斤）
- **外观**：表面光滑无缝、无焊接痕迹
- **温度**：坠落后类似冰箱温度（异常低）
- **坠落前行为**：目击者报告呈"之字形"飞行后坠落
- **现场效应**：周边草地出现土壤与植被异常干燥现象

## 研究发现（2025年底至2026年5月）

| 研究维度 | 发现 |
|----------|------|
| 结构分析（UNAM等） | 三层金属状材料；内含类光纤结构、中央"芯片状核"、18个微球体 |
| 动态扫描 | 内部结构位置随时间轻微变化 |
| 碳定年（佐治亚大学） | 约12,560年前（公元前10,560年），与末次冰期结束接近 |
| 能量响应 | 据称高能粒子束照射后完全吸收，实验随后被中止 |
| 声学响应 | 据称对梵文咒语或特定声音有"响应" |

## 竞争性解读

**支持异常起源**：
- Jaime Maussan等研究者认为其非人类制造
- Jose Luis Velazquez指出无缝结构与复杂内部不符合已知制造技术
- 部分报告提到"自感知编程"迹象

**怀疑/伪造观点**（[[Patrick Jackson球体网络理论]]作者明确否定为骗局）：
- X射线图像显示原始稳定装置与人工缺陷（Jackson论据）
- 科学社区认为可能是人造物（燃料罐改装或艺术品）
- 碳定年结果可能因污染而偏差

## 2026年7月最新评估

截至2026年7月，科学共识已进一步明确：

| 评估来源 | 结论 |
|---------|------|
| Garry Nolan公开声明 | "99%是地球产物"，由常规材料（含已知光纤技术）制成 |
| 哥伦比亚科学家（国立大学天文台、Cali天文学校等） | 组件"非常地球化"，光纤可识别，整体像近期人造技术物品或宣传炒作 |
| SSRN预印本等独立分析 | 制造痕迹（旋转对称、均匀切口、抛光表面、缺乏锈蚀）符合现代机器辅助制作；基线判断为人造约70% |
| 2026年5月保管链危机 | Maussan承认第二颗球体（Las Baldías）在交接前已被"切开并重新密封"，严重损害链完整性 |

**无任何大学、官方机构或学术期刊**发表支持"非人类起源"或"12,560年历史"的正式报告。University of Georgia未发布机构确认文件。

## 矛盾与争议

- 碳定年对象为球体孔洞中的有机树脂残留物，不代表球体整体年龄，且无大学官方报告支撑
- 所有"自感知编程"与"声音响应"来源均为社交媒体，无同行评审
- 主要推广者Jaime Maussan有多起此前被广泛质疑的案例记录（含秘鲁木乃伊）
- 最强反驳：Garry Nolan（UAP材料研究最权威的在世科学家之一）明确定性为地球产物；哥伦比亚本地科学家共识为常规技术物品
