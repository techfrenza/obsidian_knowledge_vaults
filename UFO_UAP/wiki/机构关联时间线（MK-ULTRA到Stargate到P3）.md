# 机构关联时间线（MK-ULTRA到Stargate到P3）

基于公开档案、解密文件和证人陈述构建的**意识技术机构演化时间线**。核心假说检验：情报/黑项目内部是否存在"内部确认意识相关技术有效性→外部压制/去合法化"的系统性双轨模式。

## 关键节点时间线

| 时期 | 项目 | 机构 | 核心内容 |
|------|------|------|---------|
| 1953–1973 | [[MK-ULTRA]] | CIA | LSD、催眠、感觉剥夺、行为修改；1977年Senate听证解密 |
| 1972–1995 | Stargate Project（及前身Grill Flame/Center Lane/Gondola Wish） | CIA→DoD→SAIC | 远程遥视（Remote Viewing）情报应用；Hal Puthoff、Russell Targ领导；1995年AIR报告称"不可靠"后正式终止 |
| 2007–2012 | AAWSAP/AATIP | 五角大楼/Bigelow Aerospace | UAP威胁、生物/生理效应研究；Luis Elizondo领导；2017年公开后有限披露 |
| 1990s–? | Project Preserve Destiny | NSA（据Dan Sherman） | 训练"直觉通讯员"通过心灵感应与外星实体沟通；来源：Sherman 1997年书《Above Black》 |

## "内部确认→外部压制"假说检验

### 支持证据

- **时间无缝衔接**：MK-ULTRA（意识控制，1953–1973）→ Stargate（远程感知，1972–1995）重叠一年，表明人员/方法论连续性
- **压制模式一致**：Stargate 1995报告明确"不可靠"并终止资金（公开压制）；AATIP 2012结束后有限披露（Elizondo 2017年揭露部分数据被"已解决"标签封锁）
- **黑项目延续迹象**：1995年Stargate"终止"到2007年AAWSAP启动之间存在12年空白，但有证人证词显示类似研究在私营承包商（如SAIC）中延续
- **与[[PURSUE计划与首批UAP文件解密]]模式一致**：公开项目通过"无结论"或"不可靠"标签去合法化，内部兴趣持续

### 反驳/可证伪点

- 无公开档案显示MK-ULTRA人员或资金直接转移至Stargate——Stargate更多源于冷战psi竞赛（苏联威胁）而非MK-ULTRA遗产
- Project Preserve Destiny仅依赖单一证人Sherman（1997年书），无独立档案佐证——若FOIA解密文件完全否认，该节点可证伪
- AATIP意识关联薄弱：主要聚焦物理UAP威胁，psi元素多为间接证人回忆而非核心任务文档
- Stargate 1995终止可能因真实情报价值低而非系统性压制

## 双轨制结构

```
公开轨道：Stargate → "不可靠" → 终止 → AATIP → "已解决" → 有限披露
                ↓                          ↓
内部轨道：psi研究持续（SAIC/私营）    黑项目UAP延续（据Elizondo）
```

## 假说整体评估

**部分可证伪**：时间线显示高连续性与选择性压制模式（公开项目被"科学化"终止，内部兴趣持续），但缺乏"smoking gun"级直接转移文档。

**关键空白**：1995–2007年12年间的机构状态，以及Project Preserve Destiny的NSA档案，是验证或证伪该假说的核心缺口。

## 矛盾与争议

- 认识论陷阱：现有证据结构允许两种解读——(1) 意识技术内部有效、系统性压制；(2) 技术无效、项目因资源优先级自然终止，证词受信念偏见影响
- 反驳方具体论据：国家科学院1988年报告（最强公开科学反驳）直接否定了遥视在严格控制条件下的统计有效性，但反对者称该报告本身存在方法论缺陷
