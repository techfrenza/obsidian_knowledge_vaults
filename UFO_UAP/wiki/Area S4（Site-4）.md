# Area S4（Site-4）

S4设施是美国据称最高机密的UFO逆向工程基地，位于内华达州Groom Lake（51区）以南约12-15英里的Papoose Lake（帕波斯湖）附近山体内部。机库门与山坡地貌融为一体，从未出现在任何官方地图上。

## 地理位置与存在性争议

| 要素 | 内容 |
|------|------|
| 地点 | Papoose Lake（帕波斯湖）旁山体内，内华达沙漠 |
| 与51区距离 | 约12-15英里（各来源描述为11-17英里不等） |
| 官方状态 | 从未被政府承认；1989年美国内政部地图修改移除了通往该地址的道路 |
| 卫星影像 | Google Earth曾对该区域进行模糊处理；高清4K飞越照片存在"有/无建筑"的相互矛盾分析 |

## 设施结构（据证人描述）

共五层地下结构（4-1至4-5层）：

| 楼层 | 功能 |
|------|------|
| 4-1层（机库层） | 9个机库（存放飞行器）+ 航空电子实验室 + 推进系统实验室 + 食堂 |
| 4-2层（技术研发） | Project Sidekick武器研究 + Project Looking Glass设备 |
| 4-3层（居住行政） | MJ-12居住套间 + 文化部 + 分析部 |
| 4-4层（生物实验室） | 生物封存实验室 + 去污区；[[Dan Burisch人物档案]]工作区 |
| 4-5层（洁净球） | 52英尺宽加压半球体，为与EBE互动的专用空间 |

## 九个机库与飞行器清单

| 机库 | 飞行器 |
|------|--------|
| 1号 | "运动机型"（Sport Model），直径52英尺，抛光铝质 |
| 2号 | 另一架运动机型或外星复制飞行器（ARV） |
| 3号 | 罗斯威尔飞行器（P-24），通常盖布 |
| 4号 | P-52猎户座（Orion）飞行器 |
| 6号 | 罗斯威尔飞行器人造复制品（隐身测试） |
| 7号 | [[1953年金曼UFO坠毁事件]]回收飞行器 |
| 8号 | "甘草糖"（Licorice Drop），黑色等腰三角形，黑色液态汞状表面 |
| 5号/9号 | 通常空置，用于转运 |

## 主要秘密项目

全部活动隶属于**宝瓶座计划（Project Aquarius）**：

| 项目 | 研究重点 |
|------|---------|
| Project Galileo（伽利略计划） | 逆向工程飞行器推进系统 + 元素115反物质反应堆 |
| Project Looking Glass（窥镜计划） | 利用人造重力波观察未来概率（兼作人造星门） |
| Project Sidekick（侧击计划） | 地外技术武器化应用 |
| Project Lotus（莲花计划） | J-Rod等EBE的遗传学与神经病变研究 |

### 元素115（Element 115）

- 在洛斯阿拉莫斯加工成三角形楔块，每架反应堆用量约223克
- 质子轰击→转化为元素116→衰变释放反物质→产生重力波驱动推进
- [[Bob Lazar与S4飞碟逆向工程]]的核心主张；2003年Moscovium被正式发现

### Project Looking Glass（窥镜计划）

- 苏美尔圆筒印章提供技术蓝图（据[[Dan Burisch人物档案]]）
- 水平位置：观察未来概率；翻转45度+调频：充当人造星门
- 设备结构：多个永久电磁铁，产生六个电磁场，中央可调节圆柱体

### 猎户座立方体/黄色之书（Orion Cube）

- 8×8英寸量子观察装置，1954年由P-52猎户座代表赠予艾森豪威尔
- 允许观察未来事件的各种概率
- 后被转移至华盛顿特区苏格兰礼共济会圣殿，下落不明

## 安全协议

- **走线规则**：地板蓝色线必须遵守；越过红色线可能被执行致命武力
- **裸体称重**：进出均称重，防止材料走私；几盎司偏差即触发封锁
- **交通**：从51区乘蓝色空军巴士/黑鹰直升机/Mi-24武装直升机转运
- **证件**：蓝色深蓝色斜线条纹，注有"MAJ"（Majestic）标记

## 主要证人

- **[[Bob Lazar与S4飞碟逆向工程]]**：最早公开描述S4（1989年），强调元素115和9架飞碟，无J-Rod互动记录
- **[[Dan Burisch人物档案]]**：1994年起在4-4层工作，与J-Rod（[[1953年金曼UFO坠毁事件]]幸存者）互动，操作Project Lotus
- **Oscar Wolff**（CIA分析师）：在公民披露听证会中描述受艾森豪威尔指令前往S4传递最后通牒，并目睹外星生物心灵感应交流

## 矛盾与争议

- **存在性争议**：Gabriel Zeman 2020年4K飞越照片中，部分分析认为无建筑痕迹，另一方分析认为有人造几何结构。两种分析均无法独立验证。
- **来源可信度**：核心描述来自Bob Lazar（学历存疑）和Dan Burisch（MJ-12证言无独立物证），均属[C]级证词。
- **托诺帕替代假说**：部分研究者认为托诺帕测试场（52区）的"4号站点（Site Four）"可能是"S4"名称来源，拉扎尔叙述可能混淆了地点。
- **细节膨胀问题**：每位证人的叙述都比前任更为详细（Lazar→Uhouse→Burisch），符合典型的叙事演化模式，增加了独立性判断难度。
