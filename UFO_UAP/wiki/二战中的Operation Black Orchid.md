# 二战中的 Operation Black Orchid

"黑兰花行动"是与 1933 年意大利马真塔 UFO 坠毁事件相关的**传闻性盟军情报行动**，主要出现在现代 UFO/UAP 研究文献中。**缺乏二战官方档案证实**，主要依赖 UFO 社区文件和证词。

## 行动背景

- [[1933年意大利马真塔UFO坠毁事件|1933 年意大利马真塔事件]]：墨索里尼政权封锁坠毁现场，成立 RS/33 内阁（由马可尼领导）在韦尔贾泰研究飞行器。
- 二战期间：德国 SS 和空军突袭韦尔贾泰试图夺取"奇怪机械"；盟军通过伊斯坦布尔情报站获知飞行器存在。

## 行动细节（据称）

| 要素 | 内容 |
|------|------|
| 时间 | 主要在 1944 年（部分叙述延伸至 1944–1945 年） |
| 目标 | 确认并回收马真塔坠毁飞行器，防止落入德国/苏联手中 |
| 执行方 | OSS（美国战略情报局，CIA 前身） |
| [[梵蒂冈与UAP档案|梵蒂冈]]协助 | 教皇庇护十二世通过耶稣会士和瑞士中介向 OSS 泄露 RS/33 电报和马可尼笔记 |
| 结果（据称） | 成功获取飞行器（或关键部件），战争末期运往美国 |

## 战后影响（据称）

- 飞行器被运至美国，可能影响后续隐形技术、推进系统研究（如 Area 51 相关项目）。
- 被视为美国**早期 UAP 逆向工程程序的起点之一**。
- David Grusch 2023 年国会证词中将 1933–1945 年的回收流程纳入美国早期 UAP 保密历史。

## 争议与评估

- **支持方**：Grusch 证词、Roberto Pinotti 文件、轴心国对先进技术的历史追求、梵蒂冈在战时情报网络中的角色。
- **反对方**：无官方二战档案、无物理证据、韦尔贾泰设施在战时未遭严重破坏（可能为间接证据，也可能说明德军未在此找到飞行器）。
- 主流历史学家视其为**阴谋论或误传**。
