# Timothy Taylor（Tyler D）人物档案

Tim Taylor 是 Diana Pasulka《American Cosmic》（2019）中以化名"**Tyler D.**"出现的关键人物。他将严谨的航天工程素养与神秘的意识/灵性体验结合，被视为"现代科技宗教"的典型案例。

## 核心身份

| 领域 | 事实 |
|------|------|
| 教育背景 | 密西西比州立大学工程学本科；佛罗里达理工学院 MBA |
| NASA 经历 | 系统工程师、现场测试工程师、首席研究员；40+ 次航天飞机任务、80+ 次 DoD 发射 |
| 外号 | "The Dragon"（龙），手臂有龙纹身，任务控制中心设有专属 Dragon Console 席位 |
| 企业家成就 | Endius, Inc. 联合创始人（2007 年被 Zimmer 以 7500 万–1.25 亿美元收购）；VIVEX Biologics 董事会主席；40 多项美国专利 |

## 信息"下载"主张

Taylor 声称多项专利突破来自**非人类智能（NHI）的直接"下载"**——完整技术蓝图突然闪现在脑海中（"未来记忆"）。Garry Nolan 通过 MRI 发现相关受访者**尾状核和壳核（基底神经节区域）存在超密度神经连接**，将其解释为"生物天线"特征。

## 严格生活"协议"

- 绝不喝咖啡，极少饮酒
- 每天 9 小时强制睡眠（8 小时常规 + 额外 1 小时）
- 每天在阳光下暴晒以同步生物节律
- 高度水合（大量饮水）
- 目标：抑制前额叶皮层，维持"极度创意"接收状态

## UAP 相关活动

- 带 Pasulka 和 [[Garry Nolan的UAP研究|Garry Nolan]] 前往新墨西哥州圣奥古斯丁平原秘密坠毁现场（蒙眼操作）；Nolan 在斯坦福实验室对挖掘碎片进行质谱分析，发现异常同位素比例。
- 与 [[Chris Bledsoe接触案例|Chris Bledsoe]] 家族保持深厚友谊，展示带机密警告的简报。
- 据传曾向奥巴马总统汇报 Bledsoe 案例（主要依赖 Bledsoe 口述，缺乏官方记录）。

## 哲学与世界观

- 自称服务于"**The Hammer**"实体（高于人类政府，直接听命于"至高神"）。
- 现实五层级论：上帝 → 天使 → 地外生物 → 情报机构特定派系 → 普通人类。
- 2017 年访[[梵蒂冈与UAP档案|梵蒂冈秘密档案馆]]，查看伽利略/开普勒原稿后**从无神论者皈依罗马天主教**（《American Cosmic》高潮）。
- 拿骚时间旅行小组（Nassau Group）传闻：据称参与 Thomas Townsend Brown 领导的秘密项目（高度推测性，无公开证据）。

## 评估

- **航天与生物医学背景 100% 真实**，是典型的"隐形精英"。
