# Collins Elite：恶魔叙事派系

Collins Elite（柯林斯精英）是据称存在于美国政府、军方和情报机构内部的非正式秘密团体，由具有强烈福音派基督教背景的官员组成，坚信UAP现象为恶魔欺骗而非地外文明。

## 基本档案

| 要素 | 内容 |
|------|------|
| 信息来源 | Nick Redfern著《Final Events》（2010），基于匿名访谈 |
| 核心信源 | 自称"Richard Duke"的前CIA成员（据称是最后幸存者） |
| 成立时间 | 约1952年 |
| 触发事件 | Jack Parsons（JPL联合创始人）与Aleister Crowley的神秘学活动 |
| 涉及机构 | AFOSI、Army G-2、Naval Intelligence |

## 核心信念

- UAP实体（包括"灰人"）是**堕落天使或恶魔**伪装，目的是诱导人类合作、进行灵魂收割
- 1946年Jack Parsons的仪式打开了"通往另一侧的门户"，导致1947年后的UFO浪潮（含[[Roswell事件与Ramey Memo]]）
- 这些现象与圣经末世预言结合，是"撒旦的大规模欺骗（Great Deception）"
- 部分成员研究生命后状态、灵魂出体，并试图通过基督教灵性手段对抗这些实体

## 当前影响（截至2026年）

- [[Luis Elizondo]]在其2024年著作《Imminent》中提到国防部高层中确实存在将UAP视为"demonic"的派系
- 2025-2026年讨论中被频繁提及，尤其在基督教保守派圈子和部分UFO研究社区
- 代表人物：Timothy Alberino、Father Chad Ripperger等公开讨论"aliens are demons"观点

## 与其他叙事的对比

| 叙事框架 | Collins Elite立场 | EBO科学框架 |
|---------|-----------------|------------|
| UAP性质 | 恶魔实体 | 生物工程生命体 |
| 目的 | 灵魂收割/末世欺骗 | 基因采集/意识利用 |
| 应对方式 | 基督教灵性对抗 | 科学研究与政策应对 |
| 证据基础 | 宗教文本+匿名证词 | 生物分析+情报文件 |

## 矛盾与争议

- 主流科学界和多数UAP披露倡导者视其为未经证实的宗教过滤下的阴谋论
- 缺乏公开文件支持，主要来源为匿名访谈
- 反映美国情报圈中长期存在的福音派影响这一可证实的社会事实
