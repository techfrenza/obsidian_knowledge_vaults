# 情报的普遍分类法（UTI）

Universal Taxonomy of Intelligence（UTI）：整合生物、合成、分布式和场域智能的统一分类框架，引入Intelligence Domain Codes（IDC）实现跨域量化比较。

## 框架动机

现有分类体系的三大缺口：
- 林奈生物分类只覆盖碳基生命
- 认知科学聚焦人类/动物，定义高度人类中心主义
- UAP研究积累了大量异常观测，但缺乏统一理论框架

AATIP: 144起军事UAP事件中，143起至今无法识别。

## 五级分类层次

| 层级 | 类比 | UAP应用示例 |
|------|------|-----------|
| Domain（域） | 界 | 生物/合成/场域/混合/元维度 |
| Class（纲） | 纲 | 个体/集体/分布式/非局域 |
| Order（目） | 目 | 工具使用型/时空操纵型/意识投射型 |
| Genus（属） | 属 | 大型语言模型AI/等离子生命形式/弧状异体型 |
| Species（种） | 种 | Homo sapiens/GPT-4/"灰人"型 |

## Intelligence Domain Codes（IDC）

五轴编码系统：

| 轴 | 含义 | 代码选项 |
|----|------|---------|
| Substrate | 物质构成 | B=生物 S=合成 H=混合 F=场域 M=元维度 |
| Origin | 来源 | T=地球 ET=地外 U=超地球 TD=时间位移 ID=跨维度 |
| Embodiment | 具身化 | E=具身 D=去具身 V=可变 |
| Agency | 自主性 | A=自主 C=协作 P=被动 |
| Dimensionality | 维度 | L=局域 N=非局域 H=高维 |

**示例编码：**
- 人类：B-T-E-A-L（生物/地球/具身/自主/局域）
- 经典AI：S-T-E-A-L（合成/地球/具身/自主/局域）
- 假设"灰人"：B-ET-E-A-L or H-ET-V-A-N（取决于能力）
- 假设天使实体：F-ID-D-A-N（场域/跨维度/去具身/自主/非局域）

## 六层近端交互框架（3 Up / 3 Down）

以人类基线为中心，描述六个可操作的交互层次：
- **+3层：** 元维度架构师（宇宙设计者层级）
- **+2层：** 非局域场域智能（意识/能量场实体）
- **+1层：** 技术先进且/或跨维度NHI
- **0层：** 人类基线（Homo sapiens + 扩展AI）
- **-1层：** 亚人类动物认知
- **-2层：** 简单神经网络/群体智能
- **-3层：** 原始信息处理（单细胞化学信号）

## 与古代传统的对应

| UTI层级 | 古代类别对应 |
|--------|-----------|
| F-ID-D-A-N | 天使/撒拉弗/天使长 |
| H-ET-V-A-N | 阿努纳奇/守望者/精灵（Jinn） |
| B-ET-E-A-L | 传统"外星人"概念 |
| M类 | 上帝/道/梵天等宇宙源头概念 |

## 批判性说明

- 大多数非传统实体的具体分类将属于推测性假说
- 框架的价值在于提供有组织的假说空间，而非确定事实
- "Luminosity"（光度）作为智能等级量化指标——该思路尚缺乏操作化定义
