# UAPTF（UAP任务小组）

UAP Task Force，即"不明异常现象任务小组"，是美国国防部于2020年8月正式成立的 UAP 调查机构，是从 AATIP/AAWSAP 到 AARO 之间的过渡性机构。其存在揭示了美国政府在 UAP 问题上的机构性震荡。[Source: raw/Immaculate Constellation.md]

## 成立背景

**前身**：AATIP（高级航天威胁识别计划，2007–2012）和 AAWSAP（高级航空航天武器系统应用计划，2007–2012）
**成立时间**：2020年8月14日，由时任国防部副部长下令成立
**归属**：隶属海军情报局（ONI）

**成立直接触发事件**：
1. 2017年12月《纽约时报》披露 AATIP 存在
2. 2017年 Luis Elizondo 辞职并公开批评 DoD 未严肃对待 UAP 威胁
3. 国会持续压力（尤其是参议员 Marco Rubio）要求建立制度化调查机制

## 主要职能

| 职能 | 说明 |
|------|------|
| 情报汇聚 | 收集来自军事和情报机构的 UAP 目击报告 |
| 威胁评估 | 评估 UAP 是否对美国军事行动构成威胁 |
| 报告发布 | 向国会提交非保密的初步评估报告 |
| 跨机构协调 | 协调 NSA、CIA、NRO 等机构的相关数据共享 |

## 2021年报告

2021年6月25日，UAPTF 发布了《关于不明空中现象的初步评估》（Preliminary Assessment: Unidentified Aerial Phenomena），这是美国政府历史上首份公开的 UAP 系统性评估报告：

- 审查了2004–2021年间144起军方目击事件
- 仅能"解释"1起（气球）
- 将143起列为"无法解释"
- 明确承认 UAP 可能对飞行安全和国家安全构成威胁
- 拒绝排除"外国政府先进技术"或"其他"来源

## 内部评价与批评

据在五角大楼任职的吹哨人记录（Immaculate Constellation 文件相关证词），UAPTF 的发展被内部人士描述为"缓慢的死亡"：

- 信息在进入正式 UAPTF 渠道之前已被[[Sentient（NRO AI情报过滤系统）]]等系统隔离
- UAPTF 的分析人员无法访问隐藏在[[Immaculate Constellation（神圣星座计划）]]等 uSAP 中的最重要数据
- 结果是 UAPTF 的报告基于"残余信息"而非完整数据

## 机构演变

```
AATIP/AAWSAP (2007-2012)
    ↓
UAPTF (2020-2022)
    ↓
AARO (2022-现在)
```

每次重组均伴随机构设置变化，但内部信息是否同步移交始终是公开争议点（见[[David Grusch]]证词：AARO 无法访问其报告中涉及的关键 SAP）。

## 矛盾与争议

- **权限局限**：UAPTF 被批评为缺乏传唤能力（subpoena power），无法强制机构合作
- **数据完整性问题**：如果 Immaculate Constellation 吹哨人属实，UAPTF 的全部报告均基于经过系统性过滤的残余数据，其调查结论的有效性存在根本性质疑
- **与 AARO 的延续性**：AARO 首任主任 Sean Kirkpatrick 向国会的简报被内部人士指控为"歪曲、淡化甚至公然撒谎"，沿袭了机构性否认传统
