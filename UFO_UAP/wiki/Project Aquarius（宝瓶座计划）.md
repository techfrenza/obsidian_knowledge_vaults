# Project Aquarius（宝瓶座计划）

MJ-12旗下的总括性管理计划，负责统筹所有与非人类技术相关的研究、医疗和外交接触。Eric Davis确认1977年卡特政府时期曾进行过相关简报，获悉真相的工作人员表现出极度震惊。设施位于赖特-帕特森空军基地（WPAFB），由TRW等国防承包商协作研究，同时管理Area S4（Site-4）处的飞行器与EBO相关研究。

## 证据层级评估

- **项目存在性**：E/D级（仅见于泄露文件与吹哨人证词，无独立核实）
- **Eric Davis 1977年卡特简报细节**：C级（Davis直接陈述，具名证人但无文件）
- **与Wilson-Davis备忘录的交叉点**：C级（威尔逊声称被拒绝访问相关承包商项目）
- **FOIA确认**：仅有少量模糊提及，无完整档案解密

## 矛盾与争议

- Project Blue Book公开结论（ETH不成立）与Aquarius内部研究并行的结构性矛盾——Robertson Panel（公开否认）↔ Aquarius（内部深度研究）构成政府信息双轨制的核心证据 [B级]
- Looking Glass时间物理声称若为真，则现有物理学框架需要根本性修正；无物理文献佐证
- 所有子项目描述均来自Dan Burisch或Bob Lazar等单一证人，认识论互保风险极高 [E级]
