# Ryan Graves

前美国海军F/A-18飞行员，Americans for Safe Aerospace（ASA）创始人。UAP披露运动中最具公信力的现役/前飞行员代表，其证词强调航空安全而非外星叙事。

## 背景

| 项目 | 内容 |
|------|------|
| 军事背景 | F/A-18超级大黄蜂飞行员，在美国东海岸执行训练任务 |
| UAP遭遇 | 2014–2015年间，其中队在弗吉尼亚海岸反复遭遇不明飞行物，持续数月 |
| 国会证词 | 2023年7月与[[David Grusch]]、David Fravor同台作证 |
| 组织 | 创立Americans for Safe Aerospace，收集飞行员UAP报告 |

## 核心贡献

- 首批公开发声的现役/近现役飞行员，打破"飞行员不谈UAP"的文化禁忌
- 证词聚焦**航空安全**：UAP在限制空域内无应答飞行构成碰撞风险，与外星假说无关
- 记录UAP呈现"固定悬停后急速机动"的飞行特征，与[[Tic Tac事件与海洋探针假说]]中描述一致
- ASA已收集超过30个国家飞行员的UAP报告

## 认识论立场

Graves刻意不对UAP起源作出判断，仅陈述观测事实，这使其证词在怀疑论者和信仰者两端均保有信誉。
