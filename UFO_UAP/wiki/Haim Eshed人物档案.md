# Haim Eshed人物档案

以色列国防部前太空计划负责人，以色列卫星计划之父。2020年以81岁高龄在新书《地平线之外的宇宙》（The Universe Beyond the Horizon）中公开声称外星文明与美国政府存在协议，银河联邦正延迟公开披露。其特殊之处在于：以色列最高级别太空安全官员公开披露，并以"我已无可失去"说明其不受职业压力制约。

## 背景与资历

| 项目 | 内容 |
|------|------|
| 机构 | 以色列国防部太空计划 |
| 主要成就 | 以色列首颗卫星 Ofek 1 发射（1988年，Shavit运载火箭） |
| 任期 | 以色列太空局行政主任，历任约30年 |
| 获奖 | 以色列安全奖、参谋长奖 |
| 其他贡献 | 参与以色列无人机/侦察机的发明与发展 |
| 退休后 | 科学课程开发（中学卫星实际发射项目）；与赫兹利亚科学中心合作 |

## 核心声明

**证据层级：C级——前高级官员直接陈述，无文件支撑，属未经独立验证的内部人士证词**

## 矛盾与争议

- 所有具体声明（火星基地、九类文明、协议细节）均无文件支撑 [C级]
- "银河联邦"术语在New Age圈广泛流通，Eshed的框架与此高度重合 [文化采样风险]
- 最强反驳：一位年迈退休官员可能将情报圈道听途说与真实文件混淆；以色列太空计划的重心是军事卫星而非UAP研究，他的直接知情渠道存疑
- 火星基地声明：目前NASA所有公开数据不支持此说法 [与A级证据矛盾]
