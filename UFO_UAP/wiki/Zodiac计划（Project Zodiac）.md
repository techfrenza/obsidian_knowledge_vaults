# Zodiac计划（Project Zodiac）

据称是 MJ-12 体系下的顶层 UAP 情报伞状计划，Project Aquarius 等关键子计划据称在其架构下运作。属于黑色预算项目体系中迄今公开信息最少的层级之一。[Source: raw/综合 UAP 机密档案：设施、代号计划、吹哨人、生物技术清单与反情报规程.md]

## 已知信息

**来源层级**：E/D级（主要来自匿名来源、MJ-12 文件引用及内部人士间接证词）

**核心结构主张**：
- Project Zodiac 是"黄道带计划"，据称统摄所有 MJ-12 相关 UAP 研究子计划
- Project Aquarius（水瓶座计划）是其下设子部门，专门负责收集 UFO 相关科学、技术、医学情报并进行逆向工程

## MJ-12 子计划层级（吹哨人叙事综合）

| 计划代号 | 功能 | 归属层级 |
|----------|------|----------|
| Project Zodiac | 顶层伞状架构 | MJ-12 直属 |
| Project Aquarius | 逆向工程+情报汇聚 | Zodiac 下设 |
| Project Looking Glass | 时间/概率可视化技术 | Aquarius 下设（Burisch 证词）|
| Project Lotus | 生物/基因研究 | Aquarius 下设（Burisch 证词）|
| Project Moon Dust | 全球坠毁飞行器回收 | 并行执行机构 |
| Project Blue Fly | 快速反应回收 | 空军执行机构 |

注：上述层级关系来自[[Dan Burisch人物档案]]、[[MJ-12特种作战手册（SOM-1）]]及匿名来源，均属 C-E 级证据。

## 与 AATIP-era 机构的关系

根据综合档案文件中的内部人士证词，Zodiac 计划体系在结构上先于 AATIP/UAPTF/AARO 等公开机构存在，并据称持续在其之外平行运作。这一声明与 David Grusch 证词中"遗产计划（Legacy Program）绕过国会监督60年"的说法形成对应。

## 认识论评估

**高度不确定性声明**：Zodiac 计划的存在主要依赖两类来源：
1. MJ-12 文件体系（真实性仍有争议，[[MJ-12特种作战手册（SOM-1）]]条目有详述）
2. Dan Burisch 的 S4 项目证词（高度戏剧化，存在多处可疑情节）

缺乏任何 A 级或独立 B 级证据证明 Zodiac 作为独立计划代号实际存在。将其单独列条目的价值在于：记录 MJ-12 叙事体系的内部层级声明，供未来核实使用。

## 矛盾与争议

- **代号真实性存疑**：FOIA 请求从未返回与"Project Zodiac"匹配的任何解密文件（与 Moon Dust、Blue Fly 等已证实存在的代号形成对比）
- **Burisch 可信度问题**：Dan Burisch 的 S4 证词包含多个内部矛盾，部分研究者认为其叙事系杜撰或严重混淆
- **MJ-12 文件真实性争议**：FBI 曾将部分 MJ-12 文件认定为伪造；Stanton Friedman 等研究者对此持不同意见
