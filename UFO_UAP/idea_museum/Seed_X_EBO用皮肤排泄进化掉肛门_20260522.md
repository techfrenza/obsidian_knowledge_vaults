# 技术核心逻辑

EBO无肛门/尿道，"肝肾一体器官"过滤血液，氮废物（氨气）通过**全身微孔皮肤蒸发排出**，同时完成散热。皮肤为灰色生物合成薄膜，强烈的烧焦头发+氨水气味是多起目击事件的共同报告。

## 工程权衡分析

| 系统 | 地球人类（进化产物） | EBO（工程设计） |
|------|-----------------|--------------|
| 氮废物处理 | 尿素循环 → 肾脏过滤 → 膀胱存储 → 排泄 | 氨气直接通过皮肤蒸发 |
| 散热 | 汗腺（专用排热系统） | 氨蒸发+皮肤微孔（废物排出与散热合一） |
| 专用排泄器官 | 肛门、尿道、膀胱、输尿管 | 全部消除 |
| 代谢成本 | 尿素循环消耗ATP（额外能耗） | 氨直排省去转化步骤（但有毒性风险） |
| 可检测性 | 低气味特征 | 强烈氨水气味——这是工程权衡的代价 |

## 关键洞察（非显见）

人类选择排泄氨的水合物（尿素）而非氨气本身，是因为氨对神经系统有毒——将废物代谢为低毒形式需要额外的能量投入。EBO选择直排氨气表明：

1. **工程师认为毒性风险可接受**：EBO生命周期短（生物无人机），无需长期毒性管理
2. **暴露气味是设计缺陷，非特征**：目击者报告的强烈氨水气味是"最小可行生物设计"的外泄特征
3. **皮肤系统是多功能集成**：感知（灰色薄膜含传感功能？）+ 排泄 + 散热，三合一——这正是工程设计而非进化的标志性思维
