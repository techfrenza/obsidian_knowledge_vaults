## 技术核心逻辑

UAP案例影响力的决定因素分析：

| 因素 | Varginha（1996，巴西）| Rendlesham Forest（1980，英国）|
|------|----------------------|------------------------------|
| 证人数量 | 约62名平民 + 军警 | 约80名军事人员 |
| 证人职业可信度 | 混合（学生+消防+军警） | 高（全部为美英军方） |
| 物证 | 无 | 辐射测量、树木损伤 |
| 语言 | 葡萄牙语 | 英语 |
| 研究文献语言 | 主要为葡萄牙语 | 全部为英语 |
| 在英语UAP研究圈的影响力 | 低-中 | 高 |

**推论**：若Varginha发生在美国或英国，其证人数量和多元来源将使它成为UAP历史上引用最多的案例之一。当前低影响力是系统性的语言-地理偏置，而非证据评估。
