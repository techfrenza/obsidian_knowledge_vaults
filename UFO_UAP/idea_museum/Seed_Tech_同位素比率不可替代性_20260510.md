# Seed_Tech: 同位素比率——鉴别"在哪里生长"而非"是什么"

## 核心技术逻辑
基因组测序告诉你**序列是什么**；同位素比率（IRMS）告诉你**有机体在哪个环境中生长**。  
地球生物圈的碳（δ¹³C ≈ -20‰至-30‰）、氮、氧同位素分馏规律是太阳系中独特的"地址标记"。

## 权衡对比

| 场景 | 同位素结果 | 推断 |
|------|-----------|------|
| 独立进化外星生物 | δ¹³C/δ¹⁵N显著偏离地球范围 | 非地球生物圈来源 ✓ |
| 地球工厂培育的生物机器人 | 接近地球正常值 | 暴露人工在地球培育 |
| 外星环境培育的生物机器人 | 偏离地球值但含人类基因序列 | 工程 + 外星原料，最复杂情形 |

## 关键洞察（非显见）
David Grusch国会证词提及"isotopic ratios that have to be engineered"——这意味着如果有人在伪造外星样本，**他们必须刻意篡改同位素比率才能通过检验**。这使IRMS成为最难造假的鉴别工具，也是政府最可能优先保密相关结果的理由。
