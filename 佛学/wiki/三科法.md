# 三科法


## 定义
佛教分析身心世界的三套框架，层层递进，揭示一切现象的无自性本质。

## 三科结构
```
五蕴（5）        → 粗分：身心全貌
十二处（12）     → 中分：认知接触界面
十八界（18）     → 细分：识的生起机制
```

### 五蕴
→ 见[[五蕴]]

### 十二处（āyatana）
六根（内处）+ 六尘（外处）：
- 根：眼、耳、鼻、舌、身、意
- 尘：色、声、香、味、触、法
**功能**：描述主客体相遇的"接触界面"

### 十八界（dhātu）
六根 + 六尘 + 六识（眼识、耳识…意识）：
- 细化识的生起：根 + 尘 → 识（三和合触）
- 揭示识非独立存在，由缘生起

## 空性论证逻辑
三科法是逐层解构"我"与"世界"的分析工具：
1. 五蕴 → "我"只是聚合，无实体
2. 十二处 → 认知是根尘接触，无固定主体
3. 十八界 → 识因缘生，无自性识

目标：破除[[我执]]与[[法执]]，证入[[空性]]
