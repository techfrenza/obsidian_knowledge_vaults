# 四圣谛


四圣谛（Four Noble Truths，梵文 Catvāri Āryasatyāni）是佛陀首次说法（初转法轮）的核心内容，记录于[[阿含经]]《转法轮经》。"圣"指圣者（觉悟者）所见的真实；"谛"为真理。四谛是佛法的根本框架，如同医生的诊断模型：认识疾病 → 找出病因 → 确认可以治愈 → 给出治疗方案。

## 四谛结构

| 谛 | 巴利文 | 内容 | 对应 |
|----|--------|------|------|
| **苦谛**（苦的诊断）| Dukkha | 生命存在本质上是苦、不圆满 | 认识问题 |
| **集谛**（苦因分析）| Samudāya | 苦的根源是贪爱（Taṇhā）与[[无明]] | 找出病因 |
| **灭谛**（解脱可能）| Nirodha | 苦可以止息；[[涅槃]]是可以实现的目标 | 确认可治 |
| **道谛**（修行路径）| Magga | [[八正道]]是通向苦灭的方法 | 治疗方案 |

> 四谛是佛法的逻辑闭环：不回避苦（苦谛）→ 追溯根源（集谛）→ 确认出路（灭谛）→ 落地实践（道谛）。缺少任一谛，佛法便流于悲观主义或乐观主义的片面。

## 苦谛：如实认识苦

[[苦]]的三层结构：
- **苦苦**：直接的痛苦体验（病、老、死）
- **坏苦**：快乐消逝之苦（一切享乐终将变灭）
- **行苦**：有为法无常变易的底层不稳定性

八苦（生老病死、爱别离、怨憎会、求不得、五取蕴苦）是苦谛的具体展开。

## 集谛：苦的根源

根本原因是**贪爱（Taṇhā）**，分三类：
- 欲爱：对感官享乐的渴求
- 有爱：对存在延续、成为某物的渴求
- 无有爱：对消灭或逃避的渴求

贪爱背后是[[无明]]：对三法印（无常、无我、苦）的根本误解，导致把无常之物当作可永恒执取的目标。

## 灭谛：涅槃可证

[[涅槃]]不是虚无，而是贪嗔痴的火焰寂灭——烦恼止息后的心的自由。灭谛是四圣谛中最具革命性的命题：**苦有出路，解脱可实现**。

## 道谛：八正道

[[八正道]]是道谛的具体内容，以三学（戒定慧）为骨架：
- **戒学**（正语、正业、正命）：净化行为，不再造新的苦因
- **定学**（正精进、正念、正定）：培育心力，观察苦的生灭
- **慧学**（正见、正思惟）：以般若智慧直断无明与贪爱的根

## 四谛与三法印的关系
三法印是四谛的哲学基础：
- 无常（[[无常]]）→ 贪爱之物终将变灭 → 苦谛的根基
- 无我（[[无我]]）→ 无永恒主体可保护 → 集谛中我执的来源
- 苦（[[苦]]）→ 三法印在体验层面的落地 → 苦谛本身

## 四圣谛在各传统中的地位
| 传统 | 四圣谛的核心地位 |
|------|----------------|
| 原始佛教（[[阿含经]]系）| 佛陀首次说法核心，所有教法的起点 |
| 大乘佛教 | 以四谛为基础，扩展至菩萨道（自利利他） |
| 藏传佛教（[[藏传佛教]]）| 苦谛扩展为轮回三界苦，道谛含密乘方便 |
| [[禅宗]] | 不重次第分析，但顿悟即见苦灭（涅槃当下）|
