# 觉照


## 定义
对当下心念、情绪、感受的清醒觉察与观察。不压制、不追随，只是如实知道"此刻正发生什么"。是[[定慧等持]]在日常生活中的具体形态。

## 核心比喻
> "情绪如云，觉性如空"

云（情绪）来去变化，空（觉性）始终如是——觉照是安住于空而观云，而非变成云或赶走云。

[Source: raw/般若智慧：破迷开悟的修持指南.md]

## 操作方法
1. 情绪/念头升起时，不立即反应
2. 退一步，识别："我正在感受______"
3. 观察其能量、质地、变化
4. 不判断好坏，如实知之
5. 觉察本身会令念头自然消融

## 与"压抑"的区别
| 压抑 | 觉照 |
|------|------|
| 强行阻止情绪 | 允许情绪存在，但不被卷走 |
| 能量被压制，积累 | 能量在觉察中自然流动释放 |
| 治标不治本 | 斩断业力造作的链条 |

## 截断业力的机制
```
刺激 → 觉照介入 → 不造新业
刺激 → 无觉照 → 习惯性反应 → 业力种子
```
觉照是在因果链"刺激→反应"之间插入意识空间，令[[业力]]造作暂停。

[Source: raw/自性清净与福慧双修.md]

## 禅宗诠释
"自净其意"——觉照看清念头来去而不被带走，即是自净其意，是[[六祖坛经]]修行要旨的日常实践。
