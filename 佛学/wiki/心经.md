# 心经


## 基本信息
- **全称**：摩诃般若波罗蜜多心经（Prajñāpāramitā-hṛdaya-sūtra）
- **篇幅**：260余字（最短的佛经之一）
- **地位**：六百卷《大般若经》的精髓提炼，最广为流传的佛教经典

## 结构解析
```
【主体】观自在菩萨，行深般若波罗蜜多时
【核心命题】照见五蕴皆空，度一切苦厄
【色空论】色即是空，空即是色
【无系列】无眼耳鼻舌身意…无智亦无得
【以故】以无所得故，菩提萨埵…心无挂碍
【咒语】揭谛揭谛，波罗揭谛…菩提萨婆诃
```

## 核心命题详解

### 色即是空，空即是色
- **色即是空**：物质现象无固定自性（否定实有）
- **空即是色**：空性不妨现象显现（否定虚无）
- **不二**：色与空非对立，是同一实相的两面
[Source: raw/心经：空性智慧与修证指南.md]

### 五不（不生灭/不垢净/不增减）
描述[[空性]]本质：超越生灭、垢净、增减的二元对立

### 无系列的逻辑
"无眼耳鼻舌身意"——否定十二处执着（见[[三科法]]）
"无无明，亦无无明尽"——连修行次第本身也不可执
"无智亦无得"——证悟空性时，无能证之智，无所证之境
