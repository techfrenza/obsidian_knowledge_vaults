# 华严经


## 基本信息
- **全称**：大方广佛华严经（Avataṃsaka Sūtra）
- **主要译本**：实叉难陀（唐）80卷本（最流行）；佛陀跋陀罗（晋）60卷本
- **地位**：大乘经典中规模最宏大，华严宗根本经典

## 核心思想

### 一真法界
- 宇宙本质是"至真、至善、至美"的完整实相
- 非苦难之地，而是完全圆满的华藏庄严世界海
- 万法相即相入，无碍融通

### 事事无碍（四法界）
| 法界 | 内容 |
|------|------|
| 事法界 | 现象各别差异 |
| 理法界 | 万法共同空性 |
| 理事无碍 | 空有不二 |
| **事事无碍** | 现象间互相融摄、无障碍（最高境界）|

"一即多，多即一"——因陀罗网比喻：每一宝珠映现所有宝珠。[Source: raw/华严经：一真法界与圆融境界综述.md]

### 广狭自在
- 一毫端中现十方刹土
- 刹那间包含永恒
- 超越时空的"不可思议解脱境界"

## 菩萨修行次第（五十二位）
```
十信（信心建立）
→ 十住（安住菩提心）
→ 十行（利生行愿）
→ 十回向（功德回向）
→ 十地（地地证悟）
→ 等觉 → 妙觉（成佛）
```
[Source: raw/华严经：一真法界与圆融境界综述.md]

### 普贤行愿
十大愿王（礼敬、称赞、供养、忏悔、随喜、请转法轮、请佛住世、常随佛学、恒顺众生、普皆回向）是华严修行的实践落脚点。
