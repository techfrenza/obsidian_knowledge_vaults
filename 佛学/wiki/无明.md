# 无明


## 定义
梵文 Avidyā，字面义"无知/不明"。不是普通的无知，而是对[[空性]]、[[无常]]、[[无我]]这些实相的根本性蒙昧。是[[十二因缘]]的第一支，[[轮回]]的起点。

## 无明 vs 一般无知
| 一般无知 | 无明 |
|---------|------|
| 不知道某事实 | 对"我"与"现象"的本质产生根本性错误理解 |
| 可通过学习解决 | 需通过[[般若]]观修亲证才能破除 |
| 非轮回的根源 | [[十二因缘]]起点，驱动一切苦的起源 |

## 十二因缘中的无明
```
无明 → 行 → 识 → 名色 → 六入 → 触 → 受
→ 爱 → 取 → 有 → 生 → 老死（苦）
```
无明是整个苦链的第一推动力。

## 无明的具体形态
- **常见**：认为"我"是恒常不变的实体
- **乐见**：认为世间享乐是究竟幸福
- **净见**：将不净之物执为清净
- **我见**：认为五蕴聚合有一个固定的"我"

## 对治
[[般若]]是唯一对治无明的工具——
- 文字般若：建立正见，初步解构无明
- 观照般若：实际观修，动摇无明的惯性
- 实相般若：亲证，根本断除无明
