# 我执


## 定义
梵文 ātma-grāha，执取"我"为真实存在的固有倾向。是[[轮回]]、烦恼、[[业力]]造作的根本驱动力。

## 两层我执
| 层次 | 内容 |
|------|------|
| 俱生我执 | 与生俱来的本能自我感，难以察觉 |
| 分别我执 | 通过错误观念强化的我执，可通过正见破除 |

## 我执的运作机制
```
五蕴聚合 → 错认为"我" → 我执生 → 爱憎取舍 → 业力造作 → 轮回
```

## 四相是我执的具体形态
见[[四相]]：
- 我相 = 执固定的"我"存在
- 人相 = 执我与他的二元分立
- 众生相 = 执群体差异与偏见
- 寿者相 = 执生命有延续的主体

## 法执
比我执更微细：执取"法"（现象/概念）为真实存在。破我执后仍需破[[法执]]，方证究竟[[空性]]。

## 破除路径
- **渐修**：[[三科法]]分析，逐层拆解五蕴无我
- **顿悟**：禅宗直指，当下见性，四相顿空
- **日常**：[[觉照]]自动化的我执反应，截断其造业链
