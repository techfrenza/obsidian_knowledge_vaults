# 十二因缘


## 定义
梵文 Dvādaśa-nidāna，十二个相互依存的条件链，描述[[轮回]]生死苦的完整发生机制。是佛教缘起论（pratītyasamutpāda）的核心应用。

## 十二支
```
1. 无明（avidyā）      — 对实相的根本蒙昧
2. 行（saṃskāra）     — 由无明驱动的意志造作
3. 识（vijñāna）      — 投胎意识
4. 名色（nāma-rūpa）  — 身心胚胎的成形
5. 六入（ṣaḍ-āyatana）— 六根的发育
6. 触（sparśa）       — 根尘相遇的接触
7. 受（vedanā）       — 苦/乐/不苦不乐的感受
8. 爱（tṛṣṇā）       — 对乐受的贪取
9. 取（upādāna）      — 执取，强化执着
10. 有（bhava）        — 业力存在，造新业
11. 生（jāti）         — 来生的诞生
12. 老死（jarā-maraṇa）— 一切苦的总结
```

## 还灭门（逆观）
顺观十二因缘 = 苦的发生（流转门）
逆观十二因缘 = 苦的解脱（还灭门）：
```
无明灭 → 行灭 → … → 老死灭（苦灭）
```
破除[[无明]]是解脱的关键第一步。

## 与三科法的关系
十二因缘细化了[[五蕴]]和[[三科法]]的动态运作：六入（= 十二处的内六处）、触（= 根尘相遇）、识（= 十八界的识）——三科法是静态解构，十二因缘是动态流程。
