# 轮回


## 定义
梵文 Saṃsāra，字面义"流转/漂泊"。指众生因[[业力]]与[[我执]]在六道中反复生死的过程。非神话惩罚机制，而是心念与行为造作的因果显现。

## 六道
| 道 | 主导情绪 | 象征状态 |
|----|---------|---------|
| 天道 | 自满/享乐执 | 福报极大但易退堕 |
| 人道 | 苦乐参半 | 修行最佳位 |
| 阿修罗道 | 嗔恨/嫉妒 | 争斗不息 |
| 畜生道 | 愚痴/无明 | 本能主导 |
| 饿鬼道 | 贪欲不满 | 永恒匮乏感 |
| 地狱道 | 极度嗔恨痛苦 | 自我创造的内心地狱 |

[Source: raw/生死轮转与觉悟之路.md]

## 轮回机制
```
[[无明]] → 我执 → 业力造作 → 临终心念 → 下一生
  ↑___________________________________|
```
楞严经："由情想二者的比例"决定去向：
- 情（贪执）> 想（认知）→ 下堕
- 想（认知）> 情（贪执）→ 上升

[Source: raw/楞严经.md]

## 现代心理解读
六道不仅是字面的来世，更是当下心理状态的象征：
- 处于极度嗔恨 = 当下在地狱道
- 贪欲难满足 = 当下在饿鬼道
- 修行觉醒 = 当下在人道/天道
