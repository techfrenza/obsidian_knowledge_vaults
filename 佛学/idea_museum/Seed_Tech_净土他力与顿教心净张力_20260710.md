## 技术核心逻辑

**两条路的核心主张对比**：

| 路径 | 经典依据 | 核心命题 | 时间轴 |
|------|---------|---------|------|
| 净土宗（他力路）| [[阿弥陀经]]、无量寿经 | 持名念佛，临终往生极乐，在极乐无障碍道场继续修行成佛 | 延迟：此生修因，死后得果 |
| 顿教（心净路）| [[圆觉经]]"于不二境现净土"；[[六祖坛经]] | 随其心净，即佛土净；明心见性即当下净土 | 即时：此生此刻证入 |

**张力的深层结构**：

净土宗的逻辑：
```
众生心不清净 → 无法当下证入 → 需借弥陀愿力 → 临终往生 → 在净土补足修行
```

顿教的逻辑：
```
众生心本清净（如来藏本性） → 只需认出 → 当下净土现前
```

如果顿教逻辑成立，净土宗是"多此一死"；如果净土宗正确，顿教是"高估了众生根器"。

**通行整合方案**：

| 根器 | 适合路径 |
|------|---------|
| 上根利器（有宿世善根，可当下直指见性）| 顿教心净路 |
| 中下根（末法众生，心散乱，临终难以自持）| 净土他力路（保险机制） |

净土宗本身也有"理一心"境界：念佛至"念而无念，念佛即空性"——在净土框架内也可当下证入。

**最深层的设计智慧**：净土宗作为"兜底系统"的价值在于：它的有效性不依赖修行者当下的心理状态，而是依赖弥陀的愿力——这是一个**对用户状态容错极高的系统设计**，专门针对临终心念无法自控的高风险场景。
